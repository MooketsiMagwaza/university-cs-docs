## Things to know

- **Pushing a big branch**: use `git -c pack.useSparse=false -c http.postBuffer=524288000 push`. Without it a branch with many renames sends a pack ten times too large and fails with HTTP 408.
- **Memory**: the dev server, `tsc` and Playwright together can use several GB (DEV-01). Run one at a time, and stop the dev server when it is not in use.
- **Browser tests**: Playwright expects its own dev server on port 3101; to reuse a running one, use a config with `baseURL: 'http://localhost:3000'` and no `webServer`.
- **Line endings**: most content files are CRLF. Edit them with tools that keep the line endings, or the diff shows every line changed.
- **The `next.config.mjs` redirects and `content/progress/aliases.json`** must both be updated whenever a page moves.
