## 5.3 Geometric and Negative Binomial Distributions

Unlike the Binomial distribution, which fixes the number of trials and counts successes, the Geometric and Negative Binomial distributions fix the number of successes and count the number of **failures** required to achieve them. *(Note: This aligns with the "failures before success" convention).*

<Card>

### Definition 5.3.1 (Geometric Distribution)

A random variable $X$ follows a **Geometric Distribution** with parameter $p$ (probability of success), denoted $X \sim \text{Geo}(p)$, if it counts the number of **failures** before the 1st success.

**Probability Mass Function (PMF):**
$$
p(x) = p(1-p)^x \quad \text{for } x = 0, 1, 2, \dots
$$
Let $q = 1-p$. The PMF is often written as $p(x) = p q^x$.

</Card>

<HighlightCard
  variant="neutral"
  title="Theorem 5.3.1: Geometric Survival Function"
  description="A critical exam concept: The probability of observing at least $x$ failures before the first success."
>

$$
P(X \ge x) = q^x \quad \text{where } q = 1-p
$$
*(Exam Warning: Because $x$ counts failures starting at $0$, the exponent is exactly $x$, **not** $x-1$.)*

</HighlightCard>

<StepByStep>
  <StepByStepTitle>Proof: Geometric Survival Function</StepByStepTitle>

  <Step number={1}>
    <StepTitle>State the Goal</StepTitle>

    Prove that $P(X \ge x) = \sum_{k=x}^\infty p q^k = q^x$.
  </Step>

  <Step number={2}>
    <StepTitle>Apply the Infinite Geometric Series Formula</StepTitle>

    The sum is a geometric series with first term $a = p q^x$ (when $k=x$) and common ratio $r = q$.
    Since $0 < q < 1$, the series converges.
  </Step>

  <Step number={3}>
    <StepTitle>Evaluate the Sum</StepTitle>

    $P(X \ge x) = \frac{a}{1 - r} = \frac{p q^x}{1 - q}$
  </Step>

  <Step number={4}>
    <StepTitle>Simplify</StepTitle>

    Since $1 - q = p$, the expression simplifies to:
    $P(X \ge x) = \frac{p q^x}{p} = q^x$. $\blacksquare$
  </Step>
</StepByStep>

<Card>

### Definition 5.3.2 (Negative Binomial Distribution)

A random variable $X$ follows a **Negative Binomial Distribution** with parameters $r$ (target number of successes) and $p$ (probability of success), denoted $X \sim \text{NB}(r, p)$, if it counts the number of **failures** before the $r$-th success.

**Probability Mass Function (PMF):**
$$
p(x) = \binom{x+r-1}{r-1} p^r (1-p)^x \quad \text{for } x = 0, 1, 2, \dots
$$

**Combinatorial Intuition:** To have exactly $x$ failures before the $r$-th success, the final trial (trial number $x+r$) **must** be a success (probability $p$). The preceding $x+r-1$ trials must contain exactly $r-1$ successes and $x$ failures. The number of ways to arrange these is $\binom{x+r-1}{r-1}$ (or equivalently $\binom{x+r-1}{x}$).

</Card>

<StepByStep>
  <StepByStepTitle>Example: Applying the Negative Binomial PMF</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Problem Statement</StepTitle>

    A basketball player makes free throws with probability $p = 0.8$. What is the probability that she misses exactly 2 free throws before making her 3rd successful free throw?
  </Step>

  <Step number={2}>
    <StepTitle>Identify Parameters</StepTitle>

    We are counting failures ($x$) before the $r$-th success.
    $r = 3$ (target successes), $x = 2$ (failures), $p = 0.8$, $q = 0.2$.
  </Step>

  <Step number={3}>
    <StepTitle>Apply the PMF</StepTitle>

    $P(X = 2) = \binom{2+3-1}{3-1} (0.8)^3 (0.2)^2$
    $P(X = 2) = \binom{4}{2} (0.512) (0.04)$
    $P(X = 2) = 6 \times 0.512 \times 0.04 = 0.12288$
  </Step>
</StepByStep>
