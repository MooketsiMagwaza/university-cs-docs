## 6.3 Reliability Engineering and Hazard Rates

Reliability engineering applies probability theory to predict the lifespan and failure rates of systems and components. We define the **Reliability Function** (or Survival Function) as $R(t) = P(T > t) = 1 - F(t)$, representing the probability that a component survives beyond time $t$.

<HighlightCard
  variant="neutral"
  title="Theorem 6.3.1: System Reliability Configurations"
  description="The overall reliability of a system depends on how its components are interconnected, assuming component failures are independent."
>

**Series System:** All components must function for the system to function.
$$
R_{\text{series}}(t) = \prod_{i=1}^n R_i(t)
$$

**Parallel System:** The system functions if at least one component functions.
$$
R_{\text{parallel}}(t) = 1 - \prod_{i=1}^n (1 - R_i(t))
$$

</HighlightCard>

<Card>

### Definition 6.3.1 (k-out-of-n Systems)

A **$k$-out-of-$n$ System** functions if at least $k$ out of its $n$ identical, independent components are functioning. 

If each component has reliability $R$, the system reliability is calculated using the Binomial Cumulative Distribution Function (summing the probabilities of $k$ to $n$ successes):
$$
R_{k/n} = \sum_{i=k}^n \binom{n}{i} R^i (1-R)^{n-i}
$$

</Card>

<StepByStep>
  <StepByStepTitle>Example: Calculating k-out-of-n System Reliability</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Problem Statement</StepTitle>

    An aircraft has 4 independent engines. The aircraft can fly safely if at least 2 engines are functioning. If each engine has a reliability of $R = 0.9$ for a given flight, what is the probability the aircraft flies safely?
  </Step>

  <Step number={2}>
    <StepTitle>Identify Parameters</StepTitle>

    This is a 2-out-of-4 system: $n = 4$, $k = 2$, $R = 0.9$.
  </Step>

  <Step number={3}>
    <StepTitle>Apply the Binomial Formula</StepTitle>

    $R_{2/4} = \sum_{i=2}^4 \binom{4}{i} (0.9)^i (0.1)^{4-i}$
    $R_{2/4} = \binom{4}{2}(0.9)^2(0.1)^2 + \binom{4}{3}(0.9)^3(0.1)^1 + \binom{4}{4}(0.9)^4(0.1)^0$
  </Step>

  <Step number={4}>
    <StepTitle>Calculate the Result</StepTitle>

    $R_{2/4} = 6(0.81)(0.01) + 4(0.729)(0.1) + 1(0.6561)(1)$
    $R_{2/4} = 0.0486 + 0.2916 + 0.6561 = 0.9963$
  </Step>
</StepByStep>

<HighlightCard
  variant="neutral"
  title="Theorem 6.3.2: The Hazard Rate Function"
  description="The hazard rate (or failure rate) $h(t)$ represents the instantaneous rate of failure at time $t$, given that the component has survived up to time $t$."
>

$$
h(t) = \frac{f(t)}{R(t)} = \frac{f(t)}{1 - F(t)}
$$

</HighlightCard>

<StepByStep>
  <StepByStepTitle>Proof: Constant Hazard Rate Implies the Exponential Distribution</StepByStepTitle>

  <Step number={1}>
    <StepTitle>State the Goal</StepTitle>

    Prove that if $h(t) = \lambda$ (a constant) for all $t \ge 0$, then the reliability function is $R(t) = e^{-\lambda t}$, which defines the Exponential distribution.
  </Step>

  <Step number={2}>
    <StepTitle>Express Hazard Rate in Terms of R(t)</StepTitle>

    Recall that $f(t) = -R'(t)$ (since $R(t) = 1 - F(t)$ and $F'(t) = f(t)$).
    Substitute this into the hazard rate definition:
    $h(t) = \frac{-R'(t)}{R(t)}$
  </Step>

  <Step number={3}>
    <StepTitle>Set Up the Differential Equation</StepTitle>

    Given $h(t) = \lambda$, we have:
    $\frac{-R'(t)}{R(t)} = \lambda \implies \frac{R'(t)}{R(t)} = -\lambda$
  </Step>

  <Step number={4}>
    <StepTitle>Integrate Both Sides</StepTitle>

    $\int \frac{R'(t)}{R(t)} \, dt = \int -\lambda \, dt$
    $\ln(R(t)) = -\lambda t + C$
  </Step>

  <Step number={5}>
    <StepTitle>Solve for R(t) and Apply Initial Condition</StepTitle>

    Exponentiate both sides: $R(t) = e^{-\lambda t + C} = e^C e^{-\lambda t}$.
    At time $t=0$, the component is new, so $R(0) = 1$.
    $1 = e^C e^0 \implies e^C = 1$.
    Therefore, $R(t) = e^{-\lambda t}$. $\blacksquare$
  </Step>
</StepByStep>
