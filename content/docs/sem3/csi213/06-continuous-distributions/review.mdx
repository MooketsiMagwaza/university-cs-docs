## Decoding the questions

Before calculating, identify the object the question gives you and the object it requests:

| Given | Requested | Main move |
|---|---|---|
| PDF with an unknown constant | Valid PDF | Set total integral equal to 1 |
| PDF | Interval probability | Integrate over the interval |
| PDF | Mean/variance | Compute $E[X]$ and $E[X^2]$ |
| CDF | Interval/tail | Subtract CDF values or take a complement |
| Uniform endpoints | Probability | Desired width divided by total width |
| Exponential mean | Probability | First convert to $\lambda=1/\mu$ |
| Normal raw value | Probability | Standardise, then use $\Phi$ |
| Normal probability | Raw cut-off | Find $z$, then use $x=\mu+z\sigma$ |
