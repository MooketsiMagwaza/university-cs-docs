---
title: "Set Theory & Combinatorics"
description: "Set notation and algebra for events, the counting rules, and sigma notation: the tools every later topic uses."
---

Probability is built on sets and counting. An event is a set of outcomes, and many probabilities are one count divided by another. This topic gives you the notation and algebra for sets, the counting rules for arrangements and selections, and the sigma notation used to add up probabilities later in the course.

<LearningObjectives items={[
  'Write a set in roster and set-builder notation, and use membership, subset and equality correctly',
  'Combine and complement sets, and use De Morgan laws to prove two set expressions equal',
  'Count arrangements and selections with the multiplication principle, permutations and combinations',
  'Evaluate sums written in sigma notation using linearity, arithmetic and geometric series, and telescoping',
]} />

<Prerequisites items={[
  'Basic algebra and set notation (CSI132 topic 1, Sets and Functions, introduces the notation)',
]} />
