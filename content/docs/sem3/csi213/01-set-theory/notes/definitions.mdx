## 1.1 Set Definitions

<Card>

### Definition 1.1.1 (Sets and Elements)

A set is a collection of distinguishable objects. We denote membership as $x \in A$ (element of) and $x \notin A$ (not element of).

</Card>

<StepByStep>
  <StepByStepTitle>Example: Identifying Sets and Elements</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Define a Base Set</StepTitle>

    Let $A = \{a, b, c\}$.
  </Step>

  <Step number={2}>
    <StepTitle>Check Membership</StepTitle>

    $a \in A$ is true.
    $d \notin A$ is true.
  </Step>

  <Step number={3}>
    <StepTitle>Verify Properties</StepTitle>

    The order of elements does not matter: $\{a, b, c\} = \{c, a, b\}$.
  </Step>
</StepByStep>

<Card title="Definition 1.1.2: Basic Set Operations">

### The Four Fundamental Set Operations

Given a Universal set $U$ and sets $A, B \subseteq U$:
- **Union ($A \cup B$):** The set of all elements that are in $A$, **or** in $B$, or in both. $\{x \mid x \in A \lor x \in B\}$
- **Intersection ($A \cap B$):** The set of all elements that are in **both** $A$ **and** $B$. $\{x \mid x \in A \land x \in B\}$
- **Complement ($\overline{A}$ or $A^c$):** The set of all elements in $U$ that are **not** in $A$. $\{x \in U \mid x \notin A\}$
- **Difference ($A - B$ or $A \setminus B$):** The set of elements in $A$ that are **not** in $B$. $\{x \mid x \in A \land x \notin B\}$

</Card>

<Card>

### Definition 1.1.3 (Universal, Empty, and Power Sets)

**Universal Set ($S$ or $U$):** The set of all possible objects under consideration (Sample Space in statistics).
**Empty Set ($\emptyset$):** A set containing no elements.
**Power Set ($\mathcal{P}(A)$):** The set of all subsets of $A$.

</Card>

<Card title="Definition: Empty Set Specifics">

### Definition 1.1.4 (Empty Set Specifics)

The **Empty Set**, denoted as $\emptyset$ or $\{\}$, is the unique set containing no elements.

Mathematically: $\emptyset = \{x \mid x \neq x\}$
For any set $A$, $\emptyset \subseteq A$ and $A \cup \emptyset = A$.

</Card>

<StepByStep>
  <StepByStepTitle>Example: Empty Set in Operations</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Identify the Sets</StepTitle>

    Let $A = \{3, 6, 9\}$ and $B = \{2, 4, 8\}$.
  </Step>

  <Step number={2}>
    <StepTitle>Find the Intersection</StepTitle>

    $A \cap B$ contains elements common to both sets. Since there are no common elements, $A \cap B = \emptyset$.
  </Step>

  <Step number={3}>
    <StepTitle>Verify Empty Set Properties</StepTitle>

    $A \cup \emptyset = \{3, 6, 9\} \cup \{\} = \{3, 6, 9\} = A$. The property holds.
  </Step>
</StepByStep>

<Card>

### Definition 1.1.5 (Power Set Specifics)

The **Power Set** of a set $A$, denoted as $P(A)$ or $\mathcal{P}(A)$, is the set of all possible subsets of $A$, including the empty set and $A$ itself.

Mathematically: $P(A) = \{X \mid X \subseteq A\}$
If $|A| = n$, then $|P(A)| = 2^n$.

</Card>

<StepByStep>
  <StepByStepTitle>Example: Constructing a Power Set</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Identify the Base Set</StepTitle>

    Let $A = \{1, 2\}$. The number of elements is $n = 2$.
  </Step>

  <Step number={2}>
    <StepTitle>Determine the Size of the Power Set</StepTitle>

    The power set will have $2^2 = 4$ elements.
  </Step>

  <Step number={3}>
    <StepTitle>List All Subsets</StepTitle>

    - Subset with 0 elements: $\emptyset$
    - Subsets with 1 element: $\{1\}, \{2\}$
    - Subset with 2 elements: $\{1, 2\}$

    Therefore, $P(A) = \{\emptyset, \{1\}, \{2\}, \{1, 2\}\}$.
  </Step>
</StepByStep>

$$
A \subset B \iff A = A \cap B

<Card title="Definition: Subset Relationship Context">

### Definition 1.1.7 (Subset Relationship Context)

A set $A$ is a subset of $B$ (denoted $A \subseteq B$) if and only if the intersection of $A$ and $B$ is exactly $A$.

Mathematically: $A \subseteq B \iff A = A \cap B$
*(Note: Some texts use $A \subset B$ to denote this same subset relationship).*

</Card>

<StepByStep>
  <StepByStepTitle>Example: Proving Subset Equivalence</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Define the Sets</StepTitle>

    Let $A = \{2, 4\}$ and $B = \{1, 2, 3, 4, 5\}$. Clearly, $A \subseteq B$.
  </Step>

  <Step number={2}>
    <StepTitle>Compute the Intersection</StepTitle>

    $A \cap B = \{2, 4\} \cap \{1, 2, 3, 4, 5\} = \{2, 4\}$.
  </Step>

  <Step number={3}>
    <StepTitle>Verify the Equivalence</StepTitle>

    Since $A \cap B = \{2, 4\}$ and $A = \{2, 4\}$, we have $A = A \cap B$, confirming the equivalence.
  </Step>
</StepByStep>
