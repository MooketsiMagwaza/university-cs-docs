---
title: "Random Variables & Distribution Functions"
description: "Random variables as functions on a sample space, the PMF, PDF and CDF that describe them, and the expected value and variance that summarise them."
---

A random variable turns the outcomes of an experiment into numbers, and a distribution says how likely each number is. This topic defines a random variable properly, describes it with a PMF, PDF or CDF, and then summarises it with two numbers: the expected value, which is its average, and the variance, which is its spread.

<LearningObjectives items={[
  'Define a random variable as a function on a sample space, and state its support',
  'Use a PMF, PDF or CDF to find probabilities, and move between them',
  'Compute and interpret an expected value, using linearity of expectation',
  'Derive and use the variance formula Var(X) = E[X squared] minus the square of E[X]',
]} />
