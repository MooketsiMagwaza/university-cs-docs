## 4.1 Random Variables and Distribution Functions

In probability theory, we often need to quantify abstract outcomes. While sample spaces can be categorical (e.g., "Heads", "Tails"), mathematical analysis requires the structure of the real number line. A random variable bridges this gap, allowing us to apply the powerful tools of calculus and algebra to probabilistic events.

<Card>

### Definition 4.1.1 (The Random Variable)

A **Random Variable**, typically denoted by an uppercase letter (e.g., $X, Y, Z$), is a deterministic mathematical function that maps every outcome $s$ in the sample space $S$ to a real number in $\mathbb{R}$.

$$
X: S \to \mathbb{R}
$$

*(Note: In rigorous measure theory, $X$ must be a measurable function, ensuring that we can always assign a valid probability to events defined by inequalities, such as $\{X \le x\}$.)*

</Card>

Random variables generally fall into two primary categories, which dictate the mathematical tools we use to analyze them:
1. **Discrete:** The range of $X$ is countable (e.g., integers). We use summations.
2. **Continuous:** The range of $X$ is an uncountable interval of real numbers. We use integrals.

---

### Discrete Random Variables and the PMF

For a discrete random variable, the probability distribution is described by the Probability Mass Function (PMF).

<Card>

### Definition 4.1.2 (Probability Mass Function)

The **Probability Mass Function (PMF)** of a discrete random variable $X$, denoted $p(x)$, gives the probability that $X$ takes on a specific value $x$:
$$
p(x) = P(X = x)
$$

</Card>

<HighlightCard
  variant="neutral"
  title="Theorem 4.1.1: Validity Conditions for a PMF"
  description="For a function $p(x)$ to be a valid PMF, it must satisfy three strict mathematical conditions."
>

1. **Non-negativity:** $p(x) \ge 0$ for all possible values of $x$.
2. **Normalization:** The sum of probabilities over all possible values of $X$ must equal 1.
   $$ \sum_{x} p(x) = 1 $$
3. **Event Probability:** The probability of any event $A$ is the sum of the PMF over the values in $A$.
   $$ P(X \in A) = \sum_{x \in A} p(x) $$

</HighlightCard>

<StepByStep>
  <StepByStepTitle>Example: Finding the Constant in a PMF</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Problem Statement</StepTitle>

    Let $X$ be a discrete random variable with PMF $p(x) = c \cdot x$ for $x \in \{1, 2, 3\}$, and $p(x) = 0$ otherwise. Find the value of the constant $c$ that makes this a valid PMF.
  </Step>

  <Step number={2}>
    <StepTitle>Apply the Normalization Condition</StepTitle>

    The sum of all probabilities must equal 1:
    $\sum_{x=1}^3 p(x) = p(1) + p(2) + p(3) = 1$
  </Step>

  <Step number={3}>
    <StepTitle>Substitute and Solve</StepTitle>

    $(c \cdot 1) + (c \cdot 2) + (c \cdot 3) = 1$
    $6c = 1 \implies c = \frac{1}{6}$
  </Step>
</StepByStep>

### Continuous Random Variables and the PDF

For a continuous random variable, the probability of any single exact point is zero. Instead, we describe the distribution using a Probability Density Function (PDF).

<HighlightCard
  variant="neutral"
  title="Theorem 4.1.2: Validity Conditions for a PDF"
  description="For a function $f(x)$ to be a valid Probability Density Function, it must satisfy two conditions."
>

1. **Non-negativity:** $f(x) \ge 0$ for all $x \in \mathbb{R}$.
2. **Normalization:** The total area under the curve must equal 1.
   $$ \int_{-\infty}^{\infty} f(x) \, dx = 1 $$

</HighlightCard>

<Card>

### Definition 4.1.3 (Probability of an Interval)

For a continuous random variable $X$ with PDF $f(x)$, the probability that $X$ falls within an interval $[a, b]$ is the area under the PDF curve over that interval:
$$
P(a \le X \le b) = \int_{a}^{b} f(x) \, dx
$$

</Card>

<StepByStep>
  <StepByStepTitle>Proof: Why $P(X = a) = 0$ for Continuous Random Variables</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Express as an Interval</StepTitle>

    The event $\{X = a\}$ can be written as the degenerate interval $[a, a]$.
  </Step>

  <Step number={2}>
    <StepTitle>Apply the PDF Definition</StepTitle>

    $P(X = a) = P(a \le X \le a) = \int_{a}^{a} f(x) \, dx$
  </Step>

  <Step number={3}>
    <StepTitle>Evaluate the Integral</StepTitle>

    By the fundamental properties of definite integrals, the integral from a point to itself is always zero, regardless of the function $f(x)$.
    Therefore, $P(X = a) = 0$. $\blacksquare$
  </Step>
</StepByStep>

### The Cumulative Distribution Function (CDF)

The CDF is a universal tool that applies to **both** discrete and continuous random variables, providing a unified way to describe their distributions.

<HighlightCard
  variant="neutral"
  title="Theorem 4.1.3: Properties of the Cumulative Distribution Function"
  description="The CDF, defined as $F(x) = P(X \le x)$, must satisfy four fundamental properties for any valid random variable."
>

1. **Non-decreasing:** If $a \le b$, then $F(a) \le F(b)$.
2. **Right-continuous:** $\lim_{x \to a^+} F(x) = F(a)$.
3. **Lower Limit:** $\lim_{x \to -\infty} F(x) = 0$.
4. **Upper Limit:** $\lim_{x \to \infty} F(x) = 1$.

</HighlightCard>

<StepByStep>
  <StepByStepTitle>Example: Deriving the CDF from a PDF</StepByStepTitle>

  <Step number={1}>
    <StepTitle>Problem Statement</StepTitle>

    Let $X$ be a continuous random variable with PDF $f(x) = 2x$ for $0 \le x \le 1$, and $f(x) = 0$ otherwise. Find the CDF $F(x)$.
  </Step>

  <Step number={2}>
    <StepTitle>Apply the CDF Definition</StepTitle>

    $F(x) = P(X \le x) = \int_{-\infty}^{x} f(t) \, dt$
  </Step>

  <Step number={3}>
    <StepTitle>Evaluate for Different Intervals</StepTitle>

    - For $x < 0$: $F(x) = \int_{-\infty}^{x} 0 \, dt = 0$
    - For $0 \le x \le 1$: $F(x) = \int_{0}^{x} 2t \, dt = \left[ t^2 \right]_0^x = x^2$
    - For $x > 1$: $F(x) = \int_{0}^{1} 2t \, dt + \int_{1}^{x} 0 \, dt = 1 + 0 = 1$
  </Step>

  <Step number={4}>
    <StepTitle>State the Final CDF</StepTitle>

    $$
    F(x) = 
    \begin{cases} 
    0 & x < 0 \\ 
    x^2 & 0 \le x \le 1 \\ 
    1 & x > 1 
    \end{cases}
    $$
  </Step>
</StepByStep>
