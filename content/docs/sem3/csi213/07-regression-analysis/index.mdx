# Chapter 7: Regression Analysis

This chapter covers the mathematical foundation of simple linear regression. We will derive the Ordinary Least Squares (OLS) estimators using multivariate calculus, prove the fundamental ANOVA identity ($SST = SSR + SSE$), and establish the relationship between Pearson correlation and the coefficient of determination. Critical emphasis is placed on avoiding common statistical interpretation traps.
