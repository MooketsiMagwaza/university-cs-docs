A graph models relationships that are not necessarily hierarchical: roads, friendships, prerequisites, or network links.

## 1. Vocabulary through one graph

<Mermaid chart={`graph LR
  A --- B
  A --- C
  B --- D
  C --- D
  D --- E`} caption="An undirected graph: each line can be travelled in both directions." />

- vertices: A, B, C, D, E;
- edges: AB, AC, BD, CD, DE;
- neighbours of D: B, C, E;
- path A → B → D → E has three edges;
- degree of D is 3.

A directed edge <code>A → B</code> does not imply <code>B → A</code>. A weighted edge also stores a cost such as distance.

## 2. Representations

| Representation | Storage | Edge check | Best fit |
|---|---:|---:|---|
| adjacency matrix | O(V²) | O(1) | dense graphs, simple edge lookup |
| adjacency list | O(V + E) | proportional to a vertex's degree | sparse graphs and traversal |

~~~java
Map<String, List<String>> graph = new HashMap<>();
graph.put("A", List.of("B", "C"));
graph.put("B", List.of("A", "D"));
~~~

For an undirected graph, add both directions when building adjacency lists.

## 3. Breadth-first search: queue

BFS visits vertices by increasing number of edges from the start.

~~~java
Queue<String> frontier = new ArrayDeque<>();
Set<String> visited = new HashSet<>();

frontier.offer("A");
visited.add("A");

while (!frontier.isEmpty()) {
    String current = frontier.poll();
    for (String next : graph.get(current)) {
        if (visited.add(next)) { // true only when newly added
            frontier.offer(next);
        }
    }
}
~~~

Assuming alphabetical neighbours:

| step | removed | newly discovered | queue after | visited |
|---:|---|---|---|---|
| 1 | A | B, C | [B, C] | A,B,C |
| 2 | B | D | [C, D] | A,B,C,D |
| 3 | C | — | [D] | A,B,C,D |
| 4 | D | E | [E] | A,B,C,D,E |
| 5 | E | — | [] | A,B,C,D,E |

Mark visited when enqueuing to avoid adding the same vertex several times.

## 4. Depth-first search: recursion or stack

~~~java
public static void dfs(
        String current,
        Map<String, List<String>> graph,
        Set<String> visited) {

    if (!visited.add(current)) return;
    System.out.println(current);

    for (String next : graph.get(current)) {
        dfs(next, graph, visited);
    }
}
~~~

DFS follows one branch deeply before backing up. The exact order depends on neighbour order, so state the ordering assumption.

## 5. Why visited is essential

In the cycle A–B–D–C–A, a traversal without visited can return to A and repeat forever. The set changes the question from “is this a neighbour?” to “is this a newly discovered neighbour?”

## 6. Complexity

With adjacency lists, BFS and DFS are O(V + E): each vertex is processed and each edge is examined a constant number of times. The visited set and frontier/stack require O(V) space.
