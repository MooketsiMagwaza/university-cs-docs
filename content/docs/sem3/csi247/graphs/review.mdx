- vertex = object; edge = relationship;
- directed edges have orientation; weighted edges have cost;
- matrix uses O(V²); adjacency lists use O(V + E);
- BFS uses a queue and finds shortest paths by edge count in unweighted graphs;
- DFS uses recursion or a stack and explores deeply;
- visited tracking prevents repeated processing and cycles;
- with adjacency lists, BFS/DFS are O(V + E).
