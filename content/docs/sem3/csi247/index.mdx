> **Course objective:** Learn, implement, and apply common data structures in Java while understanding the costs and benefits of each choice.

## Official 2026/27 course sequence

The navigation follows the supplied course outline. The supplied lecture files currently reach Generics; every later data-structure heading also has a complete foundation chapter now, and those chapters can be tightened against future lecture examples without reorganising the course again.

1. **Java programming recap** — program structure, primitives and references, strings, control flow, input/output, methods, user-defined classes, and arrays.
2. **Recursion** — base cases, recursive calls, and tracing the call stack.
3. **Algorithm Analysis** — Big-O notation and comparing algorithmic growth.
4. **Searching and Sorting** — linear/binary search and the taught array-sorting algorithms.
5. **Java Packages** — built-in packages, user-defined packages, imports, compilation, and classpaths.
6. **Object-Oriented Programming** — inheritance, encapsulation, polymorphism, abstraction, abstract classes, and interfaces.
7. **Generics** — type parameters, generic classes/methods/interfaces, bounds, wrappers, and type-safe reuse.
8. **Java predefined data structures** — the Collections Framework and its common interfaces and implementations.
9. **Implemented data structures** — linked lists, stacks, queues, hash tables, trees, and graphs.

## How to use each topic

Start with the simplified explanation and its diagram. Predict each mutation before revealing the next trace row, then study the properties and fully commented Java. Finish with exam-style questions, flashcards, and quizzes. Use the [Java playground](/docs/sem3/csi247/java-playground) after the object or array movement makes sense. The [resources page](/docs/sem3/csi247/resources) distinguishes the current 2026 materials from archived notes.

> There is no universally best data structure. The right choice depends on the operations a problem requires and the time and space costs you can accept.
