## The five checks

1. Does each variable hold a value (a primitive) or an address (an array, a `String`, an object), and is it initialised before use?
2. Is every index between 0 and `length - 1`, and is every array or object created before a method is called on it?
3. Is a method working on a copy (a primitive, the variable itself) or on the shared array behind the copied address?
4. Is every variable used inside its scope, and does every branch of a method return a value?
5. Is every file closed, and is its exception declared or caught?
