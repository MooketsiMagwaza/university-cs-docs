## 2. Data structures (Lecture 1)

| Idea | Rule |
|---|---|
| Data structure | a way of organising data in memory, with a framework for manipulating it |
| Program | algorithm + data structure; the choice of structure decides the performance |
| Primitive | basic structures: integers, characters |
| Non-primitive | derived from primitives: array, linked list, stack, queue, tree, hash map, graph |
| Classified by | homogeneous or heterogeneous (the type stored); linear or non-linear (the arrangement); static or dynamic (memory management) |
| Linear / non-linear | linear: array, linked list, stack, queue; non-linear: trees, hash maps, graphs |
| Operations | create, add or insert, delete, modify, search, sort, merge |
| Efficient structure | easy storage, access and modification; quick access; less memory |

## 3. The Java review (Lecture 2)

```text
public class ClassName { public static void main(String[] args) { statements } }       saved as ClassName.java
int x;   x = 5;   final int LIMIT = 5;       declare, initialise, constant
Scanner scan = new Scanner(System.in);       scan.nextInt()   scan.nextDouble()
System.out.print()   System.out.println()   System.out.printf("%s %d %c %5.2f%n", ...)
Read a file:   new Scanner(new FileReader("data.txt"))      Write:   PrintWriter pw = new PrintWriter("out.txt");  pw.printf(..);  pw.close();
```

| Topic | Rule |
|---|---|
| Memory diagram | a primitive box holds the value; a reference box holds an address; assigning a reference copies the address |
| Operators | `17 / 5` is 3, `17 / 5.0` is 3.4, `2 + 3 * 4` is 14; `a++` uses then adds, `++a` adds then uses |
| Selection | `if`, `if-else`, multi-branch `if`, `switch` (use `break`), nested `if` |
| Repetition | `for` and `while`; errors: one too many or too few iterations, a wrong or missing update, nested loops |
| Strings | `"Computer Science".length()` is 16; `indexOf("scie")` is -1 (case-sensitive); `substring(9)` is `Science`; `charAt(length())` fails |
| Files | the input file must exist; an output file is overwritten; always `close()`; handle exceptions with `throws` or `try-catch` |

## 4. Methods and scope (Lecture 3)

```text
modifiers returnType name(type param) { body }          public static double cubeVolume(double length) { return length * length * length; }
double v = cubeVolume(2);                               arguments in the same number, order and types
/** purpose  @param name description  @return description */
```

| Topic | Rule |
|---|---|
| Parameters | the actual parameter (argument) is copied into the formal parameter; the method cannot change the caller's variable |
| Return | `return` ends the method and sends back a value of the declared type; every branch needs one, or `missing return statement` |
| `void` | no value; `return;` ends the method early |
| Implementing | describe it, find the inputs, find the types, write pseudocode, code the body, test (design the test cases first); use a stub while it is unfinished |
| Scope | local (inside a method), block (ends at `}`), global (outside any method); names must be unique within a scope; a local hides a global of the same name |
| Range reader | start the loop with `low - 1`: the lecture's `input = 0` returns 0 unasked for a range that contains 0 |

## 5. Arrays (Lecture 5)

```text
type[] arr = new type[n];     type[][] grid = new type[r][c];     int[] nums = {10, 6, -7, 9, 19};
arr[i] = expression;          arr[i]          arr.length          grid.length rows     grid[0].length columns
```

| Topic | Rule |
|---|---|
| Contents of a new array | numbers 0, `char` the zero character, `boolean` false, objects `null` |
| Index | 0 to `length - 1`; outside it: `ArrayIndexOutOfBoundsException` at run time |
| `length` | an attribute for an array (`arr.length`), a method for a `String` (`str.length()`) |
| Arrays as parameters | the parameter is a copy of the address: the method can change the elements of the caller's array, but not make the caller's variable point at a new array |
| Arrays of objects | each cell is `null` until you assign `new Class(...)`; a method on a `null` cell throws `NullPointerException` |
| Dry run | one value of the loop variable at a time; use the new values of earlier cells; cross out, never rub out |

```java title="FundamentalsCheat.java"
import java.util.Arrays;

public class FundamentalsCheat {
    static double average(int[] numbers) {
        double sum = 0.0;
        for (int i = 0; i < numbers.length; i++) {
            sum = sum + numbers[i];
        }
        return numbers.length != 0 ? sum / numbers.length : 0.0;
    }

    static int indexOfMax(int[] numbers) {
        int index = 0;                               // assume numbers[0] is the largest
        for (int i = 1; i < numbers.length; i++) {
            if (numbers[i] > numbers[index]) {
                index = i;
            }
        }
        return index;
    }

    static void doubleAll(int[] numbers) {           // changes the caller's array
        for (int i = 0; i < numbers.length; i++) {
            numbers[i] = numbers[i] * 2;
        }
    }

    static int addOne(int n) {                       // changes only its own copy
        n = n + 1;
        return n;
    }

    public static void main(String[] args) {
        int[] marks = {40, 85, 62};
        System.out.println(average(marks) + " " + indexOfMax(marks));
        doubleAll(marks);
        int n = 5;
        addOne(n);
        System.out.println(Arrays.toString(marks) + " " + n);

        String dept = "Computer Science";
        System.out.println(dept.length() + " " + dept.indexOf("scie") + " " + dept.substring(9));

        int[][] grid = new int[2][3];
        grid[1][2] = 7;
        System.out.println(grid.length + " " + grid[0].length + " " + grid[1][2]);
    }
}
```

## 7. Common errors

| Mistake | What javac or Java reports | Repair |
|---|---|---|
| `int x; x++;` | `variable x might not have been initialized` | initialise it |
| `final int k = 5; k = 6;` | `cannot assign a value to final variable k` | do not reassign |
| the same name twice in one scope | `variable count is already defined in method main(String[])` | rename |
| a method with a branch that does not return | `missing return statement` | return in every branch |
| using a block variable after the block | `cannot find symbol` | declare it outside the block |
| `cube()` or `cube("2")` for `cube(double)` | `cannot be applied to given types` / `incompatible types: String cannot be converted to double` | pass the right arguments |
| `int r = cube(2);` for a `double` method | `incompatible types: possible lossy conversion from double to int` | use a `double` variable |
| `numbers.length()` | `cannot find symbol` | `numbers.length` |
| `new FileReader(name)` with no handling | `unreported exception FileNotFoundException; must be caught or declared to be thrown` | `throws` or `try-catch` |
| `numbers[10]` on `new int[10]` | `ArrayIndexOutOfBoundsException` (run time) | use 0 to `length - 1` |
| `str.charAt(str.length())` | `StringIndexOutOfBoundsException` | `str.length() - 1` |
| a method on a `null` cell or array | `NullPointerException` | create the array or object first |
| `printf("%d", aDouble)` | `IllegalFormatConversionException` | `%.2f` |
| a `PrintWriter` that is not closed | the file is empty | `close()` |
| a method changes its parameter and the caller is unchanged | no error: a copy was changed | return the value and assign it |
| javac shows only some errors | flow errors appear after the type errors are fixed | fix and compile again |
