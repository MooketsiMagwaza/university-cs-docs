## 1. Placeholders used in every template on this page

| Placeholder | Meaning | Example |
|---|---|---|
| `Type` | Any type | `int`, `double`, `String`, `Student` |
| `name` | A variable, method or class name | `total`, `average`, `Main` |
| `condition` | An expression of type `boolean` | `age >= 18`, `i < a.length` |
| `value` | An expression that gives a value | `0`, `a[i] * 2` |
| `args` | The parameters of a method | `int a, int b` |

## 2. The skeleton of a program

```java
public class Name {                          // file must be Name.java
    public static void main(String[] args) { // the JVM starts here
        // statements, each ending with ;
    }
}
```

Compile with `javac Name.java`, run with `java Name` (no `.class`). Java is case-sensitive. The file name must match the `public` class.

## 3. Primitive types

| Type | Holds | Size | Default as a field or array element | Example literal |
|---|---|---|---|---|
| `byte` | whole number | 8 bits | `0` | `(byte) 100` |
| `short` | whole number | 16 bits | `0` | `(short) 100` |
| `int` | whole number | 32 bits, about ±2.1 billion | `0` | `42` |
| `long` | whole number | 64 bits | `0L` | `42L` |
| `float` | decimal | 32 bits | `0.0f` | `3.5f` |
| `double` | decimal | 64 bits | `0.0` | `3.5` |
| `char` | one UTF-16 character | 16 bits | `'\u0000'` | `'A'` |
| `boolean` | true or false | 1 bit of information | `false` | `true` |

A **local variable** has no default: using it before assigning it is a compile error. `String` is a class, not a primitive, so its default is `null`.

## 4. Operators and conversion

| Group | Operators | Watch for |
|---|---|---|
| Arithmetic | `+ - * / %` | `/` on two `int`s drops the fraction: `7 / 2` is `3`; `-7 % 3` is `-1` |
| Compound | `+= -= *= /= %= ++ --` | `x++` returns the old value, `++x` the new one |
| Comparison | `== != < <= > >=` | `==` on objects compares references |
| Logical | `&& \|\| !` | `&&` and `\|\|` stop early (short-circuit) |
| Ternary | `condition ? a : b` | both branches must have a compatible type |

**Widening** (smaller to larger type) is automatic: `int` to `long` to `double`. **Narrowing** needs a cast and can lose data: `(int) 3.9` is `3`, not `4`.

```java title="Operators.java"
public class Operators {
    public static void main(String[] args) {
        System.out.println(7 / 2);                 // int division
        System.out.println(7 / 2.0);               // one double makes the whole division double
        System.out.println((double) 7 / 2);        // cast BEFORE dividing
        System.out.println((double) (7 / 2));      // cast AFTER dividing: too late
        System.out.println(-7 % 3);                // the sign follows the left operand
        System.out.println((int) 3.9);             // truncates, does not round
        int x = 5;
        int y = x++ + ++x;                         // 5 + 7
        System.out.println(x + " " + y);
        System.out.println('A' + 1);               // char arithmetic gives an int
        System.out.println((char) ('A' + 1));
        System.out.println("1" + 2 + 3);           // left to right: text from the start
        System.out.println(1 + 2 + "3");
    }
}
```

```text
3
3.5
3.5
3.0
-1
3
7 12
66
B
123
33
```

## 5. Decisions

```java
if (condition) {
    // when true
} else if (otherCondition) {
    // when the first was false and this is true
} else {
    // when all were false
}

switch (value) {            // int, char, String or an enum
    case 1:
        // ...
        break;              // without break, execution FALLS THROUGH to the next case
    default:
        // ...
}
```

## 6. Loops

| Loop | Use when | Template |
|---|---|---|
| `for` | you know the count | `for (int i = 0; i < n; i++) { ... }` |
| `while` | you repeat until a condition changes | `while (condition) { ... }` |
| `do ... while` | the body must run at least once | `do { ... } while (condition);` |
| for-each | you visit every element and need no index | `for (Type item : collection) { ... }` |

`break` leaves the loop; `continue` skips to the next pass. Trace a loop with a table: one column per variable, one row per pass.

| Pass | `i` | `i < 4`? | `sum` afterwards |
|---|---|---|---|
| start | | | 0 |
| 1 | 0 | true | 0 |
| 2 | 1 | true | 1 |
| 3 | 2 | true | 3 |
| 4 | 3 | true | 6 |
| end | 4 | false | 6 |

## 7. Arrays

| Task | Code |
|---|---|
| Declare and create | `int[] a = new int[5];` (five zeros) |
| Create with values | `int[] a = {4, 8, 15};` |
| Length (a field, no brackets) | `a.length` |
| Read and write | `a[0] = 7;` valid indexes are `0` to `a.length - 1` |
| Loop with the index | `for (int i = 0; i < a.length; i++)` |
| Loop without the index | `for (int v : a)` |
| 2D array | `int[][] grid = new int[3][4];` then `grid[row][col]` |
| Print the contents | `Arrays.toString(a)`, `Arrays.deepToString(grid)` |

An array is an **object**: `int[] b = a;` copies the reference, not the contents, so `a` and `b` are the same array. Use `Arrays.copyOf(a, a.length)` for a copy. An index outside `0..length-1` throws `ArrayIndexOutOfBoundsException`.

## 8. Methods and parameter passing

```java
accessModifier static ReturnType name(Type param1, Type param2) {
    // body
    return value;                  // omit for void
}
```

Java passes **by value**: the method receives a copy of each argument. For a primitive the copy is the number, so the caller's variable never changes. For an object or array the copy is the reference, so the method can change the object the caller sees, but assigning a new object to the parameter changes only the copy.

```java title="PassByValue.java"
import java.util.Arrays;

public class PassByValue {
    static void changeNumber(int n) {
        n = 99;                          // changes the copy only
    }

    static void changeArray(int[] a) {
        a[0] = 99;                       // changes the shared array
        a = new int[] {7, 7, 7};         // changes the copy of the reference only
    }

    static int max(int a, int b) {       // overloading: same name, different parameters
        return a > b ? a : b;
    }

    static double max(double a, double b) {
        return a > b ? a : b;
    }

    public static void main(String[] args) {
        int n = 1;
        int[] arr = {1, 2, 3};
        changeNumber(n);
        changeArray(arr);
        System.out.println(n + " " + Arrays.toString(arr));
        System.out.println(max(3, 8) + " " + max(2.5, 1.5));
    }
}
```

```text
1 [99, 2, 3]
8 2.5
```

## 9. Strings

A `String` is an immutable object: its methods return new strings and never change the original.

| Task | Code | Result for `s = "Data"` |
|---|---|---|
| Length | `s.length()` | `4` |
| Character at index | `s.charAt(1)` | `'a'` |
| Substring | `s.substring(1, 3)` | `"at"` (end index excluded) |
| Compare contents | `s.equals("Data")` | `true` |
| Compare ignoring case | `s.equalsIgnoreCase("data")` | `true` |
| Order | `s.compareTo("Dog")` | negative, zero or positive |
| Search | `s.indexOf("t")` | `2`, or `-1` if absent |
| Change case | `s.toUpperCase()` | `"DATA"` |
| Join | `"a" + s` | `"aData"` |
| Split | `"a,b".split(",")` | `{"a", "b"}` |

**Never compare strings with `==`.** It compares references, and two equal-looking strings can be different objects.

```java title="Strings.java"
public class Strings {
    public static void main(String[] args) {
        String a = "Data";
        String b = new String("Data");
        System.out.println(a == b);                 // different objects
        System.out.println(a.equals(b));            // same characters
        System.out.println(a.substring(1, 3) + " " + a.indexOf("t") + " " + a.compareTo("Dog"));
        a.toUpperCase();                            // the result is thrown away
        System.out.println(a);
    }
}
```

```text
false
true
at 2 -14
Data
```

## 10. Reading input

```java
import java.util.Scanner;

Scanner in = new Scanner(System.in);
int n = in.nextInt();            // reads one int
String word = in.next();         // one word
in.nextLine();                   // consume the rest of the line after a number
String line = in.nextLine();     // a whole line
```

`nextLine()` straight after `nextInt()` returns the empty remainder of the number's line, not the next line. Call `nextLine()` once to discard it.

## 11. Common errors

| Mistake | What happens | Repair |
|---|---|---|
| `if (x = 5)` | compile error (`int` cannot be a condition) | `==` to compare |
| `a == b` on strings | `false` for equal text in different objects | `a.equals(b)` |
| `7 / 2` where `3.5` was wanted | `3` | `7 / 2.0` or `(double) 7 / 2` |
| `i <= a.length` | `ArrayIndexOutOfBoundsException` | `i < a.length` |
| Missing `break` in a `switch` | the next case also runs | add `break;` |
| Using a local variable before assigning it | compile error | give it a value first |
| Expecting a method to change an `int` argument | the caller's variable is unchanged | return the new value |
| `String s; s.length()` | `NullPointerException` if `s` is `null` | create or assign the string first |
| `;` after `for (...)` or `if (...)` | the body is an empty statement | remove the stray `;` |
