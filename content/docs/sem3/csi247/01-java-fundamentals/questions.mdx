Seven questions, grouped by what they test, each with its marks. Work a question on paper before opening the solution. The lessons that teach each form are [Data Structures by Example](/docs/sem3/csi247/01-java-fundamentals/notes/data-structures-by-example), [Java Basics by Example](/docs/sem3/csi247/01-java-fundamentals/notes/java-basics-by-example), [Methods by Example](/docs/sem3/csi247/01-java-fundamentals/notes/methods-by-example), [Arrays by Example](/docs/sem3/csi247/01-java-fundamentals/notes/arrays-by-example), [Lay-buy Labs by Example](/docs/sem3/csi247/01-java-fundamentals/notes/laybuy-labs-by-example) and [Java Fundamentals Exam Practice](/docs/sem3/csi247/01-java-fundamentals/notes/java-fundamentals-exam-practice), which has eight more.

**Marking guide.** A full-credit answer writes the value of every variable after every statement, draws a primitive as a box with a value and a reference as a box with an address and an arrow, gives the exact exception or compiler message, and for a boundary says whether it is included ("exceeds" is strictly more).
