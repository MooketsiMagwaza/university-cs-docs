<ExamQuestion title="Question 1: Types, Casting & Integer Division [10 Marks]">
  <SubQuestion part="a" prompt={<>State the resulting value and type of <code>double result = 7 / 2;</code>. Explain your answer. [3]</>} solution={<>Both operands are integers, so Java performs integer division first and produces <code>3</code>. That value is then widened to a <code>double</code>, so <code>result</code> becomes <code>3.0</code>.</>} />
  <SubQuestion part="b" prompt={<>Rewrite the expression so that it produces <code>3.5</code>. [2]</>} solution={<>Make at least one operand a <code>double</code>, for example <code>double result = 7.0 / 2;</code> or <code>double result = (double) 7 / 2;</code>.</>} />
  <SubQuestion part="c" prompt={<>What value is stored by <code>int mark = (int) 79.95;</code>, and why? [2]</>} solution={<>The value is <code>79</code>. Narrowing from <code>double</code> to <code>int</code> discards the fractional part; it does not round it.</>} />
  <SubQuestion part="d" prompt={<>Distinguish widening from narrowing conversion and give one example of each. [3]</>} solution={<>Widening moves to a type with a broader range and is normally automatic, such as <code>int</code> to <code>double</code>. Narrowing may lose information and requires an explicit cast, such as <code>double</code> to <code>int</code>.</>} />
</ExamQuestion>

<ExamQuestion title="Question 2: Scope, Strings & Control Flow [12 Marks]">
  <SubQuestion part="a" prompt={<>Explain why a variable declared inside an <code>if</code> block cannot be used after the closing brace. [3]</>} solution={<>A local variable exists only within the block in which it is declared. The closing brace ends that scope, so the variable is no longer accessible.</>} />
  <SubQuestion part="b" prompt={<>Why should Java strings normally be compared with <code>.equals()</code> instead of <code>==</code>? [3]</>} solution={<><code>==</code> compares object references, whereas <code>.equals()</code> compares the character content of the strings.</>} />
  <SubQuestion part="c" prompt={<>Determine what is printed and explain the role of braces:<br/><code>int score = 45;<br/>if (score &gt;= 50)<br/>  System.out.println("Pass");<br/>  System.out.println("Recorded");</code> [3]</>} solution={<><code>Recorded</code> is printed. Without braces, only the first statement belongs to the <code>if</code>; indentation has no meaning to the compiler.</>} />
  <SubQuestion part="d" prompt={<>Correct the code so that both messages are printed only when the mark is at least 50. [3]</>} solution={<><code>if (score &gt;= 50) &#123;<br/>  System.out.println("Pass");<br/>  System.out.println("Recorded");<br/>&#125;</code></>} />
</ExamQuestion>

<ExamQuestion title="Question 3: Arrays & Loops [12 Marks]">
  <SubQuestion part="a" prompt={<>Write a method <code>average(int[] values)</code> that returns the arithmetic mean as a <code>double</code>. Assume the array is non-empty. [5]</>} solution={<>Accumulate the values in a loop, then return <code>(double) total / values.length</code>. The cast prevents integer division.</>} />
  <SubQuestion part="b" prompt={<>For an array of length 8, state the first valid index, last valid index, and the index that would cause an out-of-bounds error immediately after the final element. [3]</>} solution={<>The first valid index is 0, the last valid index is 7, and index 8 is outside the array.</>} />
  <SubQuestion part="c" prompt={<>Choose the most suitable loop type for: processing exactly 20 marks; repeating a menu at least once; and reading values until a sentinel is entered. Justify each choice. [4]</>} solution={<>Use a <code>for</code> loop for exactly 20 iterations, a <code>do-while</code> loop for a menu that must run once, and a <code>while</code> loop when repetition depends on an unknown future sentinel.</>} />
</ExamQuestion>

<ExamQuestion title="Question 4: Scanner & Input Validation [12 Marks]">
  <SubQuestion part="a" prompt={<>Explain why <code>nextLine()</code> may appear to be skipped immediately after <code>nextInt()</code>. [3]</>} solution={<><code>nextInt()</code> reads the number but leaves the line-ending character in the input buffer. The following <code>nextLine()</code> consumes that leftover line ending.</>} />
  <SubQuestion part="b" prompt={<>Show the statement normally used between <code>nextInt()</code> and the next text prompt. [2]</>} solution={<>Call <code>scanner.nextLine();</code> once to consume the remaining line ending.</>} />
  <SubQuestion part="c" prompt={<>Write the logic for repeatedly asking for an integer from 1 to 10 using <code>hasNextInt()</code>. Invalid tokens and out-of-range integers must both be rejected. [7]</>} solution={<>Use a loop. If <code>hasNextInt()</code> is false, consume the invalid token with <code>next()</code>. Otherwise read the integer, test whether it lies from 1 through 10, and leave the loop only when both type and range are valid.</>} />
</ExamQuestion>

<ExamQuestion title="Question 5: Methods [10 Marks]">
  <SubQuestion part="a" prompt={<>Differentiate a <code>void</code> method from a value-returning method. [3]</>} solution={<>A <code>void</code> method performs an action without returning a result. A value-returning method declares a return type and sends a compatible value back to its caller.</>} />
  <SubQuestion part="b" prompt={<>Write a method header and body for <code>isEven</code>, which accepts an integer and returns whether it is even. [3]</>} solution={<><code>static boolean isEven(int number) &#123;<br/>  return number % 2 == 0;<br/>&#125;</code></>} />
  <SubQuestion part="c" prompt={<>Explain the difference between a parameter and an argument using <code>isEven(12)</code>. [4]</>} solution={<>The parameter is the named variable in the method declaration, such as <code>number</code>. The argument is the actual value supplied by the caller, which is <code>12</code> here.</>} />
</ExamQuestion>

<ExamQuestion title="Question 6: File I/O & Exception Handling [14 Marks]">
  <SubQuestion part="a" prompt={<>Why must file operations be handled carefully even when the Java code is syntactically correct?   <SubQuestion part="b" prompt={<>Describe a safe sequence for writing three names to a text file and ensuring the writer is closed. [5]</>} solution={<>Open a writer inside a try-with-resources statement, write each name followed by a line separator, and allow try-with-resources to close the writer automatically. Catch or declare the relevant <code>IOException</code>.</>} />
  <SubQuestion part="c" prompt={<>Write pseudocode for reading a file line by line and counting the number of non-empty lines. [6]</>} solution={<>Open the reader in try-with-resources, initialize a counter to zero, loop while reading a line does not return <code>null</code>, increment only when <code>line.isBlank()</code> is false, then return the counter. Handle <code>IOException</code>.</>} />
</ExamQuestion>
