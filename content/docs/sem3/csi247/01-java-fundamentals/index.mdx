This module rebuilds Lectures 2–5 as five connected visual lessons. The key thread is **what each variable actually stores**. That one distinction explains primitive values, object references, array mutation, parameter passing, `null`, and why generics use wrapper/reference types.

### How to study the recap

For each lesson, draw the memory picture before reading the Java trace. Say the evaluated condition aloud, predict the next value/reference, and only then inspect the result. Finish the local quiz and the larger [exam-style question bank](/docs/sem3/csi247/01-java-fundamentals/questions).

The [Java playground](/docs/playgrounds/java) contains runnable recap examples. Change one value or boundary at a time so the visual model and output remain connected.
