## 1. The ideas in one table

| Idea | The lecture's statement |
|---|---|
| Program | the implementation of an algorithm, in a programming language |
| Algorithm | a well-defined set of instructions for solving a specific problem in a finite amount of time |
| Data structure (DS) | a way of organising data in a computer's memory; it gives a framework for manipulating the data and says what operations are allowed on the stored data (direct against sequential access, deletions, and so on) |
| Why both | an algorithm alone is not enough, because programs manipulate data: **Program = Algorithm + Data Structure** |
| The choice matters | the choice of data structure affects the program design and determines an algorithm's performance |

A program takes input, processes it and produces output. The data must be stored somewhere in memory and organised properly for efficient storage and retrieval. The key qualities of the most appropriate (efficient) data structure are: it offers easy storage, access and modification; it gives quick access to data; and it uses less memory space.

## 2. Classification of data structures

```text
                       Data structures
                 /                          \
        Primitive                      Non-primitive
   (integers, characters, ...)    (derived from the primitive ones)
                                   /                       \
                              Linear                    Non-linear
                  Array  Linked list  Stack  Queue     Trees  Hash map  Graph
```

| Classification | Question it answers | Examples |
|---|---|---|
| Primitive | is it a basic structure, introduced in first-year programming? | integers, characters |
| Non-primitive | is it more complex, derived from primitives? | array, stack, tree |
| Homogeneous or heterogeneous | what data type is stored? | an array holds one type; an object can hold several |
| Linear or non-linear | how are the data items arranged? | array, linked list, stack, queue are linear; trees, hash maps, graphs are not |
| Static or dynamic | how is memory managed? | an array has a fixed size (static); a linked list grows and shrinks (dynamic) |

The program below shows the last two rows with working code. An array of three cells cannot take a fourth item (it is static), whereas an `ArrayList` grows. An `int` array stores one type (homogeneous), whereas a `Student` object stores a text, an integer and a decimal number together (heterogeneous).

```java title="Student.java"
public class Student {
    String name;           // text
    int age;               // integer
    double gpa;            // decimal number

    Student(String name, int age, double gpa) {
        this.name = name;
        this.age = age;
        this.gpa = gpa;
    }
}
```

```java title="StructureKinds.java"
import java.util.ArrayList;

public class StructureKinds {
    // Question (Lecture 1): what is the difference between a static and a dynamic structure, and between a homogeneous and a heterogeneous one?
    public static void main(String[] args) {
        int[] fixed = new int[3];                       // static: 3 cells for ever
        fixed[0] = 10;
        fixed[1] = 20;
        fixed[2] = 30;
        try {
            fixed[3] = 40;                              // there is no fourth cell
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("array of 3: " + e.getClass().getName());
        }

        ArrayList<Integer> flexible = new ArrayList<Integer>();    // dynamic: grows when we add
        for (int i = 1; i <= 5; i++) {
            flexible.add(i * 10);
        }
        System.out.println("list: " + flexible + " size " + flexible.size());

        Student s = new Student("Kago", 20, 3.4);       // heterogeneous: three types in one structure
        System.out.println(s.name + " " + s.age + " " + s.gpa);
    }
}
```

```text
array of 3: java.lang.ArrayIndexOutOfBoundsException
list: [10, 20, 30, 40, 50] size 5
Kago 20 3.4
```

The array refuses the fourth value, the list accepts five, and the `Student` mixes three types, while `fixed` and `flexible` each hold values of one type only.

<Callout type="mistake" title="Common error">

Saying that an array is "dynamic" because it can be created with a size taken from a variable. The size is chosen once, when `new` runs, and cannot change afterwards. A dynamic structure, such as a linked list, changes its size as items are added and removed.

</Callout>

## 3. Common operations on a data structure

The lecture lists the activities that can be performed on a data structure: create it; add or insert an item; delete an item; modify, change or update an item; search (locate a specific item); sort (order the items); merge; and so on. The program below carries out each one on an array of capacity 8 that tracks how many cells are in use.

```java title="DataStructureOps.java"
public class DataStructureOps {
    static int[] data = new int[8];        // create: space for 8 items
    static int size = 0;                   // how many are in use

    static void add(int value) {           // add at the end
        data[size++] = value;
    }

    static void insert(int index, int value) {    // insert: shift the later items right
        for (int k = size; k > index; k--) {
            data[k] = data[k - 1];
        }
        data[index] = value;
        size++;
    }

    static void delete(int index) {        // delete: shift the later items left
        for (int k = index; k < size - 1; k++) {
            data[k] = data[k + 1];
        }
        size--;
    }

    static void modify(int index, int value) {    // modify: replace an item
        data[index] = value;
    }

    static int search(int value) {         // search: locate a specific item
        for (int k = 0; k < size; k++) {
            if (data[k] == value) {
                return k;
            }
        }
        return -1;
    }

    static void sort() {                   // sort: order the items
        java.util.Arrays.sort(data, 0, size);
    }

    static int[] merge(int[] a, int[] b) { // merge: combine two sorted arrays into one sorted array
        int[] out = new int[a.length + b.length];
        int i = 0;
        int j = 0;
        int k = 0;
        while (i < a.length && j < b.length) {
            out[k++] = (a[i] <= b[j]) ? a[i++] : b[j++];
        }
        while (i < a.length) {
            out[k++] = a[i++];
        }
        while (j < b.length) {
            out[k++] = b[j++];
        }
        return out;
    }

    static String show() {
        String s = "[";
        for (int k = 0; k < size; k++) {
            s = s + data[k] + (k < size - 1 ? ", " : "");
        }
        return s + "]";
    }

    public static void main(String[] args) {
        add(40);
        add(10);
        add(30);
        System.out.println("add 40, 10, 30:    " + show());
        insert(1, 25);
        System.out.println("insert 25 at 1:    " + show());
        delete(0);
        System.out.println("delete index 0:    " + show());
        modify(2, 99);
        System.out.println("modify index 2:    " + show());
        System.out.println("search 25: " + search(25) + ", search 7: " + search(7));
        sort();
        System.out.println("sort:              " + show());
        int[] merged = merge(new int[] {10, 25, 99}, new int[] {5, 15});
        System.out.println("merge with 5, 15:  " + java.util.Arrays.toString(merged));
    }
}
```

```text
add 40, 10, 30:    [40, 10, 30]
insert 25 at 1:    [40, 25, 10, 30]
delete index 0:    [25, 10, 30]
modify index 2:    [25, 10, 99]
search 25: 0, search 7: -1
sort:              [10, 25, 99]
merge with 5, 15:  [5, 10, 15, 25, 99]
```

What to notice. `insert` and `delete` move the items after the position; this is why they are expensive in an array and are one reason the course goes on to linked lists. `search` returns the index or -1. `merge` assumes both inputs are already sorted, and the result is sorted. The `size` counter is what separates the cells in use from the capacity: the array has 8 cells, but `show` prints only the first `size`.

<Callout type="mistake" title="Common error">

Inserting into a full array. When `size` equals the capacity, `insert` and `add` write past the last cell and fail with `ArrayIndexOutOfBoundsException`. A fixed-size structure needs a test for fullness, or a bigger copy.

</Callout>

### Exam question 1: classify the structures (6 marks)

Classify each of the following as primitive or non-primitive, linear or non-linear, and static or dynamic where that applies: an `int`, an array, a linked list, a stack, a tree. (6 marks)

<details>
<summary>Worked answer, with the reasoning</summary>

<Steps title="Answering the question">

<Step title="1. Read the question">

Five structures; for each, the three classifications the lecture gives. Primitive structures are not linear or non-linear, so the other two columns apply to the non-primitive ones.

</Step>

<Step title="2. Plan">

An `int` is a basic structure from first-year programming, so it is primitive. The other four are derived from primitives, so they are non-primitive. Then place each by its arrangement and memory management.

</Step>

<Step title="3. Solution">

| Structure | Primitive or not | Linear or non-linear | Static or dynamic |
|---|---|---|---|
| `int` | primitive | not applicable | not applicable |
| array | non-primitive | linear | static: the size is fixed when it is created |
| linked list | non-primitive | linear | dynamic: it grows and shrinks |
| stack | non-primitive | linear | depends on its implementation: an array stack is static, a linked stack is dynamic |
| tree | non-primitive | non-linear | dynamic: nodes are added and removed |

</Step>

<Step title="4. Check">

The array and linked list rows are the lecture's own example of static against dynamic ("array vs linked list"). The program `StructureKinds` showed the array refusing a fourth item and the list accepting five. A stack is the case where the answer depends on how it is built, which is a point the later chapters return to.

</Step>

</Steps>

</details>

### Exam question 2: carry out the operations (6 marks)

Start with an empty array structure of capacity 8. Apply these operations in order and show the contents after each: add 40, add 10, add 30, insert 25 at index 1, delete the item at index 0, modify index 2 to 99, sort. (6 marks)

<Step title="1. Read the question">

Seven operations and the contents after each. The index of an insert or delete refers to the contents at that moment.

## 4. Why study data structures, and where they are used

Data must be stored in memory and organised properly, for efficient storage and retrieval. The lecture lists the application areas:

| Area | Data structures used |
|---|---|
| Operating systems | process scheduling such as printing (queues), dynamic memory allocation (linked lists) |
| Graphics | arrays, linked lists, trees |
| Simulation | queues, heaps |
| The Internet | for example a stack for the Back button |
| Database management systems | indexing data items |
| Data analytics | storing and retrieving large collections |
| AI and machine learning | quick retrieval of items: arrays, linked lists, hash tables, trees |

## Summary

<Callout type="key" title="Remember">

Program = algorithm + data structure: the algorithm gives the steps, the data structure organises the data, and the choice of structure determines the performance. Data structures are primitive (integers, characters) or non-primitive (derived from them); non-primitive ones are classified as homogeneous or heterogeneous, linear (array, linked list, stack, queue) or non-linear (trees, hash maps, graphs), and static (an array) or dynamic (a linked list). The common operations are create, add or insert, delete, modify, search, sort and merge. An efficient structure gives easy storage, access and modification, quick access and low memory use.

</Callout>
