## 2. The structure of a program

A Java program is a collection of lines of code that solve a specific problem. It is saved as `className.java`, and `main` is the point of entry during execution.

## 3. Variables and the memory diagram

A variable is a placeholder for data in memory. It must be declared before use, with a unique name and a data type, which is a set of values with a set of permitted operations. There are two kinds of data type: **primitives** (`int` with `+`, `*`, `++`) and **reference types**, which are classes (`String` with `charAt()`, `length()`, `indexOf()`). **Declaration** allocates space for the type and gives it a name; **initialisation** gives the variable an initial value; `final` means the value must not change.

```java title="VariableKinds.java"
public class VariableKinds {
    // Question (Lecture 2): declare, initialise and use primitive and reference variables.
    public static void main(String[] args) {
        int x;                            // declaration
        x = 5;                            // initialisation (also an assignment)
        final int LIMIT = 10;             // a constant
        int y = x;                        // y gets a COPY of the value
        x = 7;
        String course = "CSI247";         // a reference variable
        String other = course;            // copies the ADDRESS
        System.out.println(x + " " + y + " " + LIMIT);
        System.out.println(course.length() + " " + (course == other));
    }
}
```

```text
7 5 10
6 true
```

Using a variable that was declared but never given a value. Local variables have no default value, so the compiler stops you with "might not have been initialized".

## 4. Operators

Operators process the data: assignment (`x = 17`, `x = x + 17`), arithmetic (`+ - * / %`), relational (`> >= <`), logical (`&& || !`) and increment or decrement (`++x`, `x--`). **The order of precedence is important.**

```java title="OperatorsDemo.java"
public class OperatorsDemo {
    // Question (Lecture 2): what do these expressions evaluate to?
    public static void main(String[] args) {
        System.out.println(17 / 5);                   // integer division
        System.out.println(17 % 5);                   // remainder
        System.out.println(17 / 5.0);                 // one double operand
        System.out.println(2 + 3 * 4);                // * before +
        System.out.println((2 + 3) * 4);              // brackets first

        int a = 5;
        int b = a++;                                  // use the value, then add 1
        int c = ++a;                                  // add 1, then use the value
        System.out.println(a + " " + b + " " + c);

        int x = 7;
        x += 4;                                       // x = x + 4
        System.out.println(x);
        System.out.println((4 > 7) + " " + (4 < 7 && !(x < 0)) + " " + (4 > 7 || x == 11));
    }
}
```

```text
3
2
3.4
14
20
7 5 7
11
false true true
```

`17 / 5` is 3 because both operands are `int`; one `double` operand gives 3.4. Multiplication binds tighter than addition, so `2 + 3 * 4` is 14, and brackets change that. `a++` gives the old value (5) and then increments, `++a` increments and then gives the new value: after both, `a` is 7, `b` is 5 and `c` is 7.

## 5. Selection and repetition

**Selection** statements are `if`, `if-else`, the multi-branch `if`, `switch` and nested `if`. **Repetition** statements are `for` and `while`; every loop has a condition, a body and an update statement. The lecture lists the loop errors: one too many or one too few iterations, an incorrect update, a missing update (an infinite loop), and nested loops.

```java title="SelectionDemo.java"
public class SelectionDemo {
    static String grade(int mark) {
        if (mark >= 75) {                       // multi-branch if: the first true branch only
            return "A";
        } else if (mark >= 60) {
            return "B";
        } else if (mark >= 50) {
            return "C";
        } else {
            return "F";
        }
    }

    static String dayType(int day) {
        String type = "";
        switch (day) {
            case 6:
            case 7:
                type = "weekend";
                break;                          // without break the next case also runs
            default:
                type = "weekday";
        }
        return type;
    }

    public static void main(String[] args) {
        System.out.println(grade(82) + " " + grade(60) + " " + grade(49));
        System.out.println(dayType(3) + " " + dayType(7));

        int x = 0;
        if (4 > 7) x += 4;                      // the lecture's if
        else x += 8;                            // and its else
        System.out.println(x);
    }
}
```

```text
A B F
weekday weekend
8
```

```java title="LoopErrors.java"
public class LoopErrors {
    // Question (Lecture 2): what goes wrong in each loop, and what is the sum?
    public static void main(String[] args) {
        int sum = 0;
        for (int i = 1; i <= 5; i++) {                 // correct: 5 iterations
            sum += i;
        }
        System.out.println("correct: " + sum);

        sum = 0;
        for (int i = 1; i <= 6; i++) {                 // one too many iterations
            sum += i;
        }
        System.out.println("one too many: " + sum);

        sum = 0;
        for (int i = 1; i < 5; i++) {                  // one too few iterations
            sum += i;
        }
        System.out.println("one too few: " + sum);

        sum = 0;
        for (int i = 1; i <= 5; i += 2) {              // incorrect update
            sum += i;
        }
        System.out.println("wrong update: " + sum);

        int i = 0;
        int passes = 0;
        while (i < 5 && passes < 8) {                  // missing update: i never changes; passes caps the demonstration
            passes++;
        }
        System.out.println("missing update: i is still " + i + " after " + passes + " passes");

        for (int row = 1; row <= 3; row++) {           // nested loops
            for (int col = 1; col <= row; col++) {
                System.out.print(row * col + " ");
            }
            System.out.println();
        }
    }
}
```

```text
correct: 15
one too many: 21
one too few: 10
wrong update: 9
missing update: i is still 0 after 8 passes
1
2 4
3 6 9
```

A loop with a missing update is an infinite loop: the demonstration adds a `passes` cap only so that it can stop. The nested loop prints a triangle because the inner loop depends on the outer counter.

<Callout type="mistake" title="Common error">

Forgetting `break` in a `switch`. Execution carries on into the next case. In `dayType`, `case 6` has no statements and falls through to `case 7`, which is what is wanted there, but a missing `break` after `type = "weekend"` would also run `default`.

</Callout>

## 6. Strings

Java has a class `String` with many methods for manipulating text. The lecture's four expressions use the string `"Computer Science"`:

```java title="StringSlide.java"
public class StringSlide {
    // Question (Lecture 2): what do these four statements do?
    public static void main(String[] args) {
        String dept = "Computer Science";

        System.out.println(dept.length() * 10);

        int x = dept.indexOf("scie");
        System.out.println(x);

        String st = dept.substring(9) + 7;
        System.out.println(st);

        try {
            char ch = dept.charAt(dept.length());      // the slide's statement
            System.out.println(ch);
        } catch (StringIndexOutOfBoundsException e) {
            System.out.println("charAt(length): " + e.getClass().getName());
        }

        System.out.println(dept.charAt(dept.length() - 1));
        System.out.println(dept.indexOf("Sci") + " " + dept.toLowerCase().indexOf("scie"));
    }
}
```

```text
160
-1
Science7
charAt(length): java.lang.StringIndexOutOfBoundsException
e
9 9
```

The string has 16 characters, so `length() * 10` is 160. `indexOf("scie")` is -1: the search is case-sensitive and the text has a capital `S`, so it is not found (it is found, at index 9, once the text is in lower case). `substring(9)` is "Science", and `+ 7` appends the digit. The slide's `charAt(dept.length())` fails at run time: the valid indexes are 0 to `length() - 1`, and `length()` is one past the last character.

<Callout type="mistake" title="Common error">

Using `charAt(s.length())` to get the last character. The last index is `s.length() - 1`; `s.length()` throws `StringIndexOutOfBoundsException`.

</Callout>

## 7. Classes, objects, methods and the API

Java is an OOP language: related methods are grouped into a class, a blueprint used to create objects (`Scanner scan = new Scanner(System.in);`). There are pre-defined classes, bundled with Java and documented at `https://docs.oracle.com/javase/8/docs/api/`, and user-defined ones. A method is written inside a class and has a name, a parameter list (zero or more, each with a type) and a return type (`void`, a primitive, or a class). `Scanner.nextInt()` takes no parameter and returns an `int`; `String.charAt()` takes an `int` and returns a `char`; `length()` takes none and returns an `int`.

When you invoke a method, you must provide the expected number of parameters, in the expected order, each of the expected type; if the method returns a value, you store it in a variable of a matching type.

| Call | Compiler message |
|---|---|
| `double r = cube();` for `cube(double length)` | `error: method cube in class Scope cannot be applied to given types;` (required: double; found: no arguments) |
| `double r = cube("2");` | `error: incompatible types: String cannot be converted to double` |
| `int r = cube(2);` for a `double` method | `error: incompatible types: possible lossy conversion from double to int` |

## 8. Keyboard input and output

`Scanner` reads the keyboard. The lecture's example asks for the number of pens and the unit price. The program below reads the same values from a `String` instead of the keyboard, so that it can run by itself; the keyboard form is `Scanner scan = new Scanner(System.in);`.

```java title="PensBill.java"
import java.util.Scanner;

public class PensBill {
    // Question (Lecture 2): read the number of pens and the unit price, and print the total.
    public static void main(String[] args) {
        Scanner scan = new Scanner("12 4.75");           // stands in for new Scanner(System.in)
        System.out.println("Enter number of pens needed: ");
        int pens = scan.nextInt();
        System.out.println("Enter unit price: ");
        double price = scan.nextDouble();
        System.out.printf("Total for %d pens at P%.2f: P%5.2f%n", pens, price, pens * price);
    }
}
```

```text
Enter number of pens needed:
Enter unit price:
Total for 12 pens at P4.75: P57.00
```

The three output methods: `print` leaves the cursor at the end of the displayed text; `println` moves the cursor to the start of the next line; `printf` uses format specifiers (`%s` a string, `%d` an integer, `%c` a character, `%5.2f` a decimal number in at least 5 places with 2 after the point, `%n` a new line).

```java title="OutputFormats.java"
public class OutputFormats {
    public static void main(String[] args) {
        System.out.print("one ");
        System.out.print("two");
        System.out.println();
        System.out.println("three");
        System.out.printf("[%s] [%d] [%c] [%5.2f] [%8.3f] [%-6d]%n", "text", 42, 'Q', 3.14159, 2.5, 7);
    }
}
```

```text
one two
three
[text] [42] [Q] [ 3.14] [   2.500] [7     ]
```

## 9. File input and output

To read a file you can use `FileReader` (or `File`) with a `Scanner`. To write, use `PrintWriter`. The notes of the lecture: an input file **must exist**, or `FileNotFoundException` is thrown; an output file that does not exist is created, and one that exists is **overwritten** by default; and you **must close** files when done. File operations are prone to problems such as a missing file, so the exceptions must be handled: with a `throws` clause, or with a `try-catch` block.

```java title="FileNotes.java"
import java.io.File;
import java.io.FileNotFoundException;
import java.io.FileReader;
import java.io.PrintWriter;
import java.util.Scanner;

public class FileNotes {
    static int countLines(File f) throws FileNotFoundException {
        Scanner scan = new Scanner(new FileReader(f));
        int lines = 0;
        while (scan.hasNextLine()) {
            scan.nextLine();
            lines++;
        }
        scan.close();
        return lines;
    }

    public static void main(String[] args) throws Exception {
        File f = File.createTempFile("notes", ".txt");
        f.deleteOnExit();

        PrintWriter pw = new PrintWriter(f);
        pw.printf("Practicing File output");
        // no pw.close() yet: the text may still be in a buffer
        System.out.println("without close: " + countLines(f) + " lines, " + f.length() + " bytes");
        pw.close();                                      // close writes the buffered text
        System.out.println("after close: " + countLines(f) + " lines, " + f.length() + " bytes");

        PrintWriter again = new PrintWriter(f);          // an existing file is overwritten
        again.println("first");
        again.println("second");
        again.close();
        System.out.println("rewritten: " + countLines(f) + " lines");

        try {
            countLines(new File("no-such-file.txt"));    // the input file must exist
        } catch (FileNotFoundException e) {
            System.out.println("missing file: " + e.getClass().getName());
        }
    }
}
```

```text
without close: 0 lines, 0 bytes
after close: 1 lines, 22 bytes
rewritten: 2 lines
missing file: java.io.FileNotFoundException
```

Without `close()` the text written by `printf` had not reached the file: it was still in the writer's buffer, so the file looked empty. After `close()` the file has its one line. Opening the same file again for output replaced the old contents with two lines. And a file that does not exist makes `new FileReader` throw `FileNotFoundException`, which the `try-catch` handled.

The compiler also forces the handling. The statement `FileReader fr = new FileReader("data.txt");` in a method that neither catches the exception nor declares it gives `error: unreported exception FileNotFoundException; must be caught or declared to be thrown`. The two repairs are `throws FileNotFoundException` on the method (as `countLines` has), or a `try-catch` around the call.

<Callout type="mistake" title="Common error">

Not closing an output file. The data stays in the buffer and the file is empty or incomplete. Always `close()` a `PrintWriter` when you have finished.

</Callout>

## Summary

<Callout type="key" title="Remember">

A program is `public class ClassName` with a `main` method, saved as `ClassName.java`. Variables are declared with a type, initialised before use, and are primitive (the box holds the value) or reference (the box holds an address); `final` forbids changes. Remember precedence, integer division and `a++` against `++a`. Selection uses `if`, `if-else`, multi-branch `if`, `switch` (with `break`) and nested `if`; repetition uses `for` and `while`, and the loop errors are one too many or too few iterations, a wrong or missing update, and nested loops. Strings are zero-indexed, `indexOf` is case-sensitive and `charAt(length())` fails. Read the keyboard with `Scanner`; output with `print`, `println` and `printf`. An input file must exist, an output file is overwritten, every file must be closed, and file exceptions are handled with `throws` or `try-catch`.

</Callout>

<CheckQuestion question="What is the difference between declaring and initialising a variable?">

Declaring allocates space for a data type and gives it a name (`int x;`). Initialising gives it its first value (`x = 5;`). A local variable must be initialised before it is used, or the compiler reports "might not have been initialized".

</CheckQuestion>

<CheckQuestion question="Why is 17 / 5 equal to 3, and what makes it 3.4?">

Both operands are `int`, so the division is integer division and drops the fraction. If one operand is a `double`, as in `17 / 5.0`, the result is a `double`, 3.4.

</CheckQuestion>

<CheckQuestion question="Why does searching for the lower-case text scie in Computer Science return -1?">

The search is case-sensitive and the string has a capital `S`. The method returns -1 when the text is not found; searching for "Sci", or for "scie" in the lower-case copy, finds index 9.

</CheckQuestion>

<CheckQuestion question="Why was the file empty before pw.close() was called?">

The `PrintWriter` keeps the text in a buffer. `close()` writes the buffered text to the file and releases it. Without it the data may never reach the file.

</CheckQuestion>

<CheckQuestion question="What are the two ways to deal with the FileNotFoundException of new FileReader?">

Declare it with a `throws` clause on the method, or catch it with a `try-catch` block around the statement. If neither is done the compiler reports "unreported exception FileNotFoundException; must be caught or declared to be thrown".

</CheckQuestion>

</CheckQuestions>
