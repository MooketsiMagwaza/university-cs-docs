## Question set

1. Refactor duplicated Circle and Rectangle state into an abstract Shape. Include UML. [16]
2. Trace constructor calls for <code>new Circle("Blue", 2)</code>, showing defaults, <code>super</code>, and final state. [10]
3. Given a mixed Shape array, identify reference/runtime types and every selected <code>getArea</code> body. [12]
4. Compare overriding and overloading with one legal example of each. [8]
5. Repair an Account class whose public balance permits invalid state. [10]
6. Implement and test a two-interface class. [12]

<Callout title="Marking standard">
Answers must show object state and evaluated dispatch decisions, not definitions alone. A design question earns implementation marks only when its class relationships, modifiers, constructors, and tests agree.
</Callout>
