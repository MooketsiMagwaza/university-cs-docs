Polymorphism lets one superclass/interface reference refer to different compatible runtime objects. An overridden instance-method call is selected from the runtime object's class.

## 1. Two types to track

~~~java
Shape item = new Circle("Blue", 2.0);
~~~

## 2. Override the same contract

~~~java
public class Circle extends Shape {
    // ... radius and constructor ...

    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }
}

public class Rectangle extends Shape {
    // ... width, height and constructor ...

    @Override
    public double getArea() {
        return width * height;
    }
}
~~~

## 3. Dynamic dispatch trace

~~~java
Shape[] shapes = {
    new Circle("Blue", 2.0),
    new Rectangle("Red", 3.0, 4.0)
};

for (Shape shape : shapes) {
    System.out.println(shape.getArea());
}
~~~

| Iteration | Reference type | Runtime type | Selected body | Result |
|---:|---|---|---|---:|
| 1 | Shape | Circle | <code>Circle.getArea</code> | about 12.57 |
| 2 | Shape | Rectangle | <code>Rectangle.getArea</code> | 12.0 |

No manual type test is needed; each object knows its behaviour.

## 4. Overriding versus overloading

| Feature | Overriding | Overloading |
|---|---|---|
| Relationship | subclass replaces inherited instance method | same class/name, different parameter lists |
| Selection | runtime object type | compile-time argument types |
| Signature | same compatible signature | different signatures |
| Annotation | <code>@Override</code> recommended | no override annotation |
| Common label | dynamic polymorphism | static/compile-time polymorphism |

## 5. Upcasting and downcasting

Assigning a Circle to Shape is an automatic upcast. A downcast asks Java to treat a general reference as a more specific type and can fail at runtime.

~~~java
Shape shape = new Circle("Blue", 2.0); // Safe upcast.

if (shape instanceof Circle circle) {
    System.out.println(circle.getRadius()); // Safe narrowed variable.
}
~~~

Do not downcast merely to call behaviour that should be declared in the common abstraction.

## 6. A polymorphic algorithm

~~~java
public static Shape larger(Shape first, Shape second) {
    // Each call dispatches to the runtime object's getArea implementation.
    if (first.getArea() >= second.getArea()) {
        return first;
    }
    return second;
}
~~~

The algorithm depends on the Shape contract, not on every concrete subclass. New Shape subclasses can participate without modifying this method.
