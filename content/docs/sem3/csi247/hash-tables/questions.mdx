title: Exam Practice
description: Hash-table insertion, lookup, deletion, collision and load-factor questions.

Given 7 buckets and index <code>hash % 7</code>, insert keys with hashes 10, 17, 4, 24, and 11 using separate chaining. Draw the complete table after each insertion. [15]

Then answer:

1. How many equality comparisons are needed to find the last key in each chain? [5]
2. What changes when an equal key is inserted with a new value? [4]
3. Why may unequal keys have equal hashes, but equal keys may not have unequal hashes? [6]
4. At what load factor would a given policy trigger resizing, and what work does resizing perform? [8]
5. Compare hash lookup with binary search: required ordering, expected cost, and worst-case caveats. [8]
