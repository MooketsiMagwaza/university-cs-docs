description: Hash-table revision sheet.
---

<code>key → hash → bucket → equals check → value</code>

- collisions are expected, not errors;
- equal keys must produce equal hashes;
- a good hash spreads likely keys;
- mutating a stored key's hash-relevant state breaks retrieval;
- expected lookup is O(1), but worst-case behaviour can degrade;
- resizing costs O(N) at that moment but happens occasionally.
