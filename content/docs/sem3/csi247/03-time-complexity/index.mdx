---
title: "Algorithm Analysis"
description: "Algorithm efficiency, runtime estimation, growth rates, and Big-O notation."
---

More than one algorithm can solve the same problem, so we compare how their running time grows as the input size N grows. This topic estimates that growth by counting primitive operations, then expresses it in Big-O notation so algorithms can be grouped by how well they scale.

<LearningObjectives items={[
  "Explain what time complexity measures and why it is stated in terms of the input size N",
  "Compare experimentation with methodological analysis as ways to compare algorithms",
  "Count primitive operations, and apply the counting rules for sequences, if/else, single loops, and nested loops",
  "Distinguish best, average, and worst cases",
  "Simplify a runtime expression to its dominant term and express it in Big-O notation",
  "Order the common orders of growth from O(1) to O(N!)",
]} />

<Prerequisites items={[
  "Loops, arrays, and methods in Java, from the Java Programming Recap topic",
]} />
