## The five checks

1. What concrete type replaces each type parameter?
2. Is every type argument a reference type, and are the types on both sides of `=` identical?
3. Does the code need a method that requires a bound (`compareTo`, `doubleValue`)?
4. Is the type parameter declared where it is used: after the class name, or before the method's return type?
5. Are objects compared with `equals`, and is no array created with `new T[n]`?
