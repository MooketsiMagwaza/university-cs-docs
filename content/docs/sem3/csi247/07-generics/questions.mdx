title: Exam Practice
description: Gradual generics questions from type substitution to bounded algorithms and PECS.
---

Attempt the questions in order. The first group checks whether the notation is readable; the last group asks you to design reusable code.

## A. Read the notation [20]

1. In <code>class Pair&lt;A, B&gt;</code>, distinguish formal parameters from the actual arguments in <code>Pair&lt;String, Integer&gt;</code>. [4]
2. Replace every occurrence of T in <code>Box&lt;T&gt;</code> when a <code>Box&lt;Book&gt;</code> is constructed. [4]
3. Explain why <code>List&lt;int&gt;</code> is illegal and show the wrapper form. [4]
4. Identify the runtime risk reintroduced by a raw <code>Box</code>. [4]
5. Explain why a static field cannot use a class type parameter. [4]

## B. Trace and diagnose [24]

1. Trace boxing and unboxing in <code>Box&lt;Integer&gt;</code>, including the result if the stored wrapper is null. [6]
2. Trace <code>max(List.of(7, 3, 11, 5))</code> for a method bounded by <code>Comparable&lt;T&gt;</code>. Show every comparison and current best. [8]
3. Explain why <code>List&lt;Integer&gt;</code> is not a subtype of <code>List&lt;Number&gt;</code>. Use the unsafe insertion that would otherwise become possible. [6]
4. State why <code>new T()</code> and <code>new T[10]</code> are unavailable in ordinary generic code. [4]

## C. Write reusable code [36]

1. Write a generic <code>Pair&lt;L, R&gt;</code> with constructor, getters, and <code>toString</code>. [10]
2. Write <code>&lt;T&gt; void swap(T[] data, int a, int b)</code> with bounds validation. [8]
3. Write a bounded method that returns the smaller of two Comparable values. [8]
4. Write <code>copy</code> using an extends source and super destination, then demonstrate copying Integer values into a Number list. [10]

<Accordions>
<Accordion title="Marking focus">

Full-credit answers connect every use of T to one relationship. Wildcard answers must state both the safe read type and the safe write type. “Because Java says so” does not explain invariance; show the value that could enter the wrong list.
