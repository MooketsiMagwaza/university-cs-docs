## 1. Placeholders used in every template on this page

| Placeholder | Meaning | Example |
|---|---|---|
| `T` | A type parameter: "some type, chosen when the object is created" | `GenTest<T>` |
| `E` | A type parameter naming an element | `<E> void printArray(E[] elements)` |
| `K`, `V` | Key and value types | `Lookup<K, V>` |
| `N` | A number type | `Nums<N extends Number>` |
| `Bound` | A type the parameter must extend | `Number`, `Comparable<T>` |

By convention one capital letter: `T` type, `E` element, `K` key, `N` number, `V` value.

## 2. A generic class

Generics allow one class, method or interface to work with different reference types. The advantages are **code reuse**, **type safety**, **no type casting** and **errors caught at compile time**.

```java
public class GenTest<T> {              // T is declared once, after the class name
    private T obj;                     // T: the type of the instance variable
    void modify(T obj) { this.obj = obj; }   // T: a parameter type
    T get() { return obj; }                  // T: a return type
}

GenTest<Integer> a = new GenTest<Integer>();   // read: "GenTest of Integer"
a.modify(17);                                  // accepts an Integer
```

Read a generic class by **substitution**: replace every `T` with the type argument. The rules for creating an object:

| Rule | Example |
|---|---|
| The type argument must be a **reference type** | `GenTest<Integer>`, never `GenTest<int>` |
| The types on both sides of `=` are identical | `GenTest<Integer> a = new GenTest<Integer>();` |
| Keep the `()` at the end | `new GenTest<Integer>()` |
| `T` cannot be used to allocate memory | `new T[20]` does not compile |

Two or more type parameters are separated by commas: `class Test<T, U>`.

## 3. Bounded types

`<T extends Number>` restricts `T` to `Number` and its subclasses (`Integer`, `Double`, `Float`, `Long`). The bound also lets the class call the methods of `Number` on a `T`. For an interface bound the keyword is still `extends`: `<T extends Comparable<T>>`.

## 4. A generic method

Put the type parameter in angle brackets **before the return type**. Its scope is that method. It works for static and non-static methods, and a method may also use the class's type parameter.

## 5. A generic interface

A generic interface takes a type parameter, and the class that implements it is generic too and passes the parameter on: `class GenC<T> implements GenI<T>`. A class that uses `T` without declaring it does not compile.

```java title="GenericsCheat.java"
public class GenericsCheat {
    static class Box<T> {
        private T item;

        void set(T item) {
            this.item = item;
        }

        T get() {
            return item;
        }
    }

    static class Nums<T extends Number> {
        private T value;

        Nums(T value) {
            this.value = value;
        }

        double twice() {
            return value.doubleValue() * 2;   // allowed: T is a Number
        }
    }

    interface GenI<T> {
        void modify(T val);

        T get();
    }

    static class GenC<T> implements GenI<T> {
        T val;

        public void modify(T val) {
            this.val = val;
        }

        public T get() {
            return val;
        }
    }

    static <E> void printArray(E[] elements) {
        for (E element : elements) {
            System.out.printf("%s ", element);
        }
        System.out.println();
    }

    static <T extends Comparable<T>> T larger(T a, T b) {
        return a.compareTo(b) >= 0 ? a : b;
    }

    public static void main(String[] args) {
        Box<String> box = new Box<String>();
        box.set("Kago");
        System.out.println(box.get().length());
        System.out.println(new Nums<Integer>(4).twice());
        GenC<Integer> n = new GenC<Integer>();
        n.modify(190);
        System.out.println("Num: " + n.get());
        printArray(new Integer[] {2, 4, 5});
        System.out.println(larger(3, 9) + " " + larger("pear", "apple"));
    }
}
```

```text
4
8.0
Num: 190
2 4 5
9 pear
```

## 6. What does not compile

| Statement | Compiler message |
|---|---|
| `a.modify("CSI247");` on a `GenTest<Integer>` | `incompatible types: String cannot be converted to Integer` |
| `GenTest<int> a;` | `unexpected type` (required: reference, found: int) |
| `GenTest<Integer> a = new GenTest<String>();` | `incompatible types: GenTest<String> cannot be converted to GenTest<Integer>` |
| `new GenTest<Integer>;` | `'(' or '[' expected` |
| `T[] arr = new T[20];` | `generic array creation` |
| `Nums<String>` when `T extends Number` | `type argument String is not within bounds of type-variable T` |
| `printArray(new int[] {1, 2})` | `method printArray ... cannot be applied to given types` (required `E[]`, found `int[]`) |
| `class G implements GenI<T>` without declaring `T` | `cannot find symbol` (symbol: class T) |
| `x.compareTo(y)` on an unbounded `T` | `cannot find symbol` (symbol: method compareTo(T)) |

## 7. Lab 7: the generic Set and Pair

| Class | Design | Key points |
|---|---|---|
| `Set<T>` | an array of 10 cells of type `T`, all `null` at first | `add` uses the **first empty cell** (duplicates allowed); `remove` uses `equals` and leaves a gap; `search` returns the first element equal to the argument |
| the array | `items = (T[]) new Object[10];` with `@SuppressWarnings("unchecked")` | `new T[10]` is rejected; the cast is unchecked |
| `Pair<T extends Number, U extends Number>` | two members, a getter and a setter for each | `add`, `subtract`, `multiply` and `divide` use `doubleValue()` and return a `Pair<Double, Double>`; `7 / 2` gives 3.5; dividing by zero gives `Infinity`, not an exception |

## 8. Common errors

| Mistake | What happens | Repair |
|---|---|---|
| `GenTest<int>` | unexpected type | `GenTest<Integer>` |
| Different type arguments on the two sides of `=` | incompatible types | make them identical |
| Calling `compareTo` or `doubleValue` on an unbounded `T` | cannot find symbol | add the bound: `<T extends Comparable<T>>`, `<T extends Number>` |
| `<E>` placed after the return type | illegal start of type | `public static <E> void method(...)` |
| `new T[n]` | generic array creation | `(T[]) new Object[n]` |
| Comparing generic values with `==` | compares addresses | use `equals` |
| A class that implements a generic interface does not declare `T` | cannot find symbol | `class C<T> implements I<T>` |
