Generics let a class, method, or interface describe a **relationship between types** without committing to one concrete reference type.

The simplest reading rule is:

> Replace every occurrence of the type parameter with the chosen type argument, then check whether the resulting operations make sense.

## Why this chapter is deliberately detailed

Generics combine several earlier ideas at once: reference types, inheritance, interfaces, method signatures, compile-time checking, and arrays/collections. The lessons therefore build one layer at a time.
