A **linear search** compares the search key with array elements one after another. It needs no preparation: the array may be sorted or unsorted.

This lesson uses one contract throughout:

```text
linearSearch(arr, key) returns the first index whose value equals key.
If no such index exists, it returns -1.
```

## 1. See the search before reading code

Linear search is the simplest search: start at the left and ask each card, **"Are you the key?"** Stop at the first **yes**. If every card says no, return `-1`.

## 2. Properties you should know

| Property | Linear search | Why |
|---|---|---|
| Required order | None | Each value is checked directly |
| Best-case time | `O(1)` | The first value matches |
| Worst-case time | `O(n)` | The key is last or absent |
| Extra space | `O(1)` | Only the loop index is stored |
| Duplicates | Returns the first match | The method stops immediately |

## 3. Iterative implementation

The loop index is both the current position and the value returned when a match is found.

```java
public static int linearSearch(int[] arr, int key) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == key) {
            return i;
        }
    }
    return -1;
}
```

Read it line by line:

1. `i` starts at the first valid index, `0`.
2. `i < arr.length` prevents an out-of-bounds access.
3. Equality returns immediately, so duplicate keys produce the **first** matching index.
4. Reaching the final `return -1` proves every valid index was checked without a match.

### Complete runnable example

```java
import java.util.Arrays;

public class LinearSearchDemo {
    public static int linearSearch(int[] arr, int key) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == key) {
                return i;
            }
        }
        return -1;
    }

    public static void main(String[] args) {
        int[] values = {63, 29, 85, 72, 18, 42, 23, 54, 8, 32};
        System.out.println(Arrays.toString(values));
        System.out.println("18 -> " + linearSearch(values, 18));
        System.out.println("31 -> " + linearSearch(values, 31));
    }
}
```

```text
[63, 29, 85, 72, 18, 42, 23, 54, 8, 32]
18 -> 4
31 -> -1
```

The program is deterministic: the shown output is the result of compiling and running this class.

## 4. Using sorted order for an early stop

Linear search does not *need* sorted data, but ascending order gives one extra fact. Once `arr[i]` is greater than the key, every later value is also too large.

```java
public static int orderedLinearSearch(int[] arr, int key) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == key) {
            return i;
        }
        if (arr[i] > key) {
            return -1;
        }
    }
    return -1;
}
```

On `[8, 18, 23, 29, 34, 42, 54, 63, 72, 85]`, a search for `31` checks `8`, `18`, `23`, `29`, then `34`. Because `34 > 31`, the method stops after five comparisons.

<CommonMistake title="Using the early stop on unsorted data">
The test `arr[i] > key` is valid only when the remaining values cannot become smaller again. On `[8, 40, 18]`, searching for `18` would stop incorrectly at `40`. Remove the early stop for unsorted data.
</CommonMistake>

## 5. Cost and boundaries

Let `n` be the number of elements in the array.

| Case | Comparisons | Time |
|---|---:|---:|
| Key at index 0 | 1 | `O(1)` best case |
| Key at index `k` | `k + 1` | `O(k + 1)` |
| Key at the final index | `n` | `O(n)` worst case |
| Key absent from an unsorted array | `n` | `O(n)` worst case |
| Empty array | 0 | `O(1)` |

The method uses only `i` in addition to its inputs, so its auxiliary space is `O(1)`.

## 6. Common errors

| Attempt | What happens | Repair |
|---|---|---|
| `i <= arr.length` | The last iteration tries `arr[arr.length]` and throws `ArrayIndexOutOfBoundsException` | Use `i < arr.length` |
| Return `-1` inside the loop after the first mismatch | Only index 0 is ever checked | Return `-1` after the loop |
| Return the value instead of `i` | The caller cannot tell where the key was found | Return the index promised by the contract |
| Use `==` to compare arbitrary objects | It compares references, not object content | Use an appropriate `equals` method |
| Forget that duplicates exist | The method's result is underspecified | State that this version returns the first match |
