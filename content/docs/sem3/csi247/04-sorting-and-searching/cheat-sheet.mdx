## 2. Searching (Lecture 8)

```text
Linear search:   for (int i = 0; i < arr.length; i++) { if (arr[i] == key) return i; }  return -1;
Binary search:   while (low <= high) { int mid = low + (high - low) / 2;
                     if (arr[mid] < key) low = mid + 1; else if (arr[mid] > key) high = mid - 1; else return mid; }  return -1;
```

| | Linear search | Binary search |
|---|---|---|
| Requires | nothing (ordered or unordered) | a sorted array |
| Idea | compare the key with each element in turn | compare with the middle element, keep the half that can hold the key |
| Returns | the index, or -1 | the index, or -1 |
| Best case | O(1): index 0 | O(1): the middle element |
| Average case | O(n) | O(log n) |
| Worst case | O(n): the last element or absent | O(log n) |
| Use for | small collections, unsorted data | large sorted data with random access (arrays) |
| Recursive form | `i == arr.length` returns -1; `arr[i] == key` returns `i`; else call with `i + 1` | `low > high` returns -1; equal returns `mid`; else call with `mid + 1, high` or `low, mid - 1` |

Counts to remember: in `63 29 85 72 18 42 23 54 8 32`, key 18 takes 5 comparisons and 31 takes 10; in the ordered `8 18 23 29 34 42 54 63 72 85`, 18 takes 2 and 31 takes 5 with the early stop. For binary search on the ordered array, key 18 takes 2 passes (mid 4 then mid 1), key 31 takes 4 and returns -1. Binary search on an unsorted array silently gives wrong answers.

## 3. Sorting (Lecture 9)

```text
Swap:        int temp = arr[a]; arr[a] = arr[b]; arr[b] = temp;
Bubble:      for i: for (j = 0; j < arr.length - 1; j++) if (arr[j] > arr[j + 1]) swap arr[j], arr[j + 1]
Insertion:   for (i = 1; i < arr.length; i++) { temp = arr[i]; j = i;
                 while (j > 0 && temp < arr[j - 1]) { arr[j] = arr[j - 1]; j--; }  arr[j] = temp; }
Selection:   for (i = 0; i < arr.length - 1; i++) { minIndex = i;
                 for (j = i + 1; j < arr.length; j++) if (arr[j] < arr[minIndex]) minIndex = j;
                 swap arr[minIndex], arr[i]; }
Merge sort:  if (start < end) { mid = (start + end) / 2; mergeSort(arr, start, mid); mergeSort(arr, mid + 1, end); merge(arr, start, mid, end); }
merge:       size1 = m - s + 1; size2 = e - m; copy arr[s..m] to left, arr[m+1..e] to right;
             while (i < size1 && j < size2) arr[cur++] = (left[i] <= right[j]) ? left[i++] : right[j++];  then copy the rest
```

| Algorithm | Time | What a pass does | Telling sign in the passes |
|---|---|---|---|
| Bubble | O(n²) | compare adjacent items, swap those out of order | the largest unsorted value reaches the end in every pass; many neighbours change |
| Insertion | O(n²), a little better | insert the next item into the sorted prefix, moving larger items right | a sorted prefix grows by one item; the rest is untouched |
| Selection | O(n²) | find the smallest unsorted value, swap it into position `i` | the smallest value jumps to the front; at most `n - 1` swaps |
| Merge | O(n log n) | divide into halves, sort each, merge | recursive; `n - 1` merges for `n` items; extra memory |

Counts: for 5 items the lecture's bubble sort makes 20 comparisons (n passes of n - 1) even on a sorted array, selection sort makes 10 whatever the order, and insertion sort ranges from 0 moves (sorted) to 10 (reverse). Insertion sort suits few items and nearly sorted lists; merge sort suits large lists.

```java title="SearchSortCheat.java"
import java.util.Arrays;

public class SearchSortCheat {
    static int linearSearch(int[] arr, int key) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == key) return i;
        }
        return -1;
    }

    static int binarySearch(int[] arr, int key, int low, int high) {
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (arr[mid] < key) low = mid + 1;
            else if (arr[mid] > key) high = mid - 1;
            else return mid;
        }
        return -1;
    }

    static void bubbleSort(int[] arr) {
        for (int i = 0; i < arr.length; i++) {
            for (int j = 0; j < arr.length - 1; j++) {
                if (arr[j] > arr[j + 1]) {
                    int t = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = t;
                }
            }
        }
    }

    static void insertionSort(int[] arr) {
        for (int i = 1; i < arr.length; i++) {
            int temp = arr[i];
            int j = i;
            while (j > 0 && temp < arr[j - 1]) {
                arr[j] = arr[j - 1];
                j--;
            }
            arr[j] = temp;
        }
    }

    static void selectionSort(int[] arr) {
        for (int i = 0; i < arr.length - 1; i++) {
            int minIndex = i;
            for (int j = i + 1; j < arr.length; j++) {
                if (arr[j] < arr[minIndex]) minIndex = j;
            }
            int t = arr[minIndex]; arr[minIndex] = arr[i]; arr[i] = t;
        }
    }

    static void merge(int[] arr, int s, int m, int e) {
        int[] left = Arrays.copyOfRange(arr, s, m + 1);
        int[] right = Arrays.copyOfRange(arr, m + 1, e + 1);
        int i = 0, j = 0, cur = s;
        while (i < left.length && j < right.length) {
            arr[cur++] = (left[i] <= right[j]) ? left[i++] : right[j++];
        }
        while (i < left.length) arr[cur++] = left[i++];
        while (j < right.length) arr[cur++] = right[j++];
    }

    static void mergeSort(int[] arr, int start, int end) {
        if (start < end) {
            int mid = (start + end) / 2;
            mergeSort(arr, start, mid);
            mergeSort(arr, mid + 1, end);
            merge(arr, start, mid, end);
        }
    }

    public static void main(String[] args) {
        int[] data = {63, 29, 72, 85, 18, 49, 3, 54};
        System.out.println("linear 18 -> " + linearSearch(data, 18) + ", linear 31 -> " + linearSearch(data, 31));

        int[] b = data.clone(), ins = data.clone(), sel = data.clone(), mer = data.clone();
        bubbleSort(b);
        insertionSort(ins);
        selectionSort(sel);
        mergeSort(mer, 0, mer.length - 1);
        System.out.println("sorted " + Arrays.toString(mer));
        System.out.println("all four agree: " + (Arrays.equals(b, ins) && Arrays.equals(ins, sel) && Arrays.equals(sel, mer)));
        System.out.println("binary 54 -> " + binarySearch(mer, 54, 0, mer.length - 1) + ", binary 31 -> " + binarySearch(mer, 31, 0, mer.length - 1));
    }
}
```

```text
linear 18 -> 4, linear 31 -> -1
sorted [3, 18, 29, 49, 54, 63, 72, 85]
all four agree: true
binary 54 -> 4, binary 31 -> -1
```

## 5. Common errors

| Mistake | What happens | Repair |
|---|---|---|
| binary search on an unsorted array | -1 for keys that are present | sort first |
| `while (low < high)` | a key in the last cell is never compared | `low <= high` |
| `high = arr.length` | `ArrayIndexOutOfBoundsException` | `arr.length - 1` |
| `low = mid` or `high = mid` | the search space may not shrink; an endless loop | `mid + 1` and `mid - 1` |
| bubble sort inner loop `j < arr.length` | `ArrayIndexOutOfBoundsException` on `arr[j + 1]` | `j < arr.length - 1` |
| insertion sort `while (temp < arr[j - 1])` without `j > 0` | `ArrayIndexOutOfBoundsException` at `arr[-1]` | test `j > 0` first |
| `arr[j] = arr[j-1] )` on the insertion sort slide | `error: ';' expected` | end the statement with `;` |
| merging without copying the halves | values are overwritten before they are read | copy into `left` and `right` first |
| a merge sort split `mergeSort(arr, start, mid - 1)` and `(arr, mid, end)` | an item is skipped or the recursion never ends | `start..mid` and `mid + 1..end` |
| counting the early stop of ordered linear search for a present key | wrong comparison count | the early stop helps only for an absent key |
