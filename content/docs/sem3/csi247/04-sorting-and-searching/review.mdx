## The five checks

1. Is the array sorted, if the algorithm is binary search, and is `low <= high` the loop condition?
2. Does the search space shrink every pass (`mid + 1`, `mid - 1`), and what is the answer when it is empty (-1)?
3. For a sort, have I written the whole array after every pass, and does the last pass leave it sorted?
4. Which algorithm do the passes show: neighbours swapped and the largest value at the end (bubble), a sorted prefix that grows (insertion), or the smallest value swapped to the front (selection)?
5. For merge sort, have I shown the divisions first and then the merges, and are the two halves sorted before each merge?
