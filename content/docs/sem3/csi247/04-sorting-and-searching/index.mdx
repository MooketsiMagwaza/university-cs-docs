Searching answers **where is the value?** Sorting rearranges values so later work - especially binary search - becomes easier. The algorithms in this chapter are small enough to trace by hand and different enough to make time, space, stability, and preconditions concrete.

<LearningObjectives items={[

  "Show every pass of bubble, selection, and insertion sort",
  "Draw the split and merge stages of merge sort",
  "Explain best- and worst-case time, auxiliary space, stability, and adaptiveness",
  "Choose an algorithm for a stated scenario and justify the choice",

## Key ideas

Each lesson contains its own visual trace so that the animation, vocabulary, trace table, and Java method stay together. Predict the next state before revealing it. Every implementation here uses Java 8-compatible syntax and was checked with `javac --release 8` on JDK 21.

<Checklist title="Rules that control the whole chapter" rules={[
  { type: 'must', text: 'Binary search requires the searched range to be sorted in the same order used by its comparisons.' },
  { type: 'must', text: 'A trace records the array after each pass or the search bounds after each probe.' },
  { type: 'must', text: 'Complexity states which case is being described and what n means.' },
  { type: 'note', text: 'Bubble, selection, insertion, and merge sort can all produce the same order, but they reach it with different costs and properties.' },
