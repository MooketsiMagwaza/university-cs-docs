Six questions, grouped by what they test, each with its marks. Draw the memory before you open a solution. The lessons that teach each form are [The LinkedList Class by Example](/docs/sem3/csi247/09-linked-lists-traversals/notes/linked-list-methods-by-example) and [Linked List Exam Practice](/docs/sem3/csi247/09-linked-lists-traversals/notes/linked-list-exam-practice), which has nine more.

**Marking guide.** A diagram receives full credit only when `head` is on the stack, every node has an address and a `next` field, `null` is written in the last node, changed values are crossed out and unreachable nodes are marked as garbage. A method answer must handle the empty list, a list of one node, the first position and the last position.
