A linked list stores each element in a node, and references between nodes give the list its order. This topic replaces the array picture with nodes and links, then traces insertion at the front, traversal and search, and removal. It finishes by comparing the list variants and the cost of each operation.

<LearningObjectives items={[
  "Draw a linked list as nodes joined by references, and contrast it with the array model",
  "Write a generic Node class and a singly linked list class in Java",
  "Trace insertion at the front, keeping the old head reference inside the new node before replacing head",
  "Traverse and search a list with a current reference",
  "Remove the first occurrence of a value, handling the head separately",
  "Compare singly linked, doubly linked, and circular lists, and state the cost of common operations",
]} />
