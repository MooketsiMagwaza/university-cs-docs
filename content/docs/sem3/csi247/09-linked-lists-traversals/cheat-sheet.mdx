## 2. The node and the list

A linked list stores its elements in separate **nodes**. The list object keeps one reference, `head`. A node stores a data item and a reference `next` to the following node; the last node's `next` is `null`. The lecture writes the node as an **inner class** of the list class.

```java
public class LinkedList {
    private class Node {                 // inner class
        int data;                        // the node's data part
        Node next;                       // a link to the next node
        Node(int data) {
            this.data = data;
            this.next = null;            // assumption: the last node
        }
    }

    public Node head;                    // keeps track of the first node

    public LinkedList() {
        head = null;                     // initially no node
    }

    public boolean isEmpty() {
        return head == null;
    }
}
```

An empty list has `head == null`. A list of one node has `head.next == null`.

## 3. Adding a node

**Order matters.** Always link the new node to the rest of the list **first**, then move the arrow that reaches it. Doing it the other way round loses the rest of the list.

| Where | Steps (in this order) | Cost |
|---|---|---|
| At the front | `n.next = head;` then `head = n;` | O(1) |
| At the end | if the list is empty `head = n;`, otherwise walk to the last node (`cur.next == null`), then `cur.next = n;` | O(n) |
| At index `i` | walk to the node **before** the position, then `n.next = cur.next;` and `cur.next = n;` | O(1) at index 0, O(n) otherwise |
| Into an empty list | `head = n;` | O(1) |

## 4. Removing a node

| Which | Steps | Cost |
|---|---|---|
| The first node | `head = head.next;` (the old node is isolated; the garbage collector reclaims it) | O(1) |
| The last node | walk until `cur.next.next == null`, then `cur.next = null;` | O(n) |
| The node at index `i` | walk to the node **before** the position, then `cur.next = cur.next.next;` | O(1) at index 0, O(n) otherwise |

Special cases to test every time: the **empty list** (nothing to remove), a list of **one node** (`removeLast` sets `head = null`, because there is no second-last node), the **first** position and the **last** position.

```java title="ListMethods.java"
public class ListMethods {
    static class Node {
        int data;
        Node next;

        Node(int data) {
            this.data = data;
        }
    }

    static Node head;

    static void addFront(int data) {
        Node n = new Node(data);
        n.next = head;                        // 1. the new node points at the old first node
        head = n;                             // 2. head points at the new node
    }

    static void addLast(int data) {
        Node n = new Node(data);
        if (head == null) {
            head = n;                         // empty list: the new node is the list
            return;
        }
        Node cur = head;
        while (cur.next != null) {            // stop ON the last node
            cur = cur.next;
        }
        cur.next = n;
    }

    static void add(int i, int data) {        // the new node ends up at index i
        if (i == 0) {
            addFront(data);
            return;
        }
        Node cur = head;
        for (int k = 1; k < i; k++) {         // stop at the node before position i
            cur = cur.next;
        }
        Node n = new Node(data);
        n.next = cur.next;                    // 1. the new node takes over the rest
        cur.next = n;                         // 2. the node before points at the new node
    }

    static void removeFront() {
        head = head.next;
    }

    static void removeLast() {
        if (head.next == null) {
            head = null;                      // one node: the list becomes empty
            return;
        }
        Node cur = head;
        while (cur.next.next != null) {       // stop at the second-last node
            cur = cur.next;
        }
        cur.next = null;
    }

    static void remove(int i) {
        if (i == 0) {
            removeFront();
            return;
        }
        Node cur = head;
        for (int k = 1; k < i; k++) {         // stop at the node before position i
            cur = cur.next;
        }
        cur.next = cur.next.next;             // bypass the node
    }

    static boolean contains(int data) {
        Node tmp = head;
        while (tmp != null) {                 // visit every node, including the last
            if (tmp.data == data) {
                return true;
            }
            tmp = tmp.next;
        }
        return false;
    }

    static int size() {
        int count = 0;
        for (Node cur = head; cur != null; cur = cur.next) {
            count++;
        }
        return count;
    }

    static String show() {
        StringBuilder sb = new StringBuilder("[");
        for (Node cur = head; cur != null; cur = cur.next) {
            sb.append(cur.data);
            if (cur.next != null) {
                sb.append(", ");
            }
        }
        return sb.append("]").toString();
    }

    public static void main(String[] args) {
        addLast(6);
        addLast(3);
        addLast(9);
        System.out.println(show() + " size " + size());
        addFront(7);
        System.out.println("addFront(7): " + show());
        add(1, 5);
        System.out.println("add(1, 5): " + show());
        removeFront();
        System.out.println("removeFront: " + show());
        removeLast();
        System.out.println("removeLast: " + show());
        remove(1);
        System.out.println("remove(1): " + show());
        System.out.println("contains(3): " + contains(3) + ", contains(9): " + contains(9));
    }
}
```

```text
[6, 3, 9] size 3
addFront(7): [7, 6, 3, 9]
add(1, 5): [7, 5, 6, 3, 9]
removeFront: [5, 6, 3, 9]
removeLast: [5, 6, 3]
remove(1): [5, 3]
contains(3): true, contains(9): false
```

## 5. Traversal and contains

```java
// visit every node
for (Node cur = head; cur != null; cur = cur.next) {
    // use cur.data
}

// stop ON the last node (to append)
Node cur = head;
while (cur.next != null) {
    cur = cur.next;
}
```

Test `cur != null` to visit every node, and `cur.next != null` to stop on the last one. Using `cur.next` when `cur` can be `null` throws a `NullPointerException`. The lecture's `contains` loops `while (tmp.next != null)`, which never compares the last node and fails on an empty list; the loop must be `while (tmp != null)`.

## 6. The three types of linked list, and linked list against array

| Type | Each node has | The last node |
|---|---|---|
| Singly linked | one link: `next` | `next` is `null` |
| Doubly linked | two links: `prev` and `next` | `next` is `null` |
| Circular | `next` (and `prev` if doubly linked) | links back to the first node |

| | Array / `ArrayList` | Linked list |
|---|---|---|
| Access to an element | direct: `arr[i]`, `get(i)` | none: follow `next` from `head` (sequential) |
| Size | fixed (array) or resized (`ArrayList`) | dynamic: grows and shrinks as needed |
| Insert or remove | items are shifted | only references change; no shifting |

## 7. Time complexity (pointer moves counted for a list of `n` nodes)

| Method | Pointer moves | Best | Worst |
|---|---|---|---|
| `addFront`, `removeFront` | 0 | O(1) | O(1) |
| `addLast` | `n - 1` | O(n) | O(n) |
| `add(i)`, `remove(i)` | about `i - 1` | O(1) at index 0 | O(n) |
| `removeLast` | `n - 2` | O(n) | O(n) |
| `contains` | 0 to `n` | O(1) | O(n) |
| `size` | `n` | O(n) | O(n) |

## 8. Common errors

| Mistake | What happens | Repair |
|---|---|---|
| Moving `head` before linking the new node | the old list is lost | `n.next = head;` first, then `head = n;` |
| Linking `cur.next = n` before `n.next = cur.next` | the rest of the list is lost | take over the rest first |
| Using `cur.next` when `cur` is `null` | `NullPointerException` | test `cur != null` first |
| `while (tmp.next != null)` in `contains` | the last node is never compared | `while (tmp != null)` |
| `removeLast` on a list of one node | `NullPointerException` on `cur.next.next` | `head = null` for one node |
| Forgetting the empty list | `NullPointerException` on `head.next` | test `head == null` first |
| Standing on the node to remove | no way back to the node in front of it | stop one node earlier |
| `if (head = null)` | `error: incompatible types: Node cannot be converted to boolean` | compare with `==` |
| A declaration as the only statement of an `if` | `error: variable declaration not allowed here` | add braces |
