## What this runner is for

- short, single-file CSI247 programs;
- arrays, loops, methods, recursion, classes, and common standard-library imports;
- checking a trace after you have completed it on paper;
- experimenting with boundary cases such as an empty array, one element, duplicates, and an absent key.

The editor compiles a source file named `Main.java`, so keep one `public class Main`. It runs locally in isolated Web Workers using a WebAssembly Java compiler. Your source is not uploaded.

<Callout type="info" title="First run and Java scope">
The first run loads about 6.7 MB of compiler and class-library data, then the browser can cache it. This is a teaching runner rather than a complete desktop JDK: console programs work, while file access, networking, threads, reflection-heavy code, and multi-file package projects belong in your local `src` and `classes` folders.
</Callout>

## A productive practice loop

1. Pick an example and read the method contract.
2. Write the expected output or trace table before running.
3. Run once and reconcile every difference.
4. Change one input or condition.
5. Predict again before the next run.

For user-defined packages, continue with [Compiling and Running Packages](/docs/sem3/csi247/packages/notes/compiling-and-running), because package layout is deliberately a multi-file terminal exercise.
