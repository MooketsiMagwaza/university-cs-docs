## 1. Enhanced for: read every element

~~~java
for (Book book : books) {
    System.out.println(book.getTitle());
}
~~~

Use this when you do not need an index and do not structurally modify the collection.

## 2. Iterator: controlled removal

~~~java
Iterator<Book> cursor = books.iterator();
while (cursor.hasNext()) {
    Book current = cursor.next();
    if (current.isArchived()) {
        cursor.remove(); // Removes the item returned by next().
    }
}
~~~

| Step | cursor call | current | collection after |
|---:|---|---|---|
| 1 | next | active A | [A, archived B, C] |
| 2 | next, remove | archived B | [A, C] |
| 3 | next | active C | [A, C] |

Removing directly from <code>books</code> during for-each can cause <code>ConcurrentModificationException</code>.

## 3. Sorting and algorithms

~~~java
Collections.sort(names); // Natural String order.
books.sort(Comparator.comparing(Book::getTitle));
books.sort(Comparator.comparingDouble(Book::getPrice).reversed());

Collections.reverse(names);
String smallest = Collections.min(names);
int position = Collections.binarySearch(names, "Mpho"); // Must be sorted.
~~~

Natural ordering belongs to <code>Comparable&lt;T&gt;</code>. Alternative ordering is supplied by <code>Comparator&lt;T&gt;</code>.
