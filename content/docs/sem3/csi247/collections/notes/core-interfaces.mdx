## 2. List: sequence with positions

~~~java
List<String> numbers = new ArrayList<>();
numbers.add("A12");
numbers.add("A12"); // Duplicate allowed.
numbers.add(1, "B04");
String second = numbers.get(1); // B04
~~~

## 3. Set: membership without duplicates

~~~java
Set<String> codes = new HashSet<>();
codes.add("CSI247");
boolean addedAgain = codes.add("CSI247"); // false
~~~

A HashSet does not promise insertion order. A TreeSet keeps sorted order.

## 4. Queue: process by removal policy

~~~java
Queue<String> jobs = new ArrayDeque<>();
jobs.offer("notes.pdf");
jobs.offer("quiz.pdf");
String next = jobs.peek(); // inspect notes.pdf
String done = jobs.poll(); // remove notes.pdf
~~~

## 5. Map: key to value

~~~java
Map<String, Integer> marks = new HashMap<>();
marks.put("Nido", 78);
marks.put("Ava", 84);
marks.put("Nido", 81); // Replaces old value for this key.
Integer mark = marks.get("Nido");
~~~

## 6. Selection table

| Requirement | Start with |
|---|---|
| preserve sequence and duplicates | List |
| membership with uniqueness | Set |
| FIFO processing | Queue |
| retrieve a value using a key | Map |
| sorted unique elements | TreeSet |
| sorted keys | TreeMap |
