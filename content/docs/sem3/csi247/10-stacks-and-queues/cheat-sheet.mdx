## 1. The rule of each structure

| Structure | Rule | Add | Remove | Look without removing |
|---|---|---|---|---|
| Stack | last in, first out (LIFO) | `push(x)` at the top | `pop()` from the top | `peek()` |
| Queue | first in, first out (FIFO) | `enqueue(x)` at the tail (Java: `add(x)`) | `dequeue()` from the front (Java: `remove()`) | `peek()` |
| Double-ended queue (deque) | both ends | at the front or the tail | from the front or the tail | |
| Circular queue | FIFO, the last element is connected to the first | | | |
| Priority queue | the item with the lowest (or highest) key is always in front | `add(x)` keeps the order | `remove()` takes the front | `peek()` |

Both the lecture's stack and queue also have `size()`, `isEmpty()` and (for arrays) `isFull()`; the queue has `contains()`. Never remove or peek on an empty structure, and never add to a full array structure.

## 2. Java's Stack and Queue

`java.util.Stack<E>` has `push`, `pop`, `peek` and `empty`. `Queue<E>` is an **interface** (it extends `Collection<E>`), so create an object of a class that implements it: `LinkedList`, `PriorityQueue` or `ArrayDeque`. `remove()` throws an exception on an empty queue; `peek()` returns `null`.

```java title="StackQueueBasics.java"
import java.util.LinkedList;
import java.util.PriorityQueue;
import java.util.Queue;
import java.util.Stack;

public class StackQueueBasics {
    public static void main(String[] args) {
        Stack<String> stack = new Stack<String>();
        stack.push("a");
        stack.push("b");
        stack.push("c");
        System.out.println("stack pop order: " + stack.pop() + stack.pop() + stack.pop());

        Queue<String> queue = new LinkedList<String>();
        queue.add("a");
        queue.add("b");
        queue.add("c");
        System.out.println("queue remove order: " + queue.remove() + queue.remove() + queue.remove());

        Queue<Integer> pq = new PriorityQueue<Integer>();
        pq.add(40);
        pq.add(10);
        pq.add(30);
        System.out.println("priority order: " + pq.remove() + " " + pq.remove() + " " + pq.remove());
    }
}
```

```text
stack pop order: cba
queue remove order: abc
priority order: 10 30 40
```

## 3. Tracing: write the contents after every operation

Write the structure **left = bottom/front, right = top/tail** and keep the same convention throughout.

| Operation | Stack (bottom to top) | Returned |
|---|---|---|
| `push(7)` | 7 | |
| `push(2)` | 7 2 | |
| `push(9)` | 7 2 9 | |
| `pop()` | 7 2 | 9 |
| `peek()` | 7 2 | 2 |
| `pop()` | 7 | 2 |

| Operation | Queue (front to tail) | Returned |
|---|---|---|
| `enqueue(7)` | 7 | |
| `enqueue(2)` | 7 2 | |
| `enqueue(9)` | 7 2 9 | |
| `dequeue()` | 2 9 | 7 |
| `peek()` | 2 9 | 2 |
| `dequeue()` | 9 | 2 |

Consecutive pops return the elements in the reverse order of the pushes; dequeues return them in the order they were enqueued.

## 4. The array stack: `top` is an index

| Stack status | `top` |
|---|---|
| Empty | -1 |
| Has 1 element | 0 |
| Full (has N elements) | N - 1 |
| Overflow | N |

```java
public Stack1(int n) { stack = new Integer[n]; top = -1; }
public boolean isEmpty() { return top == -1; }
public int size()        { return top + 1; }
public boolean isFull()  { return top == stack.length - 1; }
public boolean push(Integer num) { if (isFull()) { /* overflow */ return false; } stack[++top] = num; return true; }
public Integer pop()     { if (!isEmpty()) { return stack[top--]; } /* underflow */ return null; }
public Integer peek()    { return isEmpty() ? null : stack[top]; }
```

`push` raises `top` and then stores; `pop` returns the element and then lowers `top`. The slot is not cleared, and the next push overwrites it.

## 5. The linked stack: `top` is a reference

Nodes are added and removed at the **front** of a linked list. There is no capacity, so no `isFull()`.

```java
public Stack2() { top = null; }
public boolean isEmpty() { return top == null; }
public void push(String data) { Node n = new Node(data); n.next = top; top = n; }
public String pop() { if (isEmpty()) return null; String data = top.data; top = top.next; return data; }
```

## 6. The linked queue: `front` and `tail` are references

```java
public void enqueue(String data) {
    Node oldTail = tail;
    tail = new Node(data);
    if (isEmpty()) front = tail;          // the first node is also the front
    else oldTail.next = tail;
}
public String dequeue() {
    if (isEmpty()) return null;
    String data = front.data;
    front = front.next;
    if (isEmpty()) tail = null;           // the queue became empty
    return data;
}
```

## 7. The array queue: `front` and `tail` are indexes

| Rule | Detail |
|---|---|
| Empty queue | `front = -1`, `tail = -1` |
| First `enqueue` | `front = tail = 0`, then store |
| Later `enqueue` | `tail++`, then store |
| `dequeue` | return `queue[front]`, then `front++`; the array slot is not cleared |
| `size()` | 0 if `front < 0`, otherwise `tail - front + 1` |
| Empty again | `front` is one past `tail`; the next `enqueue` resets both to 0 |

```java title="ArrayStructures.java"
public class ArrayStructures {
    static int[] stack = new int[3];
    static int top = -1;

    static boolean push(int value) {
        if (top == stack.length - 1) {
            return false;                     // full: overflow
        }
        stack[++top] = value;
        return true;
    }

    static Integer pop() {
        if (top == -1) {
            return null;                      // empty: underflow
        }
        return stack[top--];
    }

    static int[] queue = new int[3];
    static int front = -1;
    static int tail = -1;

    static int size() {
        return front < 0 ? 0 : tail - front + 1;
    }

    static boolean enqueue(int value) {
        if (size() == queue.length) {
            return false;                     // full
        }
        if (size() == 0) {
            front = tail = 0;
        } else {
            tail++;
        }
        queue[tail] = value;
        return true;
    }

    static Integer dequeue() {
        if (size() == 0) {
            return null;
        }
        return queue[front++];
    }

    public static void main(String[] args) {
        System.out.println(push(5) + " " + push(8) + " " + push(2) + " " + push(9));
        System.out.println(pop() + " " + pop() + ", top " + top);
        System.out.println(enqueue(5) + " " + enqueue(8) + " " + enqueue(2) + " " + enqueue(9));
        System.out.println(dequeue() + " " + dequeue() + ", front " + front + ", tail " + tail + ", size " + size());
    }
}
```

```text
true true true false
2 8, top 0
true true true false
5 8, front 2, tail 2, size 1
```

**The array queue can overflow with free slots.** `front` and `tail` only move forwards, so when `tail` is the last index the next `enqueue` stores outside the array (`ArrayIndexOutOfBoundsException`) even though slots in front of `front` are free. Test `tail == queue.length - 1` before an `enqueue`, or use a circular queue, in which the last element is connected to the first.

## 8. Application areas the lectures list

| Structure | Applications |
|---|---|
| Stack | recursion and method calls, undo in a text editor, the Back button of a web browser, evaluation of expressions |
| Queue | a printer queue, keystrokes, CPU processes, students in a cafeteria, an election, an ATM or bank, a bus queue |

## 9. Cost (pointer moves and index changes counted)

| Operation | Array stack / array queue | Linked stack / linked queue |
|---|---|---|
| `push`, `pop`, `peek`, `enqueue`, `dequeue`, `isEmpty` | no walking: O(1) | no walking: O(1) |
| `size()` of the linked versions | | counts every node: O(n) |
| `contains` | O(n) | O(n) |

## 10. Common errors

| Mistake | What happens | Repair |
|---|---|---|
| `pop`, `peek` or `dequeue` on an empty structure | underflow: `null` and a message, or `NoSuchElementException` from Java's `Queue.remove()` | test `isEmpty()` first |
| `push` or `enqueue` on a full array structure | overflow | test `isFull()` first |
| `isFull` written as `top == stack.length` | one index too late: a push then stores outside the array | `top == stack.length - 1` |
| First `enqueue` on an empty linked queue sets only `tail` | `front` stays `null` and the queue looks empty | set `front = tail` too |
| The last `dequeue` of a linked queue leaves `tail` as it was | `tail` refers to a removed node | set `tail = null` |
| Array queue: `tail++` past the last index | `ArrayIndexOutOfBoundsException` | check for room after the tail |
| `contains` of the array queue scans from index 0 | stale values are found | scan from `front` to `tail` |
| `search(5)` compared with `==` on objects | compares addresses | use `equals` |
