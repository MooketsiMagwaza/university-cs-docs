---
title: "Stacks & Queues"
description: "Learn LIFO and FIFO through visual state changes, array/linked implementations, and circular queue traces."
---

Stacks and queues restrict where data enters and leaves, and those restrictions make program behaviour easier to reason about. This topic follows last in, first out and first in, first out through visual state changes. It then traces an array stack and a circular array queue, and ends with the problems each one fits.

<LearningObjectives items={[
  "Describe a stack as last in, first out and a queue as first in, first out",
  "Use push, peek, and pop, and offer and poll, and predict what each does on an empty structure",
  "Trace an array stack through push and pop, with overflow and underflow checks",
  "Trace a circular array queue through wrap-around, explaining each modulo result",
  "Choose a stack or a queue for a stated problem and justify the removal order",
]} />

<Prerequisites items={[
  "Arrays and generic classes, from the Java Programming Recap and Generics topics",
  "The Queue and Deque interfaces, from the Java Collections topic",
]} />
