A tree represents hierarchy, and a binary search tree adds an ordering rule so that a search can follow one side at each step. This topic covers tree vocabulary, searching, inserting, and deleting in a binary search tree, the four traversal orders, and why the shape of a tree controls its cost.

<LearningObjectives items={[
  "Use tree vocabulary: root, parent, sibling, leaf, subtree, and height",
  "Trace a search in a binary search tree, and insert a key by following the same comparisons",
  "Write the preorder, inorder, postorder, and level-order traversals of a tree",
  "Explain why a tree's shape controls cost: O(log N) when balanced, O(N) when severely skewed",
  "Delete a leaf, a node with one child, and a node with two children",
]} />

<Prerequisites items={[
  "Recursion, for the recursive traversals",
  "Stacks and Queues, for the queue used in level-order traversal",
  "Big-O notation, from the Algorithm Analysis topic",
]} />
