A tree represents hierarchy. A binary tree node has at most two children. A **binary search tree (BST)** adds an ordering rule: smaller keys go left and larger keys go right.

## 2. Generic node

~~~java
public class TreeNode<T> {
    T data;
    TreeNode<T> left;
    TreeNode<T> right;

    TreeNode(T data) {
        this.data = data;
    }
}
~~~

## 3. BST search trace

Search for 60 in the pictured tree.

| current | condition | decision |
|---:|---|---|
| 50 | <code>60 &gt; 50</code> | move right |
| 70 | <code>60 &lt; 70</code> | move left |
| 60 | equal | found |

~~~java
public boolean contains(int target) {
    TreeNode<Integer> current = root;
    while (current != null) {
        if (target == current.data) return true;
        current = target < current.data ? current.left : current.right;
    }
    return false;
}
~~~

## 4. Insert

Insertion follows the same comparisons until a null child position is found. Inserting 65 follows 50 → 70 → 60, then becomes the right child of 60.

## 5. Traversal orders

| Traversal | Rule | Output for diagram | Common use |
|---|---|---|---|
| preorder | node, left, right | 50,30,20,40,70,60,80 | copy/prefix structure |
| inorder | left, node, right | 20,30,40,50,60,70,80 | sorted BST output |
| postorder | left, right, node | 20,40,30,60,80,70,50 | delete/evaluate children first |
| level order | breadth by depth | 50,30,70,20,40,60,80 | nearest levels first |

~~~java
public static void inorder(TreeNode<Integer> node) {
    if (node == null) return;
    inorder(node.left);
    System.out.println(node.data);
    inorder(node.right);
}
~~~

## 6. Shape controls cost

  <div className="rounded-xl border border-red-500 p-4"><strong>Skewed</strong><p className="mb-0 mt-2">Height near N; behaves like a linked list.</p></div>
</div>

BST operations are O(h), where h is height: O(log N) when balanced, O(N) when severely skewed.

## 7. Deletion cases

1. leaf: disconnect it;
2. one child: connect the parent directly to that child;
3. two children: replace with inorder successor/predecessor, then remove that moved node.
