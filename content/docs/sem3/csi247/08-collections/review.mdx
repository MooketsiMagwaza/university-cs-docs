## The five checks

1. Is the code working on an array, a `List`, or an `Iterator`, and which methods does that type have?
2. Is every index valid (0 to `size() - 1`, or up to `size()` for `add(i, e)`), and is the list non-empty before `getFirst` or `removeFirst`?
3. Is the list changed only through the iterator while it is being traversed?
4. Does `remove` receive an index (an `int`) or an object, and is the type argument a reference type?
5. Is the class `Comparable`, does `compareTo` return a negative, zero or positive value, and does it agree with `equals`?
