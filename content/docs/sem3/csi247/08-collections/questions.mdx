Six questions, grouped by what they test, each with its marks. Work a question on paper before opening the solution. The lessons that teach each form are [Collections by Example](/docs/sem3/csi247/08-collections/notes/collections-by-example), [List Implementations by Example](/docs/sem3/csi247/08-collections/notes/list-implementations-by-example) and [Collections Exam Practice](/docs/sem3/csi247/08-collections/notes/collections-exam-practice), which has eight more.

**Marking guide.** A full-credit answer writes the whole list after every statement, gives the exact exception name for a wrong index or an empty list, uses the iterator (not the list) to remove while traversing, and for sorting states what `compareTo` returns and the order it produces. For a memory diagram, show the addresses and say what is copied: the references, not the objects.
