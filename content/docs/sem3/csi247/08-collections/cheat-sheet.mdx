## 2. The framework

`java.util` holds the **Java Collection Framework**: interfaces and classes to store and manipulate collections. `Iterable` is the root interface (it permits traversal); `Collection` extends it and is implemented through its sub-interfaces.

| Interface | Implemented by (the lecture's list) |
|---|---|
| `List` | `ArrayList`, `LinkedList` |
| `Queue` | `LinkedList`, `ArrayDeque`, `PriorityQueue` |
| `Set` | `HashSet`, `TreeSet` |

These are **abstract data types**: the data and the operations on it. You cannot create an object of an interface; a class must implement it.

## 3. Arrays class and conversions

| Task | Code | Notes |
|---|---|---|
| Sort | `Arrays.sort(arr);` | ascending; `O(n log n)`; primitives and objects |
| Print | `Arrays.toString(arr)` | `println(arr)` prints a type and an address |
| Search a sorted array | `Arrays.binarySearch(arr, key)` | index, or `-(insertion point) - 1` |
| Array to list | `new ArrayList<Integer>(Arrays.asList(arr))` | `Arrays.asList` alone is a fixed-size view |
| List to array | `arr = list.toArray(arr);` | assign the result: a too-small array is not filled |

## 4. Iterating

| Way | Code | Notes |
|---|---|---|
| Standard | `for (int i = 0; i < b.length; i++)` | states how to move |
| For-each | `for (Type item : collection)` | uses an `Iterator` privately; no index |
| `Iterator` | `while (it.hasNext()) { E x = it.next(); }` | forward only; `remove()` removes the last element returned |

One `next()` per `hasNext()`. `remove()` before any `next()` throws `IllegalStateException`; `next()` with no next element throws `NoSuchElementException`; changing the list directly inside a for-each loop throws `ConcurrentModificationException`.

## 5. List, ArrayList and LinkedList

| Operation | Code | Notes |
|---|---|---|
| Add at the end | `list.add(e)` | |
| Insert | `list.add(i, e)` | indexes 0 to `size()`; the rest shift right |
| Replace | `list.set(i, e)` | returns the old element |
| Read | `list.get(i)` | indexes 0 to `size() - 1` |
| Remove by index | `list.remove(i)` | `i` is an `int`; returns the element |
| Remove by value | `list.remove(Integer.valueOf(84))` | an object; returns a `boolean` |
| Find | `list.indexOf(e)`, `list.contains(e)` | `-1` when absent |
| Size | `list.size()`, `list.isEmpty()` | |

`LinkedList` also has `addFirst`, `addLast`, `getFirst`, `getLast`, `removeFirst`, `removeLast` and `remove()` (the first element). An index outside the list throws `IndexOutOfBoundsException`; the end methods on an empty `LinkedList` throw `NoSuchElementException`.

## 6. Comparable and Collections.sort

```text
class T implements Comparable<T> {
    public int compareTo(T other) { ... }     negative: this is first   zero: equal   positive: this is later
}
Collections.sort(list);                        any List of Comparable elements; merge sort; O(n log n)
```

Keep `compareTo` consistent with `equals`: when `e1.equals(e2)` is true, `e1.compareTo(e2)` is 0, and the other way round. Test the sign of `compareTo`, not the exact value.

```java title="CollectionsCheat.java"
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Collections;
import java.util.Iterator;
import java.util.LinkedList;
import java.util.List;

public class CollectionsCheat {
    static class Item implements Comparable<Item> {
        String name;
        int qty;

        Item(String name, int qty) {
            this.name = name;
            this.qty = qty;
        }

        public int compareTo(Item other) {
            if (qty == other.qty)
                return 0;
            else if (qty > other.qty)
                return 1;
            else
                return -1;
        }

        public String toString() {
            return name + " " + qty;
        }
    }

    public static void main(String[] args) {
        Integer[] arr = {73, 64, 59, 15};
        Arrays.sort(arr);
        System.out.println(Arrays.toString(arr));

        ArrayList<Integer> list = new ArrayList<Integer>(Arrays.asList(arr));
        list.add(70);
        list.add(1, 20);
        Iterator<Integer> it = list.iterator();
        while (it.hasNext()) {
            if (it.next() % 2 == 0) {
                it.remove();
            }
        }
        System.out.println(list);

        List<Item> items = new ArrayList<Item>();
        items.add(new Item("pen", 5));
        items.add(new Item("book", 2));
        items.add(new Item("bag", 9));
        Collections.sort(items);
        System.out.println(items);

        LinkedList<String> q = new LinkedList<String>();
        q.add("B");
        q.addFirst("A");
        q.addLast("C");
        q.removeFirst();
        System.out.println(q + " " + q.getFirst() + " " + q.contains("C"));
    }
}
```

```text
[15, 59, 64, 73]
[15, 59, 73]
[book 2, pen 5, bag 9]
[B, C] B true
```

## 7. The costs (Lecture 13)

| | `ArrayList` | `LinkedList` |
|---|---|---|
| `get(i)`, `set(i, e)` | efficient: direct access | no direct access: follow the links from the head |
| `add(e)` at the end | efficient | efficient |
| `add(i, e)`, `remove(i)` | inefficient: shifts a potentially large number of elements | no shifting: only links change |
| When full | a new array twice as large, copy, insert | never full: a node is added |
| `Arrays.sort`, `Collections.sort` | `O(n log n)` | `O(n log n)` |

## 8. Common errors

| Mistake | What happens | Repair |
|---|---|---|
| `ArrayList<int>` | `unexpected type` (required: reference) | `ArrayList<Integer>` |
| `new List<Integer>()` | `List is abstract; cannot be instantiated` | `new ArrayList<Integer>()` |
| `println(arr)` | a type and an address | `Arrays.toString(arr)` |
| `(Arrays.asList(marks));` on its own | `not a statement` | pass it to the `ArrayList` constructor |
| `myList.toArray(marks)` result ignored | `marks` is still the old array | `marks = myList.toArray(marks)` |
| `marks.remove(84)` for a `List<Integer>` | an index: `IndexOutOfBoundsException` | `marks.remove(Integer.valueOf(84))` |
| `list.add(9, x)` on a short list | `IndexOutOfBoundsException` | use an index from 0 to `size()` |
| `list.remove(x)` inside a for-each loop | `ConcurrentModificationException` | `it.remove()` through the iterator |
| `getFirst()` on an empty `LinkedList` | `NoSuchElementException` | test `isEmpty()` first |
| `Collections.sort` of a class that is not `Comparable` | `no suitable method found for sort` | `implements Comparable<T>` |
| `compareTo` that disagrees with `equals` | two different objects compare as 0 | break ties with a second key |
