A graph models relationships that are not necessarily hierarchical, such as roads, friendships, prerequisites, or network links. This topic names the parts of a graph, compares the adjacency matrix with adjacency lists, and traces breadth-first and depth-first search, including why a visited set is essential and what each search costs.

<LearningObjectives items={[
  "Describe a graph using vertices, edges, neighbours, paths, degree, direction, and weights",
  "Compare an adjacency matrix with adjacency lists by storage, edge check, and best fit",
  "Trace breadth-first search with a queue and a visited set",
  "Trace recursive depth-first search, including backtracking",
  "Explain why a visited set is essential, and state the O(V + E) cost of BFS and DFS with adjacency lists",
]} />

<Prerequisites items={[
  "Stacks and Queues, for the queue and stack used in traversals",
  "Hash Tables, for visited sets and adjacency maps",
  "Recursion, for recursive depth-first search",
]} />
