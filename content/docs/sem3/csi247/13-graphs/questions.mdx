For vertices A–F and edges AB, AC, BD, CE, DE, EF:

1. Draw the graph and write its adjacency matrix and adjacency lists. [15]
2. Trace BFS from A. Show the queue and visited set after every step. [12]
3. Trace DFS from A using alphabetical neighbour order. Show calls and returns. [12]
4. Add edge FA and explain exactly what fails if visited tracking is removed. [6]
5. State V and E, then derive traversal time using adjacency lists. [6]
6. Modify BFS to store predecessors and reconstruct a shortest unweighted path. [12]
