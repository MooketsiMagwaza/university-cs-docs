A **package** groups related types under a shared name. Packages make a growing program easier to navigate, prevent unrelated classes from colliding on the same simple name, and create an access boundary for package-private members.

## Key ideas

<Checklist title="Rules that control the whole chapter" rules={[
  { type: 'must', text: 'A package declaration is the first non-comment statement in the source file.' },
  { type: 'must', text: 'The source directory structure mirrors the dotted package name.' },
  { type: 'must', text: 'Run a packaged main class by its fully qualified name from the classpath root.' },
  { type: 'note', text: 'java.lang is imported automatically; other packages are not.' },
