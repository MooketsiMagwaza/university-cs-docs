## 1. Placeholders used in every template on this page

| Placeholder | Meaning | Example |
|---|---|---|
| `packageName` | the name of a package | `java.util`, `pkg`, `bankAccounts` |
| `ClassName` | a class in a package | `Scanner`, `A` |
| `TesterName` | the class with `main` | `pkgTester` |
| `src`, `classes` | the folder of sources and the folder of class files | |

## 2. Built-in packages (the Java API)

| Package | Holds | Examples |
|---|---|---|
| `java.lang` | Java's fundamental classes; **imported by default** | `String`, `Math`, `Integer` |
| `java.util` | the collections framework and utility classes | `Scanner`, `Date`, `Random`, `StringTokenizer`, `ArrayList` |
| `java.io` | file input and output | `PrintWriter`, `FileReader`, `File` |

```text
import packageName.ClassName;      one class                         import java.util.Scanner;
import packageName.*;              every class of that package       import java.io.*;
java.util.Scanner scan = ...       a full name needs no import
```

An asterisk import covers the classes of that package only, not its sub-packages (`java.util.regex.Pattern` needs its own import). If two packages imported with `*` have a class with the same name, the short name is ambiguous.

## 3. A user-defined package

```text
project/
    src/
        pkg/A.java            starts with  package pkg;      public class A
        pkg/B.java            starts with  package pkg;      public class B
        pkgTester.java        starts with  import pkg.A;     (no package statement)
    classes/                  receives classes/pkg/A.class, classes/pkg/B.class, classes/pkgTester.class
```

| Step | What to do |
|---|---|
| 1 | create the directory structure: `src` and `classes` |
| 2 | choose a package name: a lowercase first letter, a capital at the start of each new word |
| 3 | create the `.java` files under `src`, in a folder named like the package |
| 4 | put `package packageName;` at the top of every source file of the package |
| 5 | compile each class from the folder above `src` and `classes`: `javac -d classes -sourcepath src src/pkg/A.java` |
| 6 | in the tester, `import pkg.A;` or `import pkg.*;` and compile it with `-classpath classes` |
| 7 | run from the folder above `classes`: `java -classpath classes pkgTester` (`java -classpath classes app.Main` if the tester is in the package `app`) |

A complete small session, run for real:

```java title="src/util/Greeter.java" project="cheat"
package util;

public class Greeter {
    public String greet(String name) {
        return "Hello, " + name;
    }
}
```

```java title="src/GreeterTester.java" project="cheat"
import util.Greeter;

public class GreeterTester {
    public static void main(String[] args) {
        System.out.println(new Greeter().greet("CSI247"));
    }
}
```

```text title="terminal" project="cheat"
$ mkdir classes
$ javac -d classes -sourcepath src src/util/Greeter.java
$ ls classes/util
Greeter.class
$ javac -d classes -classpath classes src/GreeterTester.java
$ java -classpath classes GreeterTester
Hello, CSI247
```

## 4. Access across packages

| Modifier | Visible in |
|---|---|
| `public` | everywhere |
| `protected` | the class, the same package, and sub classes in any package |
| none (default) | the same package only |
| `private` | the class only |

A class that other packages use must be `public`; so must the members they call.

## 5. Common faults and the message

| Fault | Message | Repair |
|---|---|---|
| no import for `Scanner` | `cannot find symbol` (class Scanner) | `import java.util.Scanner;` |
| `Pattern` with only `java.util.*` | `cannot find symbol` (class Pattern) | `import java.util.regex.Pattern;` |
| `java.util.*` and `java.sql.*` both imported, `Date` used | `reference to Date is ambiguous` | import one class or use the full name |
| tester compiled without `-classpath classes` | `package pkg does not exist` | add `-classpath classes` |
| source file not in the folder named like the package | `package ... does not exist` (and "file does not contain class") | move it to `src/packageName` |
| `java pkgTester` from the wrong place, or without `-classpath classes` | `Could not find or load main class pkgTester` | `java -classpath classes pkgTester` |
| the wrong package in front of the tester | `Could not find or load main class pkg.pkgTester` | use the tester's own package, or none |
| a class with no `public` used from another package | `Item is not public in shop; cannot be accessed from outside package` | declare it `public` |
| a protected method used by a non-sub class in another package | `sound() has protected access in Animal` | use a sub class, or make it public |
