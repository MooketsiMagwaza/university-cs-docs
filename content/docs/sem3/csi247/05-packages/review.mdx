## The five checks

1. Does the file start with the right `package` statement, and is it in a folder named like the package under `src`?
2. Is the class (and the method the tester calls) `public`?
3. Does the tester `import` the package and the class, and is `java.lang` the only package assumed?
4. Are the commands typed from the folder above `src` and `classes`, with `-d classes -sourcepath src` to compile and `-classpath classes` to compile the tester and to run it?
5. If two packages are imported with `*`, does a short name match a class in both?
