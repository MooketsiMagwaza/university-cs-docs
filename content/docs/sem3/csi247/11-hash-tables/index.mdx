title: "Hash Tables"
description: "Turn keys into bucket indexes, trace collisions, and connect equals/hashCode to correct lookup."
---

A hash table lets a key lead to its value without scanning everything: a hash function chooses a bucket, and collisions are resolved inside that bucket. This topic traces how a key becomes a bucket index, why collisions are normal, how equals and hashCode must agree, and how the load factor and resizing affect lookup cost.

<LearningObjectives items={[
  "Explain how a hash function turns a key into a bucket index",
  "Trace a collision and a lookup in a table that uses separate chaining",
  "State the equals/hashCode contract, and explain the danger of mutable keys",
  "Calculate the load factor, and explain how resizing affects lookup cost",
  "Trace a sequence of put operations, including one that replaces the value of an equal key",
]} />
