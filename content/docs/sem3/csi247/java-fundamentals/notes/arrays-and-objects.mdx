An array is a fixed-size object containing indexed cells of one declared component type. The array variable stores a reference; the cells store either primitive values or object references.

## 1. Why arrays are needed

A single variable repeatedly overwritten can remember only its newest value. To calculate an average and then revisit all 50 marks, the program must retain the whole collection.

## 2. Array reference, cells, and indexes

~~~java
int[] numbers = new int[6];
~~~

<div className="not-prose my-6 flex flex-wrap items-center justify-center gap-4 rounded-2xl border border-fd-border p-5">
  <div className="rounded-xl border-2 border-blue-500 bg-blue-500/10 p-4 text-center font-mono">numbers<br/>ref 48</div><span className="text-2xl">→</span><div className="flex gap-2">{[0,0,0,0,0,0].map((value,index) => <div key={index} className="rounded-lg border-2 border-fd-border p-3 text-center font-mono"><strong>{value}</strong><small className="mt-1 block text-fd-muted-foreground">{index}</small></div>)}</div>
</div>

The length is 6, so valid indexes are 0 through 5. Index 6 is one cell beyond the object and throws <code>ArrayIndexOutOfBoundsException</code>.

| Cell type | Default value after <code>new</code> |
|---|---|
| numeric primitive | 0 or 0.0 |
| <code>char</code> | null character |
| <code>boolean</code> | false |
| reference type | null |

values[2] = 14; // Replace the value at index 2.

## 5. Arrays passed to methods

The reference value is copied into the parameter. Mutating array cells affects the caller's object.

~~~java
public static void fill(int[] numbers, int value) {
    for (int i = 0; i < numbers.length; i++) {
        numbers[i] = value; // Follow the copied reference to shared cells.
    }
}
~~~

<Mermaid chart={`flowchart LR
  C["caller variable<br/>ref 40"] --> A["shared int[] object"]
  P["parameter numbers<br/>copied ref 40"] --> A
  V["parameter value = 7"] --> W["each cell becomes 7"]`} caption="The reference variable is copied; the array object is not copied." />

## 6. Common processing methods

~~~java
public static int indexOfMax(int[] numbers) {
    if (numbers.length == 0) {
        return -1; // No maximum exists.
    }

    int maxIndex = 0;
    for (int i = 1; i < numbers.length; i++) {
        if (numbers[i] > numbers[maxIndex]) {
            maxIndex = i;
        }
    }
    return maxIndex;
}

public static double average(int[] numbers) {
    if (numbers.length == 0) {
        return 0.0;
    }

    long sum = 0; // Wider accumulator reduces overflow risk for many ints.
    for (int value : numbers) {
        sum += value;
    }
    return (double) sum / numbers.length;
}
~~~

### Trace indexOfMax on [5, 11, 4, 13, 8]

| <code>i</code> | Evaluated comparison | <code>maxIndex</code> after | Maximum value |
|---:|---|---:|---:|
| initialise | assume index 0 | 0 | 5 |
| 1 | <code>11 &gt; 5</code> true | 1 | 11 |
| 2 | <code>4 &gt; 11</code> false | 1 | 11 |
| 3 | <code>13 &gt; 11</code> true | 3 | 13 |
| 4 | <code>8 &gt; 13</code> false | 3 | 13 |

The method returns an **index**, not the largest value.

## 8. Arrays of objects

## 9. Two-dimensional arrays

Java represents a 2D array as an array whose cells contain references to row arrays. Rows can have different lengths.

~~~java
int[][] grid = {
    {1, 2, 3},
    {4, 5},
    {6, 7, 8, 9}
};
~~~

<div className="not-prose my-6 space-y-2 rounded-2xl border border-fd-border p-5">
  {[[1,2,3],[4,5],[6,7,8,9]].map((row,r) => <div key={r} className="flex items-center justify-center gap-2"><span className="w-16 font-mono text-sm">row {r} →</span>{row.map((value,c) => <span key={c} className="grid h-10 w-10 place-items-center rounded border border-fd-border font-mono">{value}</span>)}</div>)}
</div>

Use <code>grid.length</code> for row count and <code>grid[row].length</code> for that row's column count.
