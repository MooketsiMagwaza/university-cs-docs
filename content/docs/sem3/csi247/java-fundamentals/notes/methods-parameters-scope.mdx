A method is a named block that performs one task. A call pauses the caller, creates a new method frame, copies argument values into parameters, executes the body, and optionally returns one value.

## 1. Method anatomy

~~~java
public static double cubeVolume(double sideLength) {
    double volume = sideLength * sideLength * sideLength;
    return volume;
}
~~~

The declaration answers four questions: Who may call it? Is it attached to the class or an object? What value comes back? What input must the caller provide?

|---:|---|---|---|

## 3. Arguments and parameters

An **argument** is the expression on the calling side. A **formal parameter** is the local variable named in the method declaration.

<Mermaid chart={`flowchart LR
  A["argument: total, value 10.0"] -->|"copy value"| P["parameter: price = 10.0"]
  P --> C["called method changes price to 10.75"]
  C --> R["caller total remains 10.0"]`} caption="Java is pass-by-value: the parameter receives a copy of the argument value." />

~~~java
public static double addTax(double price, double rate) {
    price = price + price * rate / 100; // Changes the local parameter copy.
    return price;                       // Caller changes only if it uses this result.
}
~~~

### References are also passed by value

For an array argument, Java copies the reference value. The parameter is a separate variable, but both references initially lead to the same object.

~~~java
public static void changeFirst(int[] values) {
    values[0] = 99;       // Mutates the shared array object.
    values = new int[3];  // Reassigns only the local parameter variable.
    values[0] = -1;       // Mutates the new local array, not the caller's array.
}
~~~

## 4. Return values and void

A value-returning method declares a result type. Every reachable path must return a compatible value. <code>return</code> immediately ends the current call.

~~~java
public static int sign(double value) {
    if (value < 0) {
        return -1;
    }
    if (value > 0) {
        return 1;
    }
    return 0; // Required path for value == 0.
}
~~~

A <code>void</code> method performs an action without producing a value expression. A bare <code>return;</code> can end it early.

~~~java
public static void boxString(String text) {
    if (text.isEmpty()) {
        return; // Nothing useful to draw.
    }
    System.out.println("[" + text + "]");
}
~~~

## 5. Scope: where a name is visible

<div className="not-prose my-6 space-y-3 rounded-2xl border border-fd-border p-5">
  <div className="rounded-xl border-2 border-blue-500 bg-blue-500/5 p-4"><strong>Class scope</strong><div className="mt-2 rounded-lg border border-fd-border p-3"><strong>Method scope: main</strong><div className="mt-2 rounded-lg border border-emerald-600 bg-emerald-500/5 p-3"><strong>Block scope: for loop</strong></div></div></div>
</div>

~~~java
public class ScopeDemo {
    private static int calls = 0; // Class field: visible to class methods.

    public static int sumSquares(int limit) { // limit: parameter/local scope.
        int sum = 0;                          // Local to this method call.
        for (int i = 1; i <= limit; i++) {   // i: only inside this loop.
            int square = i * i;               // square: loop block only.
            sum += square;
        }
        calls++;
        return sum;
    }
}
~~~

| Name | Begins | Ends | Can another method use it directly? |
|---|---|---|---|
| <code>calls</code> | class declaration | class end | yes, subject to modifiers |
| <code>limit</code> | method parameter | method end | no |
| <code>sum</code> | declaration in method | method end | no |
| <code>i</code>, <code>square</code> | loop/block declaration | loop block end | no |

Avoid shadowing a field with a local variable of the same name unless the distinction is intentional and explicit with <code>this</code>.

## 6. Design and document one-task methods

The lecture's process is reliable:

1. state the task;
2. identify inputs;
3. choose parameter and return types;
4. write pseudocode;
5. implement one small body;
6. test normal, boundary, and invalid cases.

~~~java
/**
 * Returns the volume of a square-based pyramid.
 * @param height perpendicular height; must be non-negative
 * @param baseSide length of one square-base side; must be non-negative
 * @return volume, or 0 when either dimension is negative
 */
public static double pyramidVolume(double height, double baseSide) {
    if (height < 0 || baseSide < 0) {
        return 0;
    }
    double baseArea = baseSide * baseSide;
    return height * baseArea / 3.0; // Decimal prevents integer-style truncation.
}
~~~
