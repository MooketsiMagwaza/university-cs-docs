A variable is a named storage location with a declared type. The most important Java recap question is:

> Does this variable contain the value itself, or a reference that leads to an object?

## 1. The two storage stories

A **primitive variable** stores its value directly. A **reference variable** stores a reference to an object (or <code>null</code> when it refers to no object).

## 2. Primitive types

| Family | Types | Typical use | Example |
|---|---|---|---|
| Whole numbers | <code>byte</code>, <code>short</code>, <code>int</code>, <code>long</code> | counts, indexes, IDs | <code>int count = 5;</code> |
| Decimal numbers | <code>float</code>, <code>double</code> | measurements and calculated values | <code>double price = 19.95;</code> |
| Character | <code>char</code> | one UTF-16 code unit | <code>char grade = 'A';</code> |
| Logical | <code>boolean</code> | true/false decisions | <code>boolean found = false;</code> |

## 3. Reference types and aliasing

Classes, arrays, interfaces, enums, and records are reference types. Two variables can refer to the **same** mutable object; this is called aliasing.

~~~java
int[] first = {4, 2, 7};
int[] second = first; // Copy the reference, not the three elements.
second[1] = 99;       // Follow second to the shared array and mutate cell 1.
System.out.println(first[1]); // Prints 99.
~~~

## 4. The meaning of null

<code>null</code> means “no object reference is stored here.”

~~~java
String name = null;
// name.length(); // Runtime NullPointerException: there is no String object.

if (name != null) {
    System.out.println(name.length()); // Safe only inside this branch.
}
~~~

<div className="not-prose my-6 flex items-center justify-center gap-4 rounded-2xl border border-fd-border p-5">
  <div className="rounded-lg border-2 border-red-500 bg-red-500/10 px-5 py-3 font-mono">name · null</div>
  <div className="text-2xl">→</div>
  <div className="rounded-lg border-2 border-dashed border-fd-border px-5 py-3 text-fd-muted-foreground">no String object</div>
</div>

Declaring a reference and creating its object are separate operations:

~~~java
Scanner input;                    // Reference variable exists; no Scanner yet.
input = new Scanner(System.in);   // Construct an object and store its reference.
~~~

## 5. Conversions and integer division

Widening conversions normally preserve information and can be automatic. Narrowing conversions can lose information and require a cast.

| Expression | Evaluated operation | Result |
|---|---|---|
| <code>double a = 7 / 2;</code> | integer division happens first | <code>3.0</code> |
| <code>double b = 7.0 / 2;</code> | one operand is double | <code>3.5</code> |
| <code>int c = (int) 79.95;</code> | fractional part is discarded | <code>79</code> |
| <code>double d = 12;</code> | int widens to double | <code>12.0</code> |

<CommonMistake title="Thinking a double destination changes earlier arithmetic">
The right-hand expression is evaluated before assignment. In <code>double a = 7 / 2;</code>, both operands are integers, so the lost <code>.5</code> cannot be recovered when 3 is later widened to 3.0.
</CommonMistake>

## 6. Why generics do not accept primitives

Generic type arguments must be reference types. Java provides wrapper classes for primitive values.

<div className="not-prose my-6 grid gap-3 sm:grid-cols-4">
  {[[ 'int', 'Integer' ], [ 'double', 'Double' ], [ 'char', 'Character' ], [ 'boolean', 'Boolean' ]].map(([primitive, wrapper]) => <div key={primitive} className="rounded-xl border border-fd-border p-4 text-center"><code>{primitive}</code><div className="my-2 text-fd-muted-foreground">↕ autoboxing</div><code className="font-bold">{wrapper}</code></div>)}
</div>

~~~java
ArrayList<Integer> marks = new ArrayList<>(); // Integer is a reference type.
marks.add(72);                                // int 72 is autoboxed to Integer.
int firstMark = marks.get(0);                 // Integer is unboxed to int.
~~~

Autoboxing is convenient, but <code>Integer</code> may be <code>null</code> while <code>int</code> cannot. Unboxing a null wrapper throws <code>NullPointerException</code>.

## 7. Fully commented recap program

~~~java
import java.util.Arrays;

public class ValueReferenceDemo {
    public static void main(String[] args) {
        int original = 10;          // Primitive value stored directly.
        int copy = original;        // Copy the number 10 into a new variable.
        copy = 20;                  // Only copy changes.

        int[] first = {4, 2, 7};    // first stores a reference to one array.
        int[] alias = first;        // alias receives the same reference.
        alias[1] = 99;              // Mutate their shared array object.

        System.out.println(original);            // 10
        System.out.println(copy);                // 20
        System.out.println(Arrays.toString(first)); // [4, 99, 7]
    }
}
~~~
