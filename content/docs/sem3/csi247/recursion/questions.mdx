## Question 1: calls and returns [12]

Trace <code>power(2, 4)</code> for a recursive method whose base case returns 1 at exponent 0. Show:

1. every parameter value while calls descend;
2. what each frame is waiting to multiply;
3. every expression and result while returns unwind.

## Question 2: diagnose termination [10]

For each method, identify the base case, changing input, and whether the input gets closer to the base case. Repair any non-terminating method.

## Question 3: recursive array sum [14]

Write <code>sum(int[] data, int index)</code>. The method must return 0 when <code>index == data.length</code>. Trace it on <code>[4, 7, 2]</code>, then state time and auxiliary space.

## Question 4: search [12]

Trace recursive linear search for a present value and an absent value. Include the base-case condition with substituted values at every call.

## Question 5: recursion versus iteration [12]

Write recursive and iterative factorial methods. Compare output, time, auxiliary space, readability, and invalid-input handling. Do not claim Java automatically removes tail calls.

<Accordions>
<Accordion title="Marking guide">

A trace receives full credit only when calls downward and returns upward are shown separately. Complexity must include call-stack space. A base case alone is insufficient: the recursive case must make measurable progress toward it.
