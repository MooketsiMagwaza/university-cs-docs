## Required order in a source file

```java
package pkg;

import java.util.Scanner;

public class Example {
    // fields, constructors, and methods
}
```

The package declaration is optional only for the unnamed package. When present, it comes before imports and type declarations.

The declaration defines package identity. Mirroring the package under `src` is the normal sourcepath/tooling convention; a file explicitly passed to javac can compile from another directory without being renamed.

## Name lookup forms

| Goal | Form |
|---|---|
| Import one type | `import java.util.Scanner;` |
| Import types directly in one package | `import java.util.*;` |
| Avoid a simple-name conflict | `java.sql.Date value;` |
| Import one static member | `import static java.lang.Math.sqrt;` |
| Use automatically available core type | `String`, `Math`, `System` from `java.lang` |

## Folder template

```text
project/
  src/
    pkg/
      A.java       // package pkg;
    app/
      Tester.java  // package app;
  classes/
```

## Commands

```text
javac -d classes -sourcepath src src/app/Tester.java
java -cp classes app.Tester
```

| Option | Meaning |
|---|---|
| `-d classes` | Root for generated package folders and `.class` files |
| `-sourcepath src` | Root for package-structured `.java` dependencies |
| `-cp classes` | Root for compiled packages at compile or run time |

## Access lookup

| Modifier | Same class | Same package | Subclass elsewhere | Other package |
|---|:---:|:---:|:---:|:---:|
| `private` | yes | no | no | no |
| package-private | yes | yes | no | no |
| `protected` | yes | yes | qualifying inherited access | no |
| `public` | yes | yes | yes | yes |

For protected instance members outside the package, a suitable subclass receiver is also required; an arbitrary base-class object does not qualify. The type name used at the call site must also be accessible; a public member alone does not make a hidden type name accessible.

## Book-record integration

| Job | Type or condition |
|---|---|
| Open character input | `java.io.FileReader` |
| Read whole lines | `java.io.BufferedReader`; EOF is `readLine() == null` |
| Alternative line/field scanner | `java.util.Scanner`; lines use `hasNextLine()` |
| Handle file failures | `java.io.IOException` |
| Guard storage | Capacity check before reading/storing |
| Display populated Books | `i < count`; unused cells remain null |

## Diagnostic map

| Message | Check |
|---|---|
| `package ... does not exist` | declaration, path, source/classpath root |
| `cannot find symbol` | import and exact type/member spelling |
| `... is not public` | access modifier and package boundary |
| `Could not find or load main class` | classpath root and fully qualified class name |
| `Main method not found` | main signature and target class |
