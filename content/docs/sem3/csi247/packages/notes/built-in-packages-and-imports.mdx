A **package** is a named group of related Java types. Think of the package as an address and the class as one item at that address. An **import** lets a source file use a shorter type name.

## 1. Work through name lookup before code

### Example A: one type, two spellings

`java.util.Scanner` is the fully qualified name: `java.util` is the package and `Scanner` is the simple class name. A single-type import makes that short name usable in the current file.

<Mermaid chart={`flowchart TD
  F["java.util.Scanner: full name"] --> T["The Scanner type"]
  I["import java.util.Scanner;"] --> S["Scanner: short name in this file"]
  S --> T`} caption="The two names identify the same type. The import changes source name lookup." />

| Source-file situation | Name written | Name lookup result |
|---|---|---|
| No Scanner import | `java.util.Scanner` | Full name identifies the type |
| No Scanner import | `Scanner` | Unresolved unless another applicable declaration makes it available |
| `import java.util.Scanner;` | `Scanner` | Resolves to `java.util.Scanner` |
| No String import | `String` | Available from `java.lang` automatically |

### Example B: wildcard versus subpackage

`import java.util.*;` makes accessible types directly in `java.util` available by simple name. It does not recursively include `java.util.concurrent`. A dotted subpackage is a separate package.

<Mermaid chart={`flowchart TD
  W["import java.util.*;"] --> S["Scanner: included"]
  W --> A["Arrays: included"]
  W -. "not included" .-> T["java.util.concurrent.TimeUnit"]
  D["import java.util.concurrent.TimeUnit;"] --> T`} caption="A wildcard covers one package, not a recursive directory search." />

| Import set | Name to resolve | Evaluated question | Result |
|---|---|---|---|
| `java.util.*` | `Scanner` | Directly in java.util? true | Available |
| `java.util.*` | `TimeUnit` | Directly in java.util? false | Needs its actual package import |
| `java.io.BufferedReader` | `FileReader` | Included by this single-type import? false | Needs another import or full name |

### Example C: two classes called Date

`java.util.Date` and `java.sql.Date` are different types. Two single-type imports with the same simple name conflict. With two wildcard imports, a simple reference to `Date` is ambiguous. Import one Date and fully qualify the other.

<Mermaid chart={`flowchart TD
  U["java.util.Date"] --> Q["Date: which type?"]
  S["java.sql.Date"] --> Q
  Q --> R["Repair: Date for util; java.sql.Date for sql"]`} caption="Qualification chooses the owner without changing either library class." />

### Example D: type versus static member

A normal import lets you write `Scanner`. A static import lets you write a static member such as `sqrt` without `Math.`. Neither grants access to private members.

<Mermaid chart={`flowchart TD
  N["import java.util.Scanner;"] --> C["Scanner: type name"]
  M["import static java.lang.Math.sqrt;"] --> F["sqrt(81): static method call"]
  F --> O["Same result as Math.sqrt(81): 9.0"]`} caption="Type names and static member names occupy different roles." />

## 2. A worked file-reading example from the course

An exam-style file question may ask you to read records into an array of `Book` objects. Here we assume `books.txt` has one `title|price` record per line, for example `Algorithms|120.50`. Titles contain no pipe, prices use a decimal point, and records are well formed. Capacity is 50; a count tracks populated slots.

<Mermaid chart={`flowchart TD
  F["books.txt: Algorithms|120.50"] --> R["FileReader: characters"]
  R --> B["BufferedReader: readLine"]
  B --> P["Parse title and price"]
  P --> O["new Book: Algorithms, 120.50"]
  O --> A["books[0] stores a reference; count becomes 1"]`} caption="Read a line, parse fields, construct an object, then store its reference." />

The Scanner alternative still uses a FileReader to open the file. One Scanner reads lines; a second Scanner parses each line using a pipe delimiter. Both routes create the same Book records.

<Mermaid chart={`flowchart TD
  F["FileReader for books.txt"] --> S["Scanner: hasNextLine and nextLine"]
  S --> L["Line Scanner: pipe delimiter"]
  L --> T["next: title"]
  L --> P["nextDouble: price"]
  T --> B["new Book(title, price)"]
  P --> B`} caption="Scanner is in java.util; FileReader is in java.io. Imports must cover both." />

For `Algorithms|120.50` followed by `Networks|99.00`:

| Step | Evaluated condition/action | Array state | count |
|---:|---|---|---:|
| Start | Allocate 50 reference cells | `[null, null, ...]` | 0 |
| 1 | `0 < 50` true; first line exists | `[Book("Algorithms",120.50), null, ...]` | 1 |
| 2 | `1 < 50` true; second line exists | `[Book("Algorithms",120.50), Book("Networks",99.00), ...]` | 2 |
| 3 | `2 < 50` true; `readLine() != null` false | Unchanged; stop | 2 |
| Display | `i < count` true for 0/1, false for 2 | Print only two populated cells | 2 |

`new Book[50]` creates the array, not 50 Books. Each `new Book(...)` constructs a separate object; unfilled cells remain `null`.

  C1["books[1] reference"] --> B1["Book: Networks, 99.00"]
  C2["books[2..49]: null"]`} caption="After two records: one array object and two Book objects." />

## 3. Properties and rules

| Package/form | Purpose or rule | Course examples |
|---|---|---|
| `java.lang` | Automatically available core types | `String`, `Math`, `System` |
| `java.util` | Utilities and collections | `Scanner`, `Arrays`, `ArrayList`, `StringTokenizer` |
| `java.io` | Streams and file I/O | `FileReader`, `BufferedReader`, `PrintWriter`, `IOException` |
| Single-type import | One accessible type by simple name | `import java.io.FileReader;` |
| Wildcard import | Accessible types in one package | `import java.io.*;` |
| Fully qualified reference | Selects the package explicitly | `java.sql.Date` |
| Static import | Accessible static member by simple name | `import static java.lang.Math.sqrt;` |

An import applies to its source file. It does not copy code, install a library, change access permissions, or fix a missing runtime classpath.

## 4. Fully commented Java

### Small runnable import examples

`ReadName.java`:

```java
import java.util.Scanner; // Scanner belongs to java.util.

public class ReadName {
    public static void main(String[] args) {
        // The import lets this source use Scanner instead of java.util.Scanner.
        Scanner input = new Scanner(System.in);
        System.out.print("Name: ");
        String name = input.nextLine(); // String is automatically available.
        System.out.println("Hello, " + name);
        input.close(); // This standalone program is finished using System.in.
    }
}
```

`DatesDemo.java`:

```java
import java.util.Date; // Reserve the simple name Date for this type.

public class DatesDemo {
    Date createdAt; // This is java.util.Date.
    java.sql.Date storedDate; // Select the other Date unambiguously.
}
```

`DistanceDemo.java`:

```java
import static java.lang.Math.sqrt; // Import a member, not the Math type.

public class DistanceDemo {
    public static void main(String[] args) {
        System.out.println(sqrt(81)); // Same as Math.sqrt(81); prints 9.0.
    }
}
```

### Complete Book-record program

Save both files together. This small example uses the unnamed package to focus on imports; the next lesson moves classes into named packages.

`Book.java`:

```java
public class Book {
    // Private fields hold each object's representation.
    private final String title;
    private final double price;

    public Book(String title, double price) {
        // Initialise this Book from one parsed record.
        this.title = title;
        this.price = price;
    }

    public String getTitle() {
        return title; // Public read access; callers cannot alter the final field.
    }

    public double getPrice() {
        return price; // Return the stored numeric value.
    }
}
```

`BookImportDemo.java`:

```java
import java.io.BufferedReader; // Read whole lines from a character stream.
import java.io.FileReader; // Open a file as a character stream.
import java.io.IOException; // File opening and reading may fail.
import java.util.Locale; // Fix decimal parsing to the example's dot convention.
import java.util.Scanner; // Scanner belongs to java.util.

public class BookImportDemo {
    private static Book parseLine(String line) {
        // A pipe is special in regex syntax: escape it for the delimiter.
        try (Scanner fields = new Scanner(line)) {
            fields.useDelimiter("\\|");
            fields.useLocale(Locale.US); // Parse a price such as 120.50.
            String title = fields.next().trim();
            double price = fields.nextDouble();
            return new Book(title, price); // One object per record.
        }
    }

    public static int readWithBufferedReader(String path, Book[] books)
            throws IOException {
        int count = 0; // Populated cells, not capacity.
        // Closing the wrapper also closes the underlying FileReader.
        try (BufferedReader reader = new BufferedReader(new FileReader(path))) {
            String line;
            // Capacity first; readLine returns null at end of file.
            while (count < books.length && (line = reader.readLine()) != null) {
                books[count] = parseLine(line); // Store the new object's reference.
                count++; // Advance only after successful storage.
            }
        }
        return count; // Caller avoids the remaining null cells.
    }

    public static int readWithScanner(String path, Book[] books)
            throws IOException {
        int count = 0;
        // This Scanner reads lines; parseLine uses a Scanner for fields.
        try (Scanner input = new Scanner(new FileReader(path))) {
            while (count < books.length && input.hasNextLine()) {
                books[count] = parseLine(input.nextLine());
                count++;
            }
            // Scanner records underlying read errors rather than throwing them.
            if (input.ioException() != null) throw input.ioException();
        }
        return count;
    }

    public static void main(String[] args) throws IOException {
        Book[] books = new Book[50]; // Array cells initially contain null.
        String path = args.length == 0 ? "books.txt" : args[0];
        int count = readWithBufferedReader(path, books);
        // To use the alternative route, replace the preceding call with:
        // int count = readWithScanner(path, books);
        for (int i = 0; i < count; i++) {
            System.out.println(books[i].getTitle()); // Visit only populated cells.
        }
    }
}
```

Compile `javac Book.java BookImportDemo.java` and run `java BookImportDemo` from the directory containing both sources and `books.txt`. For the two-record example:

```text
Algorithms
Networks
```

## 5. Exam practice with marking cues

Attempt each task before opening its answer. These cues are practice guidance, not an official marking scheme.

1. Define package, simple name, fully qualified name and import using Scanner. [6]
2. Explain why `java.util.*` includes Scanner but not TimeUnit. Write the extra import. [4]
3. Repair conflicting single-type Date imports while using both types. [4]
4. Distinguish a normal Math import from a static sqrt import. Give a call for each. [4]
5. Write imports for BufferedReader, FileReader, IOException and Scanner. [4]
6. Trace two records into `new Book[50]`. State Book object count, populated count and unfilled slots. [5]
7. Explain both read-loop conditions and why capacity is checked first. [4]
8. Explain and repair printing all 50 entries after reading two books. [3]
9. A program imports `java.io.*` but Scanner is unresolved. Diagnose and repair. [3]
10. Compare EOF detection, parsing and resource closing in both reading routes. [6]
