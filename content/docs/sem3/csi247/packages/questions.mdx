## Package and import concepts

The marking cues below are practice guidance. For a diagnosis, name the failing layer, cite the relevant package/name/path, and give a concrete repair. A command without its working-directory assumption is incomplete.

<ExamQuestion title="Question 1: Built-in packages and imports [12 marks]">
  <SubQuestion part="a" prompt={<>Define a Java package and give two benefits. [4]</>} solution={<>A package is a named group or namespace for related types. It organises code, reduces simple-name conflicts, supports access control, and makes large programs easier to maintain. Any definition and two developed benefits earn the marks. [4]</>} />
  <SubQuestion part="b" prompt={<>Give the fully qualified names of <code>Scanner</code>, <code>ArrayList</code>, and <code>BufferedReader</code>. [3]</>} solution={<><code>java.util.Scanner</code>, <code>java.util.ArrayList</code>, and <code>java.io.BufferedReader</code>. [3]</>} />
  <SubQuestion part="c" prompt={<>Explain why <code>import java.util.*;</code> does not import <code>java.util.concurrent.TimeUnit</code>. [3]</>} solution={<>The wildcard covers types declared directly in <code>java.util</code>. A subpackage is a separate package and is not recursively included. [3]</>} />
  <SubQuestion part="d" prompt={<>Why can <code>String</code> be used without an explicit import? [2]</>} solution={<><code>String</code> belongs to <code>java.lang</code>, which Java makes available automatically. [2]</>} />
</ExamQuestion>

## User-defined package structure

<ExamQuestion title="Question 2: Design a package tree [14 marks]">
  <SubQuestion part="a" prompt={<>Draw the source tree for <code>school.people.Student</code>, <code>school.people.Lecturer</code>, and <code>school.app.Main</code> below a source root named <code>src</code>. [5]</>} solution={<>Place <code>Student.java</code> and <code>Lecturer.java</code> in <code>src/school/people</code>, and <code>Main.java</code> in <code>src/school/app</code>. Marks are for the package path, filenames, and shared source root. [5]</>} />
  <SubQuestion part="b" prompt={<>Write the package declaration for each file. [3]</>} solution={<><code>Student.java</code> and <code>Lecturer.java</code> begin with <code>package school.people;</code>. <code>Main.java</code> begins with <code>package school.app;</code>. [3]</>} />
  <SubQuestion part="c" prompt={<>Write imports in <code>Main.java</code> for the other two classes. [2]</>} solution={<><code>import school.people.Student;</code> and <code>import school.people.Lecturer;</code>. [2]</>} />
  <SubQuestion part="d" prompt={<>A method in <code>Student</code> has no access modifier. Can <code>Main</code> call it? Explain. [4]</>} solution={<>No. With no modifier the method is package-private. <code>Main</code> is in <code>school.app</code>, a different package from <code>school.people</code>. Make the method public if it belongs to the external API. [4]</>} />
</ExamQuestion>

## Compilation and runtime lookup

<ExamQuestion title="Question 3: Compile and run [14 marks]">
  <SubQuestion part="a" prompt={<>From the project root, write a command that compiles <code>src/school/app/Main.java</code>, finds source dependencies below <code>src</code>, and writes class files below <code>classes</code>. [4]</>} solution={<><code>javac -d classes -sourcepath src src/school/app/Main.java</code>. [4]</>} />
  <SubQuestion part="b" prompt={<>Write the command that runs the packaged main class. [3]</>} solution={<><code>java -cp classes school.app.Main</code>. The classpath is the output root, while the target is the fully qualified class name. [3]</>} />
  <SubQuestion part="c" prompt={<>Predict the output path of <code>Main.class</code>. [2]</>} solution={<><code>classes/school/app/Main.class</code>. [2]</>} />
  <SubQuestion part="d" prompt={<>A student runs <code>java -cp classes Main</code> and receives “Could not find or load main class Main”. Diagnose and repair it. [5]</>} solution={<>The runtime command uses the wrong binary name. The bytecode declares package <code>school.app</code>, so Java must be started from the classpath root with <code>java -cp classes school.app.Main</code>. [5]</>} />
</ExamQuestion>

## Debugging

<ExamQuestion title="Question 4: Classify the failure [10 marks]">
  <SubQuestion part="a" prompt={<>What should you check first for <code>package pkg does not exist</code>? [3]</>} solution={<>Check the imported package spelling, the dependency's package declaration and matching path, and whether the compiler's source path or classpath points at the correct root. [3]</>} />
  <SubQuestion part="b" prompt={<>What should you check for <code>doubled() is not public in pkg.A</code>? [3]</>} solution={<>The class was found, but access control rejected the call. Check the method modifier and whether caller and member are in different packages. Make the method public only if it should be part of the package's public API. [3]</>} />
  <SubQuestion part="c" prompt={<>Distinguish an import from a classpath. [4]</>} solution={<>An import affects how a source file resolves a short type name. A classpath names roots from which compiled classes and packages are located. An import cannot repair a missing runtime classpath, and a classpath does not resolve two ambiguous simple imports. [4]</>} />
</ExamQuestion>
## Source identity versus lookup

<ExamQuestion title="Question 5: A moved source file [12 marks]">
  <SubQuestion part="a" prompt={<>A public A.java declares <code>package pkg;</code> but is saved at <code>scratch/A.java</code>. It is explicitly compiled with <code>javac -d classes scratch/A.java</code>. State its fully qualified name and output path. [4]</>} solution={<>The declaration gives identity <code>pkg.A</code> (2); output is <code>classes/pkg/A.class</code> (2). The input location does not rename the type.</>} />
  <SubQuestion part="b" prompt={<>A second build specifies only the Tester entry point and <code>-sourcepath src</code>. Explain why it may fail to discover that A source. [4]</>} solution={<>Lookup requests pkg.A (1), maps that to pkg/A.java (1), prepends src (1), and does not find src/pkg/A.java when the only source is in scratch (1). Another correctly available compiled definition could still satisfy the dependency.</>} />
  <SubQuestion part="c" prompt={<>Repair the layout, then explain why moving the file alone does not change its namespace. [4]</>} solution={<>Place it at src/pkg/A.java for normal lookup (2); the declaration, rather than the physical directory alone, determines its identity (2).</>} />
</ExamQuestion>

## Imports in the Book-record task

<ExamQuestion title="Question 6: File input and Book objects [16 marks]">
  <SubQuestion part="a" prompt={<>Write imports for FileReader, BufferedReader, IOException and Scanner. Explain why one java.io wildcard does not cover every type. [5]</>} solution={<>One mark for each correct full type import (4); Scanner belongs to java.util, a different package (1). Separate java.io and java.util wildcards also work.</>} />
  <SubQuestion part="b" prompt={<>The input contains Algorithms|120.50 and Networks|99.00. Trace these into an initially empty Book[50] using a populated count. Distinguish array objects from Book objects. [6]</>} solution={<>Initial count 0 and cells null (1); store first new Book at 0/count 1 (1); store second at 1/count 2 (1); stop at EOF (1); two Book objects and a separate array object (1); remaining cells 2–49 null (1).</>} />
  <SubQuestion part="c" prompt={<>Explain capacity-first short-circuit evaluation and why the display loop uses the populated count. [5]</>} solution={<>The capacity test guards a legal store (1); false skips further reading (1); EOF must be checked before parsing (1); unfilled cells are null (1); display only indices below count to avoid an accessor call through null (1).</>} />
</ExamQuestion>

## Conflict and static-member reasoning

<ExamQuestion title="Question 7: Name resolution repairs [12 marks]">
  <SubQuestion part="a" prompt={<>Distinguish two conflicting single-type Date imports from two wildcard imports that both contain Date. Repair use of both Date types. [5]</>} solution={<>Two single-type imports conflict immediately (1); two wildcards may coexist (1), but an ambiguous simple Date use fails (1); keep one single-type import and fully qualify the other Date (2).</>} />
  <SubQuestion part="b" prompt={<>Explain normal Math versus static sqrt imports and show a valid call for each. [4]</>} solution={<>Normal import names the type (1), Math.sqrt(81) call (1); static import names the member (1), sqrt(81) call (1).</>} />
  <SubQuestion part="c" prompt={<>Does java.util.* provide java.util.concurrent.TimeUnit? Give a correct explicit import. [3]</>} solution={<>No (1); subpackage is separate (1); import java.util.concurrent.TimeUnit; (1).</>} />
</ExamQuestion>

## Combined build and access diagnosis

<ExamQuestion title="Question 8: Four different failures [16 marks]">
  <SubQuestion part="a" prompt={<>Trace the constructed path for <code>java -cp classes/app app.Tester</code> and repair it. [4]</>} solution={<>Root classes/app (1) plus app/Tester.class (1) requests classes/app/app/Tester.class (1); use root classes (1).</>} />
  <SubQuestion part="b" prompt={<>Why may <code>java -cp classes/app Tester</code> fail even though Tester.class is present? [4]</>} solution={<>File may be found (1); requested identity Tester (1) differs from app.Tester in bytecode (1); use java -cp classes app.Tester (1).</>} />
  <SubQuestion part="c" prompt={<>A is public but its constructor is package-private. Can app.Tester instantiate it? [4]</>} solution={<>No (1); type visibility is separate from constructor access (1); pkg and app differ (1); make the constructor public if it is meant as an external API (1).</>} />
  <SubQuestion part="d" prompt={<>What does “Main method not found” establish that “Could not find or load main class” does not? [4]</>} solution={<>The selected class was found (2); the required public static void main(String[] args) entry point is absent or has the wrong signature (2).</>} />
</ExamQuestion>

## API boundaries

<ExamQuestion title="Question 9: Package peers and subclasses [12 marks]">
  <SubQuestion part="a" prompt={<>Can school.people.helpers call a package-private method in school.people? Explain. [3]</>} solution={<>No (1); exact package names differ (1); subpackage spelling does not inherit package-private access (1).</>} />
  <SubQuestion part="b" prompt={<>B in pkg calls A's package-private tripled method and returns the result through its own public wrapper. Explain why app.Tester may call that wrapper without directly calling tripled. [5]</>} solution={<>B and A share pkg (1); internal call allowed (1); B's wrapper is public (1); app can call the accessible public API (1); imports do not open tripled itself (1).</>} />
  <SubQuestion part="c" prompt={<>Explain why an outside subclass may access a protected instance member through this or a suitable subclass receiver but not an arbitrary Base receiver. [4]</>} solution={<>Protected external access requires an inheritance context (1); caller qualifies as a subclass (1); receiver restriction is also checked (1); an arbitrary Base reference does not satisfy that restriction (1).</>} />
</ExamQuestion>
