## Package and import concepts

<ExamQuestion title="Question 1: Built-in packages and imports [12 marks]">
  <SubQuestion part="a" prompt={<>Define a Java package and give two benefits. [4]</>} solution={<>A package is a named group or namespace for related types. It organises code, reduces simple-name conflicts, supports access control, and makes large programs easier to maintain. Any definition and two developed benefits earn the marks. [4]</>} />
  <SubQuestion part="b" prompt={<>Give the fully qualified names of <code>Scanner</code>, <code>ArrayList</code>, and <code>BufferedReader</code>. [3]</>} solution={<><code>java.util.Scanner</code>, <code>java.util.ArrayList</code>, and <code>java.io.BufferedReader</code>. [3]</>} />
  <SubQuestion part="c" prompt={<>Explain why <code>import java.util.*;</code> does not import <code>java.util.concurrent.TimeUnit</code>. [3]</>} solution={<>The wildcard covers types declared directly in <code>java.util</code>. A subpackage is a separate package and is not recursively included. [3]</>} />
  <SubQuestion part="d" prompt={<>Why can <code>String</code> be used without an explicit import? [2]</>} solution={<><code>String</code> belongs to <code>java.lang</code>, which Java makes available automatically. [2]</>} />
</ExamQuestion>

## User-defined package structure

<ExamQuestion title="Question 2: Design a package tree [14 marks]">
  <SubQuestion part="a" prompt={<>Draw the source tree for <code>school.people.Student</code>, <code>school.people.Lecturer</code>, and <code>school.app.Main</code> below a source root named <code>src</code>. [5]</>} solution={<>Place <code>Student.java</code> and <code>Lecturer.java</code> in <code>src/school/people</code>, and <code>Main.java</code> in <code>src/school/app</code>. Marks are for the package path, filenames, and shared source root. [5]</>} />
  <SubQuestion part="b" prompt={<>Write the package declaration for each file. [3]</>} solution={<><code>Student.java</code> and <code>Lecturer.java</code> begin with <code>package school.people;</code>. <code>Main.java</code> begins with <code>package school.app;</code>. [3]</>} />
  <SubQuestion part="c" prompt={<>Write imports in <code>Main.java</code> for the other two classes. [2]</>} solution={<><code>import school.people.Student;</code> and <code>import school.people.Lecturer;</code>. [2]</>} />
  <SubQuestion part="d" prompt={<>A method in <code>Student</code> has no access modifier. Can <code>Main</code> call it? Explain. [4]</>} solution={<>No. With no modifier the method is package-private. <code>Main</code> is in <code>school.app</code>, a different package from <code>school.people</code>. Make the method public if it belongs to the external API. [4]</>} />
</ExamQuestion>

## Compilation and runtime lookup

<ExamQuestion title="Question 3: Compile and run [14 marks]">
  <SubQuestion part="a" prompt={<>From the project root, write a command that compiles <code>src/school/app/Main.java</code>, finds source dependencies below <code>src</code>, and writes class files below <code>classes</code>. [4]</>} solution={<><code>javac -d classes -sourcepath src src/school/app/Main.java</code>. [4]</>} />
  <SubQuestion part="b" prompt={<>Write the command that runs the packaged main class. [3]</>} solution={<><code>java -cp classes school.app.Main</code>. The classpath is the output root, while the target is the fully qualified class name. [3]</>} />
  <SubQuestion part="c" prompt={<>Predict the output path of <code>Main.class</code>. [2]</>} solution={<><code>classes/school/app/Main.class</code>. [2]</>} />
  <SubQuestion part="d" prompt={<>A student runs <code>java -cp classes Main</code> and receives “Could not find or load main class Main”. Diagnose and repair it. [5]</>} solution={<>The runtime command uses the wrong binary name. The bytecode declares package <code>school.app</code>, so Java must be started from the classpath root with <code>java -cp classes school.app.Main</code>. [5]</>} />
</ExamQuestion>

## Debugging

<ExamQuestion title="Question 4: Classify the failure [10 marks]">
  <SubQuestion part="a" prompt={<>What should you check first for <code>package pkg does not exist</code>? [3]</>} solution={<>Check the imported package spelling, the dependency's package declaration and matching path, and whether the compiler's source path or classpath points at the correct root. [3]</>} />
  <SubQuestion part="b" prompt={<>What should you check for <code>doubled() is not public in pkg.A</code>? [3]</>} solution={<>The class was found, but access control rejected the call. Check the method modifier and whether caller and member are in different packages. Make the method public only if it should be part of the package's public API. [3]</>} />
  <SubQuestion part="c" prompt={<>Distinguish an import from a classpath. [4]</>} solution={<>An import affects how a source file resolves a short type name. A classpath names roots from which compiled classes and packages are located. An import cannot repair a missing runtime classpath, and a classpath does not resolve two ambiguous simple imports. [4]</>} />
</ExamQuestion>
