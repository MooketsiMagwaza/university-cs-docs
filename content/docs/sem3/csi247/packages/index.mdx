## Java packages

A **package** groups related types under a shared name. Packages make a growing program easier to navigate, prevent unrelated classes from colliding on the same simple name, and create an access boundary for package-private members.

## Chapter outcomes

- Distinguish built-in and user-defined packages.
- Read and write single-type, wildcard, and fully qualified references.
- Build a source tree whose folders match package declarations.
- Compile packaged source into a separate classes directory.
- Run a packaged class with the correct classpath root and fully qualified name.
- Diagnose common package, import, access, and classpath errors.
