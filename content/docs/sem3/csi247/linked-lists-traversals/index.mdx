A linked list stores each element inside a **node**. Nodes can live in different heap locations; references create their logical order.

There is no index calculation. To reach 41, begin at head and follow two links.

## 2. Generic node and list

~~~java
public class Node<T> {
    T data;
    Node<T> next;

    Node(T data, Node<T> next) {
        this.data = data;
        this.next = next;
    }
}

public class SinglyLinkedList<T> {
    private Node<T> head;
    private int size;
}
~~~

## 3. Insert at the front

~~~java
public void addFirst(T value) {
    head = new Node<>(value, head);
    size++;
}
~~~

| Statement | head | new node's next | visible list |
|---|---|---|---|
| before | node 12 | — | 12 → 27 → null |
| construct Node(5, head) | still node 12 | node 12 | 5 → 12 → 27 inside new chain |
| assign to head | node 5 | node 12 | 5 → 12 → 27 → null |

Order matters: preserve the old head reference inside the new node before replacing head.

## 4. Traverse and search

~~~java
public boolean contains(T target) {
    Node<T> current = head;

    while (current != null) {
        if (Objects.equals(current.data, target)) {
            return true;
        }
        current = current.next;
    }
    return false;
}
~~~

| iteration | current.data | comparison with 27 | next current |
|---:|---:|---|---:|
| 1 | 12 | false | 27 |
| 2 | 27 | true | return |

## 5. Remove the first occurrence

Handle the head separately; otherwise keep both the node before the target and the current target.

~~~java
public boolean remove(T target) {
    if (head == null) return false;
    if (Objects.equals(head.data, target)) {
        head = head.next;
        size--;
        return true;
    }

    Node<T> previous = head;
    Node<T> current = head.next;
    while (current != null) {
        if (Objects.equals(current.data, target)) {
            previous.next = current.next; // Bypass current.
            size--;
            return true;
        }
        previous = current;
        current = current.next;
    }
    return false;
}
~~~

## 6. Variants and cost

| Variant | Extra links | Benefit |
|---|---:|---|
| singly linked | next | simplest forward traversal |
| doubly linked | previous + next | movement/removal in either direction |
| circular | tail links to head | natural repeated cycles; no terminal null |

| Operation | With head only | With head and tail |
|---|---:|---:|
| add first | O(1) | O(1) |
| remove first | O(1) | O(1) |
| get by index | O(N) | O(N) |
| add last | O(N) | O(1) |
| search by value | O(N) | O(N) |
