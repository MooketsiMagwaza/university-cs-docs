Seven questions, grouped by what they test, each with its marks. Work a question on paper before opening the solution. The lessons that teach each form are [Classes by Example](/docs/sem3/csi247/06-object-oriented-programming/notes/classes-by-example), [Inheritance and Overriding by Example](/docs/sem3/csi247/06-object-oriented-programming/notes/inheritance-by-example), [Abstraction, Polymorphism and Interfaces by Example](/docs/sem3/csi247/06-object-oriented-programming/notes/abstraction-and-interfaces-by-example), [OOP Labs by Example](/docs/sem3/csi247/06-object-oriented-programming/notes/oop-labs-by-example) and [OOP Exam Practice](/docs/sem3/csi247/06-object-oriented-programming/notes/oop-exam-practice), which has eight more.

**Marking guide.** A full-credit answer names the class that supplies each method, gives the exact compiler message for a fault (a private member, a missing constructor, a weaker access privilege, an abstract class), draws or describes every object created by `new` and every address, and states the output of a trace line by line.
