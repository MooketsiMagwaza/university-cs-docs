Object-oriented design models a system as interacting objects with state and behaviour. Lecture 11 develops four connected ideas: reuse common code with inheritance, protect state with encapsulation, select behaviour at runtime with polymorphism, and expose contracts through abstraction.

<LearningObjectives items={[
  "Move shared state into a superclass, trace construction, and distinguish inherited members from private representation",
  "Separate reference type from runtime object type, and trace dynamic dispatch through overridden methods",
  "Protect object invariants with a public interface, and separate what a type promises from how it performs the work",
  "Choose between a shared base implementation and a capability contract, then trace concrete implementations and interface references",
]} />

<Prerequisites items={[
  "Classes, objects, and references in Java, from the Java Programming Recap topic",
]} />
