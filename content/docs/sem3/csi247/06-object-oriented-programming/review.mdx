## The five checks

1. Is the constructor the right one (same name as the class, no return type), and does it call `this(...)` or `super(...)` first?
2. Is the member `private` or `public`, and can the class that uses it see it?
3. Which signature does the compiler choose from the static types, and which class supplies the method at run time?
4. Is the class abstract, and does every concrete sub class implement each abstract method with `public` access?
5. Are objects compared with `equals`, and does a variable hold an address (an alias) rather than a copy?
