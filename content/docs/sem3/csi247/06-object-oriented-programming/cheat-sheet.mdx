## 1. Placeholders used in every template on this page

| Placeholder | Meaning | Example |
|---|---|---|
| `ClassName` | the class being written | `Account` |
| `Super` / `Sub` | a super class and a sub class | `Shape` / `Circle` |
| `type` | a data type | `int`, `double`, `String` |
| `x` | an instance variable | `balance` |
| `m(...)` | a method call | `getArea()` |

## 2. The class skeleton (Lecture 4)

```text
// import statements
public class ClassName {            saved as ClassName.java; the name starts with an upper-case letter
    // instance variables            private type x;
    // constructors                  public ClassName(type p) { this.x = p; }
    // other methods                 public void setX(type p) { x = p; }     public type getX() { return x; }
}
```

| Part | Rule |
|---|---|
| Instance variable | declared in the class, outside any method; usually `private`; each object has its own value |
| Constructor | same name as the class, no return type; may be overloaded; `this(...)` calls another; Java adds a default one only when you write none |
| Setter / getter | a setter is `void` and changes a variable; a getter ends with a `return` of the declared type |
| `this` | the object itself: `this.x = x` when a parameter has the variable's name (without it the statement copies the parameter onto itself) |
| Test | a separate class with `main` creates objects and calls the methods; argument types must be compatible with the parameters |
| Signature | name plus parameter types, e.g. `xyz(int,double)`; the return type is not part of it |
| Overloading | same name, different signatures; `void ABC(int,double)` and `int ABC(int,double)` clash |
| UML class box | name; instance variables; methods; `-` private, `+` public; `name: type` and `method(p: type): returnType` |

## 3. Inheritance and the Object methods (Lecture 11)

```text
public class Sub extends Super {
    public Sub(...) { super(...); ... }          super(...) is the first statement
    @Override
    public ReturnType method(sameParameters) { ... super.method() ... }
}
```

| Topic | Rule |
|---|---|
| A sub class can | inherit public members, add variables and methods, override methods |
| A sub class cannot | remove members, use inherited private members directly, inherit constructors |
| Types | single, hierarchical, multi-level; a class extends only one class; the root of the tree is `Object` |
| UML | a line with the arrow at the super class |
| Overriding rules | inheritance (is-a); same name, return type and signature; no weaker access; `@Override` checks |
| Partial overriding | `super.method()`; the returned value must be used |
| `toString` | default is `ClassName@hash`; printing a reference calls it |
| `equals` | default is `==`; override `equals(Object)`: same object, `null` or another class, then cast and compare |
| `instanceof` / cast | `obj instanceof T` is false for `null`; a downcast needs `(T) obj` and can throw `ClassCastException` |
| Wrappers | `Integer n1 = 7;` autoboxing; `int i = n1;` unboxing; compare with `equals`, not `==` |

## 4. Encapsulation, polymorphism and abstraction

| Feature | Meaning | In Java |
|---|---|---|
| Encapsulation | hide the data, show a small part | `private` variables and `public` getters and setters |
| Polymorphism | one call, the method of the object's class | overriding (dynamic) and overloading (static) |
| Abstraction | what, not how | an abstract class or an interface |

| Access modifier | Visibility |
|---|---|
| `public` (+) | everywhere |
| `protected` (#) | the class, its package and its sub classes |
| default | the package |
| `private` (-) | the class only |

```text
Abstract class:   public abstract class Shape { public abstract double getArea(); }     cannot be instantiated
Interface:        public interface Test { void methodA(); }                              public abstract methods, constants only
Implement:        class Bob implements Test { public void methodA() { ... } }           implementing methods must be public
Many interfaces:  class Multi implements InterfaceA, InterfaceB { ... }
Extend:           interface Aa extends Bb, Cc { }                                        a class extends only one class
```

## 5. One program that uses most of it

```java title="OopCheat.java"
public class OopCheat {
    interface Describable {
        String describe();
    }

    static abstract class Shape implements Describable {
        private String colour;

        Shape(String colour) {
            this.colour = colour;
        }

        String getColour() {
            return colour;
        }

        abstract double getArea();

        public String describe() {
            return colour + " " + getClass().getSimpleName() + " " + String.format("%.1f", getArea());
        }

        @Override
        public boolean equals(Object o) {
            if (o == this)
                return true;
            if (o == null || getClass() != o.getClass())
                return false;
            Shape other = (Shape) o;
            return colour.equals(other.colour) && getArea() == other.getArea();
        }
    }

    static class Circle extends Shape {
        private int radius;

        Circle(String colour, int radius) {
            super(colour);
            this.radius = radius;
        }

        double getArea() {
            return Math.PI * radius * radius;
        }
    }

    static class Square extends Shape {
        private int side;

        Square(String colour, int side) {
            super(colour);
            this.side = side;
        }

        double getArea() {
            return side * side;
        }

        @Override
        public String describe() {
            return "Sq " + super.describe();                 // partial overriding
        }
    }

    public static void main(String[] args) {
        Shape[] shapes = {new Circle("Red", 2), new Square("Blue", 3)};
        for (Shape s : shapes) {
            System.out.println(s.describe());                // the method of the object's own class
        }
        System.out.println(shapes[0].equals(new Circle("Red", 2)) + " " + shapes[0].equals(shapes[1]));
        System.out.println((shapes[1] instanceof Square) + " " + (shapes[1] instanceof Circle));
    }
}
```

```text
Red Circle 12.6
Sq Blue Square 9.0
true false
true false
```

## 7. Common errors

| Mistake | What javac reports | Repair |
|---|---|---|
| `new Account()` with only `Account(int, double)` | `constructor Account in class Account cannot be applied to given types` | add a no-argument constructor |
| a sub class constructor without `super(...)`, super class has no no-argument constructor | `constructor Base in class Base cannot be applied to given types` | `super(args);` |
| a sub class uses the super class's private variable | `colour has private access in Shape` | use the getter, or `protected` |
| `Rectangle r = new Shape();` or `Circle c = sh;` | `incompatible types: Shape cannot be converted to Rectangle` | use the sub class object, or cast |
| `toString()` without `public` in a sub class | `attempting to assign weaker access privileges; was public` | `public String toString()` |
| `@Override` with no super class method | `method does not override or implement a method from a supertype` | match the signature |
| overriding with another return type | `return type int is not compatible with String` | keep the return type |
| overriding a `final` method | `overridden method is final` | do not override it |
| `new Shape()` for an abstract class | `Shape is abstract; cannot be instantiated` | create a concrete sub class |
| a concrete class does not implement an abstract or interface method | `is not abstract and does not override abstract method` | implement it |
| `abstract void bark() { }` | `abstract methods cannot have a body` | end with `;` |
| implementing an interface method without `public` | `cannot implement ... attempting to assign weaker access privileges` | add `public` |
| `class Two extends A, B` | `'{' expected` | extend one class, implement the others |
| `super.toString();` alone | compiles, no effect | use the returned value |
| `Shape.equals(Shape)` plus a sub class `equals(Object)` | the overload is chosen for a `Shape` argument | one `equals(Object)` in the base class |
