## 16. Check the evidence

To compare countdown and list factorials, use the same valid indices and the same negative-input policy. An ordinary list range can be empty for a negative endpoint, but that does not make negative factorial valid.

<HaskellTryIt>

```haskell

factCountdown n
  | n < 0 = Nothing
  | otherwise = Just (down n)
  where
    down 0 = 1
    down k = k * down (k - 1)
factProduct :: Integer -> Maybe Integer
factProduct n
  | n < 0 = Nothing
  | otherwise = Just (between 1 n)
  where
    between a b
      | a > b = 1
      | otherwise = a * between (a + 1) b
productList :: [Integer] -> Integer
productList [] = 1
productList (x:xs) = x * productList xs
factViaList :: Integer -> Maybe Integer
factViaList n
  | n < 0 = Nothing
  | otherwise = Just (productList [1..n])
doubleFact :: Integer -> Maybe Integer
doubleFact n
  | n < 0 = Nothing
  | otherwise = Just (down n)
  where
    down k
      | k <= 1 = 1
      | otherwise = k * down (k - 2)

main :: IO ()
main = print (([factCountdown n == factViaList n | n <- [0..5]], factCountdown (-1) == factViaList (-1)))

```
