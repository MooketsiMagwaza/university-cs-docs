A template uses descriptive placeholders such as `update` or `predicate`: replace them by the function given in the question. LAM replaces a parameter by its argument; OP changes prefix operator application to infix notation; SEC-R inserts an argument into a right section. IF-T and IF-F select the branch after the test has been calculated. List and string notation only change spelling. A let-substitution replaces a local name by its value; a let pair match binds both tuple fields. Error messages below are diagnostic excerpts rather than complete compiler transcripts, which vary with GHC version.

These are value calculations for finite observations, not a specification of the compiler's internal evaluation order. In particular, infinite values must be observed finitely.

## 1. Repeated updates with `iterate`

`iterate` produces an unbounded list starting with a seed. Each following value is obtained by applying the update function once to the previous value. Observe a finite prefix with `take`.

**Template:** `take count (iterate update seed)`. `count` limits the observation, `update` advances one step, and `seed` is the first value.

Labelled equations for paper traces:

```text
iterate :: (a -> a) -> a -> [a]
iterate f x = x : iterate f (f x) -- IT
take n xs | n <= 0 = [] -- T0
take n [] = [] -- T1
take n (x:xs) = x : take (n-1) xs -- T2, for n > 0
```

### A section advances the state

<HaskellTryIt>

```haskell
main :: IO ()
main = print (take 3 (iterate (+2) 1))
```

```text
[1,3,5]
```

</HaskellTryIt>

```text
take 3 (iterate (+2) 1) -- given call
= take 3 (1 : iterate (+2) ((+2) 1)) -- IT: x := 1
= 1 : take (3-1) (iterate (+2) ((+2) 1)) -- T2
= 1 : take 2 (iterate (+2) ((+2) 1)) -- subtraction
= 1 : take 2 (iterate (+2) (1 + 2)) -- SEC-R
= 1 : take 2 (iterate (+2) 3) -- addition
= 1 : take 2 (3 : iterate (+2) ((+2) 3)) -- IT: x := 3
= 1 : (3 : take (2-1) (iterate (+2) ((+2) 3))) -- T2
= 1 : (3 : take 1 (iterate (+2) ((+2) 3))) -- subtraction
= 1 : (3 : take 1 (iterate (+2) (3 + 2))) -- SEC-R
= 1 : (3 : take 1 (iterate (+2) 5)) -- addition
= 1 : (3 : take 1 (5 : iterate (+2) ((+2) 5))) -- IT: x := 5
= 1 : (3 : (5 : take (1-1) (iterate (+2) ((+2) 5)))) -- T2
= 1 : (3 : (5 : take 0 (iterate (+2) ((+2) 5)))) -- subtraction
= 1 : (3 : (5 : [])) -- T0: no further update demanded
= [1,3,5] -- list notation
```

The seed is included; it is not transformed before the first output.

### A lambda changing strings

<HaskellTryIt>

```haskell
main :: IO ()
main = print (take 2 (iterate (\s -> 'x' : s) ""))
```

```text
["","x"]
```

</HaskellTryIt>

```text
take 2 (iterate (\s -> 'x' : s) "") -- given call
= take 2 ("" : iterate (\s -> 'x' : s) ((\s -> 'x' : s) "")) -- IT
= "" : take (2-1) (iterate (\s -> 'x' : s) ((\s -> 'x' : s) "")) -- T2
= "" : take 1 (iterate (\s -> 'x' : s) ((\s -> 'x' : s) "")) -- subtraction
= "" : take 1 (iterate (\s -> 'x' : s) ('x' : "")) -- LAM: s := ""
= "" : take 1 (iterate (\s -> 'x' : s) "x") -- string notation
= "" : take 1 ("x" : iterate (\s -> 'x' : s) ((\s -> 'x' : s) "x")) -- IT
= "" : ("x" : take (1-1) (iterate (\s -> 'x' : s) ((\s -> 'x' : s) "x"))) -- T2
= "" : ("x" : take 0 (iterate (\s -> 'x' : s) ((\s -> 'x' : s) "x"))) -- subtraction
= "" : ("x" : []) -- T0
= ["","x"] -- list notation
```

The empty string is an actual first value.

### A zero-length observation

<HaskellTryIt>

```haskell
main :: IO ()
main = print (take 0 (iterate (*2) 3))
```

```text
[]
```

</HaskellTryIt>

```text
take 0 (iterate (*2) 3) -- given call
= [] -- T0: iterate is not demanded
```

An empty observation need not even start the iteration.

**Common error.** Trying to print the whole `iterate (+1) 0` does not finish, so there is no finite output transcript. Limit it with `take`; this is a termination issue, not a type error.

**Practice with answer.** `take 1 (iterate (*2) 7)` is `[7]`: IT, T2, subtraction, T0, list notation. The seed is the only observation.

| Observation index | State | Next update, if demanded |
|---|---|---|
| `0` | `1` | `1 + 2 = 3` |
| `1` | `3` | `3 + 2 = 5` |
| `2` | `5` | not needed by `take 3` |

## 2. Producing and flattening lists with `concatMap`

`concatMap` applies a function that returns a list to each input, then joins those result lists in input order. Unlike `map`, it does not keep a separate outer list around each result.

**Template:** `concatMap makeList inputList`. `makeList` can return zero, one or many elements for each input.

Labelled equations for paper traces:

```text
concatMap :: (a -> [b]) -> [a] -> [b]
concatMap f [] = [] -- CM0
concatMap f (x:xs) = f x ++ concatMap f xs -- CM1
[] ++ ys = ys -- A0
(x:xs) ++ ys = x : (xs ++ ys) -- A1
```

### A lambda duplicates a value

<HaskellTryIt>

```haskell
main :: IO ()
main = print (concatMap (\x -> [x,x]) [2])
```

```text
[2,2]
```

</HaskellTryIt>

```text
concatMap (\x -> [x,x]) [2] -- given call
= (\x -> [x,x]) 2 ++ concatMap (\x -> [x,x]) [] -- CM1
= [2,2] ++ concatMap (\x -> [x,x]) [] -- LAM: x := 2
= 2 : ([2] ++ concatMap (\x -> [x,x]) []) -- A1
= 2 : (2 : ([] ++ concatMap (\x -> [x,x]) [])) -- A1
= 2 : (2 : concatMap (\x -> [x,x]) []) -- A0
= 2 : (2 : []) -- CM0
= [2,2] -- list notation
```

One input can contribute more than one output.

### A partially applied function

<HaskellTryIt>

```haskell
main :: IO ()
main = print (concatMap (replicate 2) "ab")
```

```text
"aabb"
```

</HaskellTryIt>

```text
concatMap (replicate 2) "ab" -- given call
= replicate 2 'a' ++ concatMap (replicate 2) "b" -- CM1
= ('a' : replicate (2-1) 'a') ++ concatMap (replicate 2) "b" -- REP1
= ('a' : replicate 1 'a') ++ concatMap (replicate 2) "b" -- subtraction
= ('a' : ('a' : replicate (1-1) 'a')) ++ concatMap (replicate 2) "b" -- REP1
= ('a' : ('a' : replicate 0 'a')) ++ concatMap (replicate 2) "b" -- subtraction
= ('a' : ('a' : [])) ++ concatMap (replicate 2) "b" -- REP0
= 'a' : (['a'] ++ concatMap (replicate 2) "b") -- A1
= 'a' : ('a' : ([] ++ concatMap (replicate 2) "b")) -- A1
= 'a' : ('a' : concatMap (replicate 2) "b") -- A0
= 'a' : ('a' : (replicate 2 'b' ++ concatMap (replicate 2) "")) -- CM1
= 'a' : ('a' : (('b' : replicate (2-1) 'b') ++ concatMap (replicate 2) "")) -- REP1
= 'a' : ('a' : (('b' : replicate 1 'b') ++ concatMap (replicate 2) "")) -- subtraction
= 'a' : ('a' : (('b' : ('b' : replicate (1-1) 'b')) ++ concatMap (replicate 2) "")) -- REP1
= 'a' : ('a' : (('b' : ('b' : replicate 0 'b')) ++ concatMap (replicate 2) "")) -- subtraction
= 'a' : ('a' : (('b' : ('b' : [])) ++ concatMap (replicate 2) "")) -- REP0
= 'a' : ('a' : ('b' : (['b'] ++ concatMap (replicate 2) ""))) -- A1
= 'a' : ('a' : ('b' : ('b' : ([] ++ concatMap (replicate 2) "")))) -- A1
= 'a' : ('a' : ('b' : ('b' : concatMap (replicate 2) ""))) -- A0
= 'a' : ('a' : ('b' : ('b' : []))) -- CM0
= "aabb" -- string notation
```

The rule repeats each character twice. REP0 and REP1 are given in the replicate section below.

### An empty input

## 3. Splitting an initial run with `span`

`span` returns both the longest passing prefix and the remaining suffix. It stops at the first failure; it does not collect all matching elements from later positions.

**Template:** `span predicate inputList`. The result is a pair `(passingPrefix, remainder)`.

Labelled equations for paper traces:

```text
span :: (a -> Bool) -> [a] -> ([a],[a])
span p [] = ([],[]) -- SP0
span p (x:xs) =
  if p x then let (ys,zs) = span p xs in (x:ys,zs)
         else ([],x:xs) -- SP1
```

### A failure followed by another success

<HaskellTryIt>

```haskell
main :: IO ()
main = print (span (<3) [1,4,2])
```

```text
([1],[4,2])
```

</HaskellTryIt>

```text
span (<3) [1,4,2] -- given call
= if (<3) 1 then let (ys,zs) = span (<3) [4,2] in (1:ys,zs) else ([],[1,4,2]) -- SP1
= if 1 < 3 then let (ys,zs) = span (<3) [4,2] in (1:ys,zs) else ([],[1,4,2]) -- SEC-R
= if True then let (ys,zs) = span (<3) [4,2] in (1:ys,zs) else ([],[1,4,2]) -- comparison
= let (ys,zs) = span (<3) [4,2] in (1:ys,zs) -- IF-T
= let (ys,zs) = (if (<3) 4 then let (us,vs) = span (<3) [2] in (4:us,vs) else ([],[4,2])) in (1:ys,zs) -- SP1
= let (ys,zs) = (if 4 < 3 then let (us,vs) = span (<3) [2] in (4:us,vs) else ([],[4,2])) in (1:ys,zs) -- SEC-R
= let (ys,zs) = (if False then let (us,vs) = span (<3) [2] in (4:us,vs) else ([],[4,2])) in (1:ys,zs) -- comparison
= let (ys,zs) = ([],[4,2]) in (1:ys,zs) -- IF-F
= (1:[],[4,2]) -- let pair match: ys := [], zs := [4,2]
= ([1],[4,2]) -- list notation
```

The later 2 belongs to the remainder, although it would pass the predicate.

## 4. Splitting before a match with `break`

`break` cuts a list just before its first matching element. The matching element belongs to the remainder. It is `span` with the predicate negated.

**Template:** `break predicate inputList`. Keep a prefix while the predicate is false; stop when it becomes true.

Labelled equations for paper traces:

```text
break :: (a -> Bool) -> [a] -> ([a],[a])
break p xs = span (not . p) xs -- BR
(f . g) x = f (g x) -- COMP
not True = False -- NOT-T
not False = True -- NOT-F
```

### Breaking at the first element

<HaskellTryIt>

```haskell
main :: IO ()
main = print (break even [2,3])
```

```text
([],[2,3])
```

</HaskellTryIt>

```text
break even [2,3] -- given call
= span (not . even) [2,3] -- BR
= if (not . even) 2 then let (ys,zs) = span (not . even) [3] in (2:ys,zs) else ([],[2,3]) -- SP1
= if not (even 2) then let (ys,zs) = span (not . even) [3] in (2:ys,zs) else ([],[2,3]) -- COMP
= if not True then let (ys,zs) = span (not . even) [3] in (2:ys,zs) else ([],[2,3]) -- EVEN
= if False then let (ys,zs) = span (not . even) [3] in (2:ys,zs) else ([],[2,3]) -- NOT-T
= ([],[2,3]) -- IF-F
```

The matching 2 is included in the second part.

### No matching element

<HaskellTryIt>

```haskell
main :: IO ()
main = print (break (>3) [1])
```

```text
([1],[])
```

</HaskellTryIt>

```text
break (>3) [1] -- given call
= span (not . (>3)) [1] -- BR
= if (not . (>3)) 1 then let (ys,zs) = span (not . (>3)) [] in (1:ys,zs) else ([],[1]) -- SP1
= if not ((>3) 1) then let (ys,zs) = span (not . (>3)) [] in (1:ys,zs) else ([],[1]) -- COMP
= if not (1 > 3) then let (ys,zs) = span (not . (>3)) [] in (1:ys,zs) else ([],[1]) -- SEC-R
= if not False then let (ys,zs) = span (not . (>3)) [] in (1:ys,zs) else ([],[1]) -- comparison
= if True then let (ys,zs) = span (not . (>3)) [] in (1:ys,zs) else ([],[1]) -- NOT-F
= let (ys,zs) = span (not . (>3)) [] in (1:ys,zs) -- IF-T
= let (ys,zs) = ([],[]) in (1:ys,zs) -- SP0
= (1:[],[]) -- let pair match
= ([1],[]) -- list notation
```

An absent match leaves the whole finite input in the first part.

### An empty input

<HaskellTryIt>


## 5. Separating every element with `partition`

`partition` sends every element to one of two lists: passing elements first, failing elements second. It preserves the original order within each part, and unlike `span` it examines the whole finite input.

**Template:** `partition predicate inputList`. Import `partition` from `Data.List`; the result is a pair of lists.

Labelled equations for paper traces:

```text
partition :: (a -> Bool) -> [a] -> ([a],[a])
partition p [] = ([],[]) -- P0
partition p (x:xs) =
  let (ys,zs) = partition p xs
  in if p x then (x:ys,zs) else (ys,x:zs) -- P1
```

### A match after a failure

<HaskellTryIt>

```haskell
import Data.List (partition)

main :: IO ()
main = print (partition even [1,2])
```

```text
([2],[1])
```

</HaskellTryIt>

```text
partition even [1,2] -- given call
= let (ys,zs) = partition even [2] in if even 1 then (1:ys,zs) else (ys,1:zs) -- P1
= let (ys,zs) = partition even [2] in if False then (1:ys,zs) else (ys,1:zs) -- EVEN
= let (ys,zs) = partition even [2] in (ys,1:zs) -- IF-F
= let (ys,zs) = (let (us,vs) = partition even [] in if even 2 then (2:us,vs) else (us,2:vs)) in (ys,1:zs) -- P1
= let (ys,zs) = (let (us,vs) = ([],[]) in if even 2 then (2:us,vs) else (us,2:vs)) in (ys,1:zs) -- P0
= let (ys,zs) = (if even 2 then (2:[],[]) else ([],2:[])) in (ys,1:zs) -- let pair match
= let (ys,zs) = (if True then (2:[],[]) else ([],2:[])) in (ys,1:zs) -- EVEN
= let (ys,zs) = (2:[],[]) in (ys,1:zs) -- IF-T
= (2:[],1:[]) -- let pair match
= ([2],[1]) -- list notation
```

The first failed test does not stop the traversal.

### A lambda on a singleton

<HaskellTryIt>


</HaskellTryIt>

```text
partition (\x -> x > 0) [3] -- given call
= let (ys,zs) = partition (\x -> x > 0) [] in if (\x -> x > 0) 3 then (3:ys,zs) else (ys,3:zs) -- P1
= let (ys,zs) = ([],[]) in if (\x -> x > 0) 3 then (3:ys,zs) else (ys,3:zs) -- P0
= if (\x -> x > 0) 3 then (3:[],[]) else ([],3:[]) -- let pair match
= if 3 > 0 then (3:[],[]) else ([],3:[]) -- LAM: x := 3
= if True then (3:[],[]) else ([],3:[]) -- comparison
= (3:[],[]) -- IF-T
= ([3],[]) -- list notation
```

All input values pass here.

## 6. Retaining three fields with `zip3`

`zip3` walks three lists at the same time and keeps a triple at each position. It stops at the shortest input.

**Template:** `zip3 firstList secondList thirdList`. The three input element types may differ.

Labelled equations for paper traces:

```text
zip3 :: [a] -> [b] -> [c] -> [(a,b,c)]
zip3 [] ys zs = [] -- Z30
zip3 xs [] zs = [] -- Z31
zip3 xs ys [] = [] -- Z32
zip3 (x:xs) (y:ys) (z:zs) = (x,y,z) : zip3 xs ys zs -- Z33
```

### Mixed types and unequal lengths

<HaskellTryIt>

```haskell
main :: IO ()
main = print (zip3 [1,2] "a" [True,False])
```

```text
[(1,'a',True)]
```

</HaskellTryIt>

```text
zip3 [1,2] "a" [True,False] -- given call
= (1,'a',True) : zip3 [2] "" [False] -- Z33: x := 1, y := 'a', z := True
= (1,'a',True) : [] -- Z31
= [(1,'a',True)] -- list notation
```

The second input determines the output length.

### An empty third list

<HaskellTryIt>

```haskell
main :: IO ()
main = print (zip3 [1] [True] ([] :: [Char]))
```

```text
[]
```

</HaskellTryIt>

```text
zip3 [1] [True] ([] :: [Char]) -- given call
= [] -- Z32
```

No complete triple exists.

### Three singleton lists

<HaskellTryIt>

```haskell
main :: IO ()
main = print (zip3 ["Ada"] [80] [True])
```

```text
[("Ada",80,True)]
```

</HaskellTryIt>

```text
zip3 ["Ada"] [80] [True] -- given call
= ("Ada",80,True) : zip3 [] [] [] -- Z33
= ("Ada",80,True) : [] -- Z30
= [("Ada",80,True)] -- list notation
```

A triple retains all three fields.

**Common error.** Expecting a pair of a pair and a value confuses `zip3 xs ys zs` with `zip (zip xs ys) zs`. Both type-check but have different types and shapes; GHC gives no value-error diagnostic.

**Practice with answer.** `zip3 ([] :: [Int]) "x" [True]` is `[]` by Z30.

## 7. Combining three positions with `zipWith3`

`zipWith3` applies a three-argument function to matching positions. It returns the results rather than the triples, and also stops at the shortest input.

**Template:** `zipWith3 combine firstList secondList thirdList`. `combine` must accept one value from each list, in that order.

Labelled equations for paper traces:

```text
zipWith3 :: (a -> b -> c -> d) -> [a] -> [b] -> [c] -> [d]
zipWith3 f [] ys zs = [] -- W30
zipWith3 f xs [] zs = [] -- W31
zipWith3 f xs ys [] = [] -- W32
zipWith3 f (x:xs) (y:ys) (z:zs) = f x y z : zipWith3 f xs ys zs -- W33
```

### A lambda with three substitutions

<HaskellTryIt>

```haskell
main :: IO ()
main = print (zipWith3 (\x y z -> x + y * z) [1,9] [2] [3,8])
```

```text
[7]
```

</HaskellTryIt>

```text
zipWith3 (\x y z -> x + y * z) [1,9] [2] [3,8] -- given call
= (\x y z -> x + y * z) 1 2 3 : zipWith3 (\x y z -> x + y * z) [9] [] [8] -- W33
= (\y z -> 1 + y * z) 2 3 : zipWith3 (\x y z -> x + y * z) [9] [] [8] -- LAM: x := 1
= (\z -> 1 + 2 * z) 3 : zipWith3 (\x y z -> x + y * z) [9] [] [8] -- LAM: y := 2
= (1 + 2 * 3) : zipWith3 (\x y z -> x + y * z) [9] [] [8] -- LAM: z := 3
= (1 + 6) : zipWith3 (\x y z -> x + y * z) [9] [] [8] -- multiplication
= 7 : zipWith3 (\x y z -> x + y * z) [9] [] [8] -- addition
= 7 : [] -- W31
= [7] -- list notation
```

Each list supplies one lambda parameter.

### The tuple constructor

<HaskellTryIt>

```haskell

```

```text
[(1,True,'x')]
```

</HaskellTryIt>

```text
zipWith3 (,,) [1] [True] "x" -- given call

= (1,True,'x') : [] -- W30
= [(1,True,'x')] -- list notation
```

Using `(,,)` recovers `zip3`.


**Common error.** `zipWith3 (+)` gives a two-argument numeric function where a three-argument one is needed. GHC reports a type or numeric-instance mismatch. Use a three-parameter lambda.

**Practice with answer.** `zipWith3 (,,) [] [True] "x"` is `[]` by W30; with a concrete first-list type such as `[Int]`, the result type is `[(Int,Bool,Char)]`.

## 8. Left scans without an explicit seed: `scanl1`

`scanl1` starts at the first element and records the successive left-fold accumulators. A non-empty input of length `n` gives `n` results. Unlike `foldl1`, the empty input is allowed and returns an empty list.

**Template:** `scanl1 combine inputList`. The first element replaces the separate seed.

Labelled equations for paper traces:

```text
scanl1 :: (a -> a -> a) -> [a] -> [a]

scanl1 f (x:xs) = scanl f x xs -- S111
scanl f z [] = [z] -- SL0
scanl f z (x:xs) = z : scanl f (f z x) xs -- SL1
```

## 9. Right scans without an explicit seed: `scanr1`

`scanr1` starts at the last element and retains every right-fold result for non-empty suffixes. It returns `[]` on an empty input and preserves input length.

**Template:** `scanr1 combine inputList`. The last element supplies the seed; no extra empty-suffix entry is present.

Labelled equations for paper traces:

```text
scanr1 :: (a -> a -> a) -> [a] -> [a]
scanr1 f [] = [] -- S120
scanr1 f [x] = [x] -- S121
scanr1 f (x:y:xs) =
  let qs = scanr1 f (y:xs) in f x (head qs) : qs -- S122
head (x:xs) = x -- HEAD
```

```text
= let qs = (let rs = [1] in (-) 3 (head rs) : rs) in (-) 8 (head qs) : qs -- S121
= let qs = (-) 3 (head [1]) : [1] in (-) 8 (head qs) : qs -- let substitution
= let qs = (-) 3 1 : [1] in (-) 8 (head qs) : qs -- HEAD
= let qs = (3 - 1) : [1] in (-) 8 (head qs) : qs -- OP
= let qs = 2 : [1] in (-) 8 (head qs) : qs -- subtraction

= (-) 8 2 : (2 : [1]) -- HEAD
```

## 10. Updating until a test succeeds with `until`

`until` returns the first state satisfying a stopping predicate. It checks the current state before updating it. If no state ever passes the test, the calculation does not terminate.

**Template:** `until stop update initialState`. `stop` returns `Bool`, while `update` returns another state of the same type.

Labelled equations for paper traces:

```text
until :: (a -> Bool) -> (a -> a) -> a -> a
until p f x = if p x then x else until p f (f x) -- U
if True then a else b = a -- IF-T
if False then a else b = b -- IF-F
```

### A section with an overshoot

<HaskellTryIt>

```haskell
main :: IO ()
main = print (until (>=5) (+2) 2)
```

```text
6
```

</HaskellTryIt>

```text
until (>=5) (+2) 2 -- given call
= if (>=5) 2 then 2 else until (>=5) (+2) ((+2) 2) -- U
= if 2 >= 5 then 2 else until (>=5) (+2) ((+2) 2) -- SEC-R
= if False then 2 else until (>=5) (+2) ((+2) 2) -- comparison
= until (>=5) (+2) ((+2) 2) -- IF-F
= until (>=5) (+2) (2 + 2) -- SEC-R
= until (>=5) (+2) 4 -- addition
= if (>=5) 4 then 4 else until (>=5) (+2) ((+2) 4) -- U
= if 4 >= 5 then 4 else until (>=5) (+2) ((+2) 4) -- SEC-R
= if False then 4 else until (>=5) (+2) ((+2) 4) -- comparison
= until (>=5) (+2) ((+2) 4) -- IF-F
= until (>=5) (+2) (4 + 2) -- SEC-R
= until (>=5) (+2) 6 -- addition
= if (>=5) 6 then 6 else until (>=5) (+2) ((+2) 6) -- U
= if 6 >= 5 then 6 else until (>=5) (+2) ((+2) 6) -- SEC-R
= if True then 6 else until (>=5) (+2) ((+2) 6) -- comparison
= 6 -- IF-T
```

The answer need not equal the boundary; it is the first reached state passing the test.

### A lambda update

</HaskellTryIt>

```text
= if (==4) 2 then 2 else until (==4) (\x -> x * 2) ((\x -> x * 2) 2) -- U
= if 2 == 4 then 2 else until (==4) (\x -> x * 2) ((\x -> x * 2) 2) -- SEC-R
= if False then 2 else until (==4) (\x -> x * 2) ((\x -> x * 2) 2) -- equality
= until (==4) (\x -> x * 2) ((\x -> x * 2) 2) -- IF-F
= until (==4) (\x -> x * 2) (2 * 2) -- LAM: x := 2
= until (==4) (\x -> x * 2) 4 -- multiplication
= if (==4) 4 then 4 else until (==4) (\x -> x * 2) ((\x -> x * 2) 4) -- U
= if 4 == 4 then 4 else until (==4) (\x -> x * 2) ((\x -> x * 2) 4) -- SEC-R
= if True then 4 else until (==4) (\x -> x * 2) ((\x -> x * 2) 4) -- equality
```

### A seed already passing

<HaskellTryIt>


</HaskellTryIt>

**Practice with answer.** `until (>=3) (+1) 3` is `3`: U, section, comparison, IF-T. The initial state already meets the condition.

| State before test | Test `state >= 5` | Action |
|---|---|---|
| `2` | `False` | update to `4` |
| `4` | `False` | update to `6` |
| `6` | `True` | return `6` |

## 11. Supplying repeated inputs with `replicate`

`replicate` makes a finite list containing a fixed number of copies of one value. The copies are values, so a replicated function is still a function until it receives an argument. Replication does not repeatedly apply an update.

**Template:** `replicate count value`. `count` has type `Int`; a non-positive count produces an empty list.

Labelled equations for paper traces:

```text
replicate :: Int -> a -> [a]
replicate n x | n <= 0 = [] -- REP0
replicate n x = x : replicate (n-1) x -- REP1, for n > 0
```

## 12. Keeping a list of functions

A list can contain functions provided they share one type. Apply every function to one input with `map ($ input) functions`, or compose the functions with `foldr (.) id functions`. The rightmost function in a composition acts first.

**Template:** `map ($ input) functions; (foldr (.) id functions) input`. The map produces a list of results. The fold produces one function and therefore needs a final input to produce a printable value.

Labelled equations for paper traces:

```text
($ k) f = f $ k -- DSEC: right section
f $ x = f x -- APP
map f [] = [] -- M0
map f (x:xs) = f x : map f xs -- M1
foldr f z [] = z -- R0
foldr f z (x:xs) = f x (foldr f z xs) -- R1
(.) f g x = f (g x) -- COMP
id x = x -- ID
```

### Apply every function to the same value

<HaskellTryIt>

```haskell

```

```text

```

</HaskellTryIt>

```text
map ($ 3) [(+1),(*2)] -- given call
= ($ 3) (+1) : map ($ 3) [(*2)] -- M1
= ((+1) $ 3) : map ($ 3) [(*2)] -- DSEC: f := (+1)
= (+1) 3 : map ($ 3) [(*2)] -- APP
= (3 + 1) : map ($ 3) [(*2)] -- SEC-R
= 4 : map ($ 3) [(*2)] -- addition
= 4 : (($ 3) (*2) : map ($ 3) []) -- M1
= 4 : (((*2) $ 3) : map ($ 3) []) -- DSEC: f := (*2)
= 4 : ((*2) 3 : map ($ 3) []) -- APP
= 4 : ((3 * 2) : map ($ 3) []) -- SEC-R
= 4 : (6 : map ($ 3) []) -- multiplication
= 4 : (6 : []) -- M0
= [4,6] -- list notation
```

Both functions receive 3; neither receives the other's result.

### Compose a list of functions

<HaskellTryIt>



</HaskellTryIt>

```text
(foldr (.) id [(+1),(*2)]) 3 -- given call
= ((.) (+1) (foldr (.) id [(*2)])) 3 -- R1
= (+1) ((foldr (.) id [(*2)]) 3) -- COMP: f := (+1), g := tail composition
= (+1) (((.) (*2) (foldr (.) id [])) 3) -- R1
= (+1) ((*2) ((foldr (.) id []) 3)) -- COMP: f := (*2)
= (+1) ((*2) (id 3)) -- R0
= (+1) ((*2) 3) -- ID
= (+1) (3 * 2) -- SEC-R
= (+1) 6 -- multiplication
= 6 + 1 -- SEC-R
= 7 -- addition
```

The rightmost `(*2)` acts on 3 before `(+1)`.

## 13. Which higher-order function?

Read the requested output shape first, then choose the function. "First", "every", "state" and "matching position" signal different jobs.

| Question wording or required shape | Choose | Important check |
|---|---|---|
| Successive states from an update | `take n (iterate f seed)` | Seed is first; observation must be finite |
| Copies of a fixed value | `replicate n x` | Copies do not apply an update |
| Zero or more outputs for each input, flattened | `concatMap f xs` | `f` must return a list |
| Passing prefix and its remainder | `span p xs` | Stops at the first failure |
| Prefix before a match and remainder starting at that match | `break p xs` | Matching element is retained in the remainder |
| All passing and all failing elements | `partition p xs` | Traverses the whole finite list; import from `Data.List` |
| Retain matching triples | `zip3 xs ys zs` | Stops at the shortest list |
| Combine three matching elements | `zipWith3 f xs ys zs` | Rule needs three arguments |
| Prefix accumulators, first element as seed | `scanl1 f xs` | Empty input gives `[]` |
| Suffix accumulators, last element as seed | `scanr1 f xs` | Original suffix order; empty gives `[]` |
| First state satisfying a test | `until p f seed` | Test before updating; may never succeed |
| Results of several functions on the same input | `map ($ x) fs` | All functions must accept that input |
| One function made from several functions | `foldr (.) id fs` | Rightmost acts first; apply final function to print a value |

### Exam question 3: Splitting an initial run with span (5 marks)

Evaluate and trace `(span (<3) [1,4,2]) :: ([Int],[Int])`. State the expression's type. Show all substitutions and explain the stopping point.

<details>
<summary>Worked answer, with the reasoning</summary>

<Steps title="Answering the question">

<Step title="1. Read the question">

"Evaluate and trace" requires both a value and its derivation. The given expression is `span (<3) [1,4,2]`; its annotation fixes the result type to `([Int],[Int])`.

</Step>

<Step title="2. Plan">

<Step title="3. Solution">

Type: `([Int],[Int])`. Result: `([1],[4,2])`.

The input elements are specialised to `Int`. `span` returns two lists of that same element type. 

```text

= if (<3) 1 then let (ys,zs) = span (<3) [4,2] in (1:ys,zs) else ([],[1,4,2]) -- SP1
= if 1 < 3 then let (ys,zs) = span (<3) [4,2] in (1:ys,zs) else ([],[1,4,2]) -- SEC-R
= if True then let (ys,zs) = span (<3) [4,2] in (1:ys,zs) else ([],[1,4,2]) -- comparison
= let (ys,zs) = span (<3) [4,2] in (1:ys,zs) -- IF-T
= let (ys,zs) = (if (<3) 4 then let (us,vs) = span (<3) [2] in (4:us,vs) else ([],[4,2])) in (1:ys,zs) -- SP1
= let (ys,zs) = (if 4 < 3 then let (us,vs) = span (<3) [2] in (4:us,vs) else ([],[4,2])) in (1:ys,zs) -- SEC-R
= let (ys,zs) = (if False then let (us,vs) = span (<3) [2] in (4:us,vs) else ([],[4,2])) in (1:ys,zs) -- comparison
= let (ys,zs) = ([],[4,2]) in (1:ys,zs) -- IF-F
= (1:[],[4,2]) -- let pair match: ys := [], zs := [4,2]
= ([1],[4,2]) -- list notation
```

The later 2 belongs to the remainder, although it would pass the predicate.

## Summary

<Callout type="key" title="Remember">

`iterate` updates; `replicate` copies. `concatMap` flattens list-valued outputs. `span` and `break` make one cut, while `partition` classifies every element. Three-list zips stop at the shortest input. `scanl1` and `scanr1` accept empty lists and retain input length. `until` tests before updating. Mapping dollar applies every function to the same input; folding composition builds one function whose rightmost part acts first.

</Callout>
