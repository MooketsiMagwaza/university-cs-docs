A **higher-order function** takes another function as an argument, or returns one as its result. This is possible because functions in Haskell are **first-class values**: they can be passed to functions, returned from functions, and stored in data structures, with no restriction on their use. The practical payoff is that the recursions you wrote by hand in Chapter 6 turn out to share three shapes.

## Key ideas

Name those shapes once, and you stop rewriting them.

### The three shapes

Every list recursion in Chapter 6 was one of these:

| Shape | Result | Captured by |
|---|---|---|
| Transform every element | A list of the same length | `map` |
| Keep some elements | A shorter list, same type | `filter` |
| Combine into one value | A single value | `foldr` / `foldl` |

Recognising which shape a problem has is the skill this chapter builds. Writing them by hand first, as you did in Chapter 6, is what makes the abstraction obvious rather than mysterious.
