title: "Haskell Basics"
description: "Installing the Haskell toolchain, using GHCi, writing and running a first script, values, identifiers, literals, types, text, expressions, and function application."
---

These lessons take you from an empty machine to a running Haskell program, then establish the language vocabulary required before functions and input/output. You will install the toolchain, work in GHCi, save and run a script, and learn how types decide whether an expression is meaningful.

<LearningObjectives items={[
  "Install the Haskell toolchain and prove that GHC and GHCi work; distinguish the GHCi prompt, entered expressions, and displayed results",
  "Write a .hs script, load it, run main, and reload it after an edit",
  "Compile a script into a standalone executable and explain the files produced",
  "Read :: as “has type”; distinguish identifiers, literals, Char, and String",
  "Predict the grouping and result of small expressions",
  "Diagnose basic syntax and type errors",
]} />

<Prerequisites items={[
  "Nothing beyond the start of the course",
]} />
