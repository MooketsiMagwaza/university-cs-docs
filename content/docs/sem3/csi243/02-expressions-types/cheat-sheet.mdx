## 1. Placeholders used in every template on this page

| Placeholder | Meaning | Example |
|---|---|---|
| `funcName` | The name you give the function | `square`, `rectangleArea` |
| `expression` | Any piece of Haskell code with a value | `2 + 3`, `True`, `"Hello"` |
| `A`, `B`, `C` | One input or output type in a signature, read left to right | `Integer`, `Bool`, `String` |

    { cmd: ':quit', short: ':q', purpose: 'Leave GHCi (Ctrl+D also works)' }

/>

**Template:**
```text
ghci> :type expression
ghci> :load File.hs
ghci> :reload
ghci> :info name
ghci> :quit
```

**Example:**
```text
ghci> :type True
True :: Bool
ghci> :load Hello.hs
[1 of 1] Compiling Main             ( Hello.hs, interpreted )
Ok, one module loaded.
ghci> :reload
Ok, one module loaded.
ghci> :quit
Leaving GHCi.
```
`:type` asks about an **expression** you supply; `:info` asks about a **name already in scope**, including which module defined it.

```text
ghci> :type 'A'
'A' :: Char
ghci> :type "A"
"A" :: String
ghci> :type True
True :: Bool
```
`'A'` and `"A"` look almost identical but are different types: `Char` holds exactly one character, `String` is a list that happens to hold one.

## 4. Reading a multi-arrow type signature

Read every `->` the same way, left to right: **"takes a(n) A, and gives back a(n) B."** Chain that reading once per arrow.

**Template:**
```haskell
funcName :: A -> B -> C
-- "funcName takes an A, and gives back [something that takes a B, and gives back a C]"
-- chained: "give funcName an A and a B, and it gives back a C"
```

**Example:**
```haskell
rectangleArea :: Integer -> Integer -> Integer
rectangleArea width height = width * height
```
```text
ghci> rectangleArea 5 3
15
```

| Signature | Arrow count | Everyday reading |
|---|---|---|
| `square :: Integer -> Integer` | 1 | Takes an `Integer`, gives back an `Integer` |
| `rectangleArea :: Integer -> Integer -> Integer` | 2 | Takes two `Integer`s, gives back an `Integer` |
| `volume :: Integer -> Integer -> Integer -> Integer` | 3 | Takes three `Integer`s, gives back an `Integer` |

**A variation worth recognising early:** one of the "things" an arrow points to can itself be a function type, in parentheses.
```haskell
applyTwice :: (t -> t) -> t -> t
```
Read it the same way, one arrow at a time: "`applyTwice` takes **a function** `t -> t`, and [gives back something that takes a `t`, and gives back a `t`]." The parentheses are doing real work here — `(t -> t)` is one single input, itself a function, not two separate inputs. Chapter 7 covers passing functions as arguments properly; for now, just recognise the shape and don't let the parentheses read as two arrows instead of one.
```text
ghci> let applyTwice f x = f (f x)
ghci> applyTwice (+3) 10
16
```
`applyTwice (+3) 10` applies `(+3)` twice: `10 + 3 = 13`, then `13 + 3 = 16`.

## 5. Literal vs. identifier — quotation marks are the only signal

<ComparisonTable
  columns={[
    { header: 'Source', key: 'source' },

  ]}
  rows={[

    { source: '"Hello"', meaning: 'A String value', why: 'Double quotes mark a sequence of characters as literal text' },
    { source: "'H'", meaning: 'One Char value', why: 'Single quotes mark exactly one character as literal text' }
  ]}
/>

```text
ghci> putStrLn Hello
<interactive>:1:10: error:
    Data constructor not in scope: Hello :: String
ghci> putStrLn "Hello"
Hello
```
An unquoted word is always looked up as a name — never read as text — no matter how it looks to a human.

## 6. Numeric defaulting, in one line

An ambiguous numeric expression defaults to `Integer` when only `Num` is required, and to `Double` when `Fractional` is required (because `Integer` isn't `Fractional`).

```text
ghci> 2 + 3
5
ghci> 2.5
2.5
```

<Callout type="warn" title="A negative number right after an operator needs brackets">
`9 + -7` is a parse error — Haskell reads the `-` as subtraction, not as the start of a negative literal, once it follows another operator. Write `9 + (-7)` instead.
</Callout>

## 7. Common errors, at a glance

| Symptom | Cause | Fix |
|---|---|---|
| `9 + -7` rejected | `-` after an operator reads as subtraction | `9 + (-7)` |
| `` `False \|\| true` `` rejected | `True`/`False` are constructors and must be capitalised | `` `False \|\| True` `` |
| `if ... then True` with no `else` | Every Haskell `if` needs an `else` | Add the `else` branch |
| `Print "Hello"` rejected | Names are case-sensitive | `print "Hello"` |
| `print Hello World` rejected | Two unquoted words are two identifiers, not one string | `print "Hello World"` |
