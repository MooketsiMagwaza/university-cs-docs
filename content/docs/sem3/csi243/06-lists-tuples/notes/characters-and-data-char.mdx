## 1. One character, empty text and nested text

The quotation basics are in Values, Names, Types, and Text. The new decision is which level a function reaches: `Char` is one character value; `String` means `[Char]`; `[String]` means `[[Char]]`. There is no empty Char. A space is a character, while `""` is an empty list. `[""]` is not an empty outer list. A displayed symbol can use several Unicode code points, so String length counts Char values, not necessarily visible symbols.

### Template

```haskell
one :: Char
one = ' '
text :: String
text = [one]
texts :: [String]
texts = [text, ""]
```

The parameter stands for the supplied input; the signature states the input and result shapes.

### Worked variation: Normal input

<HaskellTryIt>

```haskell
main :: IO ()
main = print (length " ")
```

```text
1
```

</HaskellTryIt>

The ordinary space occupies one list position.

### Worked variation: Changed alphabet or output shape

<HaskellTryIt>

```haskell
main :: IO ()
main = print (('Q', ["Q"], ['Q']))
```

```text
('Q',["Q"],"Q")
```

</HaskellTryIt>

The last list holds Chars and therefore prints as a String; the middle list holds Strings.

### Worked variation: Boundary and nonletter cases

<HaskellTryIt>

```haskell

main = print ((length "", length ([] :: [String]), length [""], map length [""," ","ab"]))
```

```text
(0,0,1,[0,1,2])
```

</HaskellTryIt>

The first two are empty at their own level. The singleton outer list contains one empty inner string.

## 2. ord and Unicode codes

`ord :: Char -> Int` returns a Unicode code point: the numeric identifier of a Char. ASCII is only the subset 0 through 127. A code point is not a UTF-8 byte count, a keyboard key or a digit value. The lecture's informal getCode operation corresponds to actual `ord`. Uppercase A to Z occupy 65 to 90; lowercase a to z occupy 97 to 122.

### Template

```haskell
import Data.Char (ord)

codeOf :: Char -> Int
codeOf c = ord c
```

The parameter stands for the supplied input; the signature states the input and result shapes.

### Worked variation: Normal input

<HaskellTryIt>

```haskell
import Data.Char (ord)

main :: IO ()
main = print ((ord 'Z', ord 'z'))
```

```text
(90,122)
```

</HaskellTryIt>

Case changes the character value and its code.

### Worked variation: Changed alphabet or output shape

<HaskellTryIt>

```haskell
import Data.Char (ord)

main :: IO ()
main = print ((ord '0', ord '9', ord ' '))
```

```text
(48,57,32)
```

</HaskellTryIt>

Digit codes are 48 through 57, not the represented digit values. Space has code 32.

### Worked variation: Boundary and nonletter cases

<HaskellTryIt>

```haskell
import Data.Char (ord)

main :: IO ()
main = print ((ord '\xE9', ord '\x3BB', ord '\n'))
```

```text
(233,955,10)
```

</HaskellTryIt>

Accented e and Greek lambda are outside ASCII. Newline is one control Char of code 10.

## 3. chr and its valid domain

`chr :: Int -> Char` reverses ord on valid codes. GHC accepts codes 0 through 1114111 inclusive (`0x10FFFF`). This interval includes controls, unassigned values and surrogate code values; accepted by chr does not mean printable or a Unicode scalar value. Negative or larger codes fail at run time. The lecture's informal code-to-character getChar means `chr`. Actual `Prelude.getChar :: IO Char` reads input and takes no code argument.

### Template

```haskell
import Data.Char (chr)
-- Precondition: 0 <= n && n <= 1114111
characterOf :: Int -> Char
characterOf n = chr n
```

The parameter stands for the supplied input; the signature states the input and result shapes.

### Worked variation: Normal input

<HaskellTryIt>

```haskell
import Data.Char (chr)

main :: IO ()
main = print (chr 66)
```

```text
'B'
```

</HaskellTryIt>

Code 66 denotes B. print shows a Char with single quotes.

### Worked variation: Changed alphabet or output shape

<HaskellTryIt>

```haskell
import Data.Char (chr, ord)

main :: IO ()
main = print ((ord (chr 955), chr 32 == ' ', chr 10 == '\n'))
```

```text
(955,True,True)
```

</HaskellTryIt>

Non-ASCII code 955 survives conversion. Space and newline have codes 32 and 10.

### Worked variation: Boundary and nonletter cases

<HaskellTryIt>

```haskell
import Data.Char (chr, ord)

main :: IO ()
main = print ((ord (chr 0), ord (chr 1114111)))
```

```text
(0,1114111)
```

</HaskellTryIt>

Both accepted endpoints round-trip without asking a terminal to display them.

## 4. Numeric escapes and their boundaries

Inside a literal, backslash and decimal digits specify a code; `\x` introduces hexadecimal and `\o` introduces octal. The bases change the written number, not the resulting Char. Numeric escapes consume all following digits valid in their base. In a String, `\&` stops an escape without adding a character. It is not an empty Char.

### Template

```haskell
decimal = '\65'
hexadecimal = '\x41'
octal = '\o101'
text = "\65\&2"
```

The parameter stands for the supplied input; the signature states the input and result shapes.

### Worked variation: Normal input

<HaskellTryIt>

```haskell
main :: IO ()
main = print (('\65', '\x41', '\o101'))
```

```text
('A','A','A')
```

</HaskellTryIt>

Decimal 65, hexadecimal 41 and octal 101 name the same code.

### Worked variation: Changed alphabet or output shape

<HaskellTryIt>

```haskell
import Data.Char (ord)

main :: IO ()
main = print ((ord '\233', ord '\xE9', ord '\o351'))
```

```text
(233,233,233)
```

</HaskellTryIt>

The same non-ASCII code has three source spellings.

### Worked variation: Boundary and nonletter cases

<HaskellTryIt>

```haskell
import Data.Char (ord)

main :: IO ()
main = print ((map ord "\65\&2", map ord "\652"))
```

```text
([65,50],[652])
```

</HaskellTryIt>

With the separator, the digit 2 is another Char. Without it, 652 is one code.

## 5. Newlines: representation versus contents

`\n` denotes one newline Char. `print` uses a readable representation, with surrounding quotes and escaped control characters. `putStr` writes String contents; `putStrLn` writes contents followed by one additional newline. Exact-output questions depend on which operation is used.

### Template

```haskell
lineBreak :: Char
lineBreak = '\n'
message :: String
message = "first\nsecond"
```

The parameter stands for the supplied input; the signature states the input and result shapes.

### Worked variation: Normal input

<HaskellTryIt>

```haskell
main :: IO ()
main = print ("a\nb")
```

```text
"a\nb"
```

</HaskellTryIt>

print shows one output line containing the escaped representation.

### Worked variation: Changed alphabet or output shape

<HaskellTryIt>

```haskell
main :: IO ()
main = putStrLn "a\nb"
```

```text
a
b
```

</HaskellTryIt>

The embedded newline ends the first line. putStrLn terminates the second.

### Worked variation: Boundary and nonletter cases

<HaskellTryIt>


```text

```

</HaskellTryIt>

An escape is one Char regardless of how many source characters spell it.

## 6. Tabs are characters, not fixed-width padding

`\t` is a horizontal tab, code 9. Its display width depends on the terminal's tab stops; it is not a fixed number of stored spaces. Use readable output or codes when checking exact values.

### Template

```haskell
tab :: Char
tab = '\t'
isTab :: Char -> Bool
isTab c = c == tab
```

The parameter stands for the supplied input; the signature states the input and result shapes.

### Worked variation: Normal input

<HaskellTryIt>

```haskell
main :: IO ()
main = print ("A\tB")
```

```text
"A\tB"
```

</HaskellTryIt>

### Worked variation: Changed alphabet or output shape

<HaskellTryIt>

```haskell

```

```text

```

</HaskellTryIt>

One tab is one Char, four literal spaces are four, and their values differ.

### Worked variation: Boundary and nonletter cases


```text

```

</HaskellTryIt>

These adjacent whitespace characters have three distinct codes.

## 9. toUpper on one Char

## 10. toLower and information loss

`toLower :: Char -> Char` maps to lowercase where possible. Different input values can map to the same result, so this is not generally reversible. ## 24. Whole-String policies and equivalent forms

Lift a Char rule with `map` to obtain `String -> String`. Each input position yields one result, so the mapped policy preserves length. Filtering is a different operation that may delete positions. Mapping a whitespace replacement does not collapse runs into one space: three whitespace Chars become three ordinary spaces. No generic comprehension rule needs relearning; the job is choosing the character rule.

```haskell
  | isSpace c = ' '
  | otherwise = toLower c
```

## Summary

<Callout type="key" title="Remember">

Char is one value; String is a list of Chars; a list of Strings needs another map level. `ord` and `chr` convert codes, whereas `digitToInt` and `intToDigit` convert a single hexadecimal digit within smaller domains. ASCII is a Unicode subset. Match guards to the requested alphabet. Literal space, tab, other whitespace and empty text are different cases. Case mapping preserves nonletters and does not sort, delete or perform full Unicode normalisation. `print` shows readable quotes and escapes; content output writes the stored characters.

</Callout>
