## Background

Instead of using `for` or `while` loops, recursion is used for looping in Haskell. A recursive function defines the function in terms of itself, and invokes itself only when a condition is met, as with an if/then/else expression.

As in any form of loop, there must be at least one case that **terminates** the recursion, and a **recursive case** that causes the function to call itself. So every recursive function has two parts:

- **The base case** — defines the function for the first input values and terminates the recursion.
- **The recursive step** — defines the function for other input values in terms of itself, creating the loop.

Recursion can be implemented using if-then-else, or using a finite number of guards where the first guard evaluating to `True` is taken.

## Question 1 — `atPosition`

Define a function `atPosition` that takes a list and a number `y`, and returns the element at position `y` together with `y` as a pair (a 2-tuple). Remember that **lists are indexed from 0**.

```text
atPosition [3,5,2,10] 3   returns   (3,10)
```

If `y` is less than 0, or `y` is greater than the length of the list, an appropriate error message should be displayed.

<Callout type="info" title="A shortcut you may use">
There is a built-in list operator `lst !! y` that returns the element at position `y` in `lst`. You may use it — but if you do, still give the recursive definition in part 2, and say in your submission which version you would ship and why.
</Callout>

## Question 2 — `largerY`

Given a list of integers and an integer `y`, the function `largerY` returns a list of all elements in the list which are larger than `y`. Assume the items can be arranged in some order.

```text
largerY [3,1,7,10] 4   returns   [7,10]
largerY [] 4           returns   []
```

Calling `largerY` on an empty list should return an empty list.

## Question 3 — `positiveNumbers`

Given a list of integers, the `positiveNumbers` function takes the list and returns all the positive integers in the list as a new list.

```text
positiveNumbers [-1,5,-3,8]   returns   [5,8]
positiveNumbers []            returns   []
```

Calling the function on an empty list should return an empty list.

## Question 4 — `isSorted`

Given a list of integers, the function `isSorted` returns `True` if the list is sorted in **descending** order, and `False` otherwise.

```text
isSorted [5,3,1]   returns   True
isSorted [3,1,5]   returns   False
isSorted []        returns   True
```

Calling `isSorted` on an empty list should always return `True`. A list with only one element is also sorted.

<Callout type="warn" title="This one needs three cases">
The empty list and the single-element list are both base cases, and they are both `True`. Only a list of at least two elements has anything to compare. Think carefully about what the recursive call should be given — dropping the wrong element loses a comparison.
</Callout>
