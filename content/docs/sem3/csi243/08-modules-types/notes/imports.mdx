description: "Import whole modules or selected names, hide conflicting ones, use qualified imports and aliases, and find your way around the standard library modules."

A module may **import** definitions from other modules. This lesson covers the five forms of import and when each is the right one.

## 1. The basic form

```haskell
import ModuleName
```

`import MyCalculator` brings in everything the module exports.

Two rules govern placement:

- **Imports must appear before any function definition**, so they go at the top of the file.
- To import several modules, put **each import statement on its own line**.

```haskell
import Data.Char
import Data.List
import MyCalculator

-- definitions follow
```

## 2. Selective import

If you need only a couple of functions from a module, import just those by listing them in parentheses:

```haskell
import Data.Char (toLower, toUpper)
```

Now `toLower` and `toUpper` are available, and nothing else from `Data.Char` is.

```haskell
import MyCalculator (addTwo)
import Data.List           -- everything from Data.List
```

<Callout type="info" title="Why bother being selective">
A selective import documents exactly what your module depends on, and it prevents a name you did not expect from clashing with one of your own. For a large module such as `Data.List`, being explicit is usually worth it.
</Callout>

A second example selects from a different module to show the same syntax generalises:

```haskell
import Data.List (sort, group)

-- Count how many times each element appears, sorted by element.
tally :: Ord a => [a] -> [(a, Int)]
tally xs = map (\g -> (head g, length g)) (group (sort xs))
```

```text
ghci> tally "mississippi"
[('i',4),('m',1),('p',2),('s',4)]
```

Only `sort` and `group` were imported; `nub`, `intercalate`, and everything else `Data.List` exports are simply not in scope in this module.

## 3. Hiding

To import everything **except** a few names, use `hiding`:

```haskell
import Data.List hiding (nub)
```

Everything after `hiding` is not imported. To hide several names, list them comma-separated in parentheses:

```haskell
import Data.List hiding (nub, sort)
```

This is useful when several modules export functions with the same name and you want to avoid a conflict — for instance when you have written your own `nub` and still want the rest of `Data.List`.

<Callout type="warn" title="Types cannot be hidden">
Algebraic datatypes and type synonyms cannot be hidden; they are always imported. `hiding` applies to functions and values.
</Callout>

<CommonMistake title="A selective import and hiding cannot be combined">
`import M (f, g) hiding (h)` is not valid Haskell — an import is either selective (list what you want) or exclusionary (list what you do not want), never both at once. If you need "everything except a couple of names, but nothing else", `hiding` alone already gives you that; there is no form that both selects and excludes in the same statement.
</CommonMistake>

## 4. Qualified imports

If a name is defined in two imported modules, referring to it is ambiguous. A **qualified** import requires every name from that module to be prefixed with the module name:

```haskell
import qualified Data.Map

-- Must now be written with the prefix.
example = Data.Map.insert 1 "one" Data.Map.empty
```

With qualified imports, all imported values include the module name as a prefix. That makes the origin of every name unambiguous:

```haskell
MyModule.functionName variables        -- the version from MyModule
MyOtherModule.functionName variables   -- the version from MyOtherModule
```

## 5. Aliases with `as`

Imported modules may be renamed and assigned a local alias using the `as` clause:

```haskell
import qualified MyVeryLongModuleName as ModAlias
```

Entities are then referenced with `ModAlias.` instead of `MyVeryLongModuleName.`. This renaming works with both qualified and regular importing.

```haskell
import qualified Data.Map as Map

example = Map.insert 1 "one" Map.empty
```

As long as there are no conflicting items, several modules may be imported and renamed the same:

```haskell
import MyLongModule as My
import MyCompletelyDifferentModule as My
```

Both modules' functions can then be prefixed with `My`.

<RecognitionStrategy title="When you actually need qualified">
Reach for `qualified` (with or without `as`) the moment you catch yourself asking "which module's version of this name am I calling?" — most often with `Data.Map` and `Data.List`, which both export `insert`, `filter`, `lookup`, and other very ordinary names. If you only import one of the two, plain `import Data.Map` is fine; the moment both are imported in the same file, prefer `qualified ... as` so every call site states which one it means.
</RecognitionStrategy>

## 7. The standard library modules

The Haskell standard library is split into modules, each containing functions and types that are related and serve a common purpose.

| Module | Contains |
|---|---|
| `Prelude` | The standard definitions, imported automatically into every module |
| `Data.List` | A wide range of functions for working with list data |
| `Data.Char` | Predefined functions for working with the `Char` type |
| `Data.Map` | An unsorted key-value pair data type, with many useful functions |
| `Data.Set` | Functions for manipulating mathematical sets |

`Prelude` needs no import, which is why arithmetic, `putStrLn`, and the list operations have worked from Chapter 2 onwards.

`Data.Set` is implemented as a binary tree, so **all the elements in a set must be unique**.

### Using `Data.Char`

```haskell
import Data.Char (toUpper, toLower, ord, chr, isDigit, isAlpha)

shout :: String -> String
shout = map toUpper
```

```text
ghci> shout "csi243"
"CSI243"
ghci> ord 'A'
65
ghci> chr 97
'a'
ghci> isDigit '7'
True
```

`ord :: Char -> Int` turns a character into its character code, and `chr :: Int -> Char` turns a code back into a character. Capital letters A to Z have codes 65 to 90, and lowercase a to z have codes 97 to 122.

Other useful `Data.Char` functions are `isAscii`, `isUpper`, `isLower`, `isAlpha`, `isDigit`, and `isAlphaNum`.

### Using `Data.List`

```haskell
import Data.List (sort, nub, group)
```

```text
ghci> sort [3,1,2]
[1,2,3]
ghci> nub [1,1,2,3,3]
[1,2,3]
```

### Using `Data.Map`

```haskell
import qualified Data.Map as Map

marks :: Map.Map String Int
marks = Map.fromList [("Kago", 72), ("Naledi", 68)]
```

```text
ghci> Map.lookup "Kago" marks
Just 72
ghci> Map.lookup "Sipho" marks
Nothing
ghci> Map.member "Naledi" marks
True
ghci> Map.insert "Sipho" 55 marks
fromList [("Kago",72),("Naledi",68),("Sipho",55)]
ghci> marks
fromList [("Kago",72),("Naledi",68)]
```

`Map.lookup` returns a `Maybe Int` — the safe lookup pattern from earlier in this chapter, but backed by an efficient tree instead of a plain association list. `Map.insert` returns a **new** map, as every Haskell update does; `marks` itself is unchanged afterwards, which the last line confirms.

### Using `Data.Set`

```haskell
import qualified Data.Set as Set

vowelSet :: Set.Set Char
vowelSet = Set.fromList "aeiouaeiou"
```

```text
ghci> vowelSet
fromList "aeiou"
ghci> Set.member 'e' vowelSet
True
ghci> Set.size vowelSet
5
```

The repeated vowels in `"aeiouaeiou"` collapse to five, because `Data.Set` enforces uniqueness by construction — the same guarantee mentioned above, now shown in a transcript.

## 8. Common errors

| Symptom | Cause | Repair |
|---|---|---|
| `Could not find module 'Data.Char'` | Misspelling, or the package is unavailable | Check the spelling and capitalisation |
| `Ambiguous occurrence 'nub'` | Two imported modules export the name | Use `hiding`, or a qualified import |
| `Variable not in scope: toUpper` | It was not included in a selective import | Add it to the parentheses |
| `Not in scope: Map.insert` | The module was imported unqualified, or the alias differs | `import qualified Data.Map as Map` |
| `parse error on input 'import'` | An import appears after a definition | Move all imports to the top |
| `hiding` on a type has no effect | Types and synonyms cannot be hidden | Use a qualified import instead |
| `import Data.List (nub) hiding (sort)` | Selective and hiding forms cannot be combined | Pick one form: either `(nub)` or `hiding (sort)` |
