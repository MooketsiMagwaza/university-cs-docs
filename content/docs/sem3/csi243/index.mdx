## CSI243 Functional Programming

This course develops Haskell in dependency order: first the programming model, then the language basics, then functions and input/output. Later chapters extend the same foundation into choices, recursion, collections, higher-order functions, modules, and custom types.

## Set up first

If Haskell is not yet installed on your machine, start with [Setting Up and Using GHCi](/docs/sem3/csi243/02-expressions-types/notes/ghci), then [Your First Haskell Program](/docs/sem3/csi243/02-expressions-types/notes/first-program). Together they take you from an empty machine to a compiled executable. You can read Chapter 1 before or after that; it needs no software.

For short experiments while reading, open the [Haskell playground](/docs/playgrounds/haskell). It executes the course's core expression and list-processing subset directly in the browser and shows parse, type, and runtime feedback beside the editor.

Before your first lab or exam, read [Decoding the questions](/docs/sem3/csi243/01-functional-thinking/review#decoding-the-questions): a reusable method, with worked examples from real CSI243 questions, for turning dense lecturer wording into plain English and then into Haskell. Every chapter's Review page has the same section.

## Course outcomes

By the end of the completed course, students should be able to:

- explain functional programming and compare it with imperative programming;
- read and write typed Haskell expressions and functions;
- separate pure transformations from input/output actions;
- solve problems with pattern matching, recursion, collections, and higher-order functions;
- organize programs with modules and custom data types;
- interpret compiler feedback and test programs systematically;
- reason about program behavior and basic complexity.
