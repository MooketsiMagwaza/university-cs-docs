## Try it yourself

Write JavaScript on the left and press **Run code**. Anything passed to `console.log` appears in the output panel. A top-level `return` value is shown after `=`.

<CodePlayground language="javascript" />

## Things to try

1. In **Array methods**, replace `filter` with `find`. What type does it return?
2. In **Recursion**, change `fib(i)` to `fib(35)` and run it. A naive recursive Fibonacci is slow. Can you speed it up with a `Map` cache?
3. In **Async and promises**, remove an `await` and watch the order of the output change.
4. Write `while (true) {}` and run it. The playground stops the program after 5 seconds, which is the same safety net it gives every run.

## Ready-made datasets

Pick a **Dataset** to have constants defined for you before your code runs.

| Dataset | Defines |
|---|---|
| Class marks | `students`, an array of objects with `name`, `year` and an array of `marks` |
| Shopping cart | `cart`, an array of items with `item`, `price` and `quantity` |

The dataset's code is shown under the editor. Because it declares these names with `const`, avoid declaring the same name again in your own code.

## What is different from a browser console

- The code runs in a **Web Worker**, so there is no `document` or `window`. Use the [HTML & CSS playground](/docs/playgrounds/html-css) for page scripting.
- **Top-level `await` works**, so you can test promises without wrapping everything in an `async` function.
- `alert(x)` is mapped to a line of output.
- Each run uses a brand new worker. State never carries over between runs.
