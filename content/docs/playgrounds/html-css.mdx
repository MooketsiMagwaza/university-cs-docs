## Try it yourself

HTML describes **what is on the page**, CSS describes **how it looks**, and a `<script>` describes **how it behaves**. Pick an example, change a colour, a size or a tag, and press **Run code**.

<CodePlayground language="html" />

## Things to try

1. In the **CSS box model** example, change `padding` from `20px` to `0`. Which part of the box shrinks?
2. In **Flexbox layout**, change `justify-content: space-between` to `center`, then to `flex-end`.
3. In **Button with JavaScript**, make each click add 5 instead of 1.
4. Delete the closing `</p>` tag. Browsers repair HTML silently, so the page often still works. That is why validating your markup matters.

## Quick reference

| Concept | Example |
|---|---|
| Heading, paragraph | `<h1>Title</h1>` `<p>Text</p>` |
| Link, image | `<a href="...">text</a>` `<img src="..." alt="...">` |
| Class selector | `.card { padding: 1rem; }` |
| Colour, size | `color: #2563eb;` `font-size: 1.25rem;` |
| Layout | `display: flex; gap: 12px;` |
| Event | `button.addEventListener('click', () => { ... })` |

## Limits

The preview frame is sandboxed. It can run scripts and show `alert()` dialogs, but it cannot read cookies, local storage or the surrounding page, and it cannot navigate away from the preview. External images and stylesheets load normally if the address is public.
