## Learn by changing the code

Every playground works the same way: edit the code on the left, press **Run code** (or **Ctrl + Enter**), and read the result on the right. Break something on purpose. Reading an error message you caused is one of the fastest ways to learn a language.

| Playground | Good for | Runs on |
|---|---|---|
| [HTML & CSS](/docs/playgrounds/html-css) | Page structure, styling, layout, small scripts | Your browser, in a sandboxed frame |
| [JavaScript](/docs/playgrounds/javascript) | Programming basics, arrays, functions, async | A Web Worker |
| [Python](/docs/playgrounds/python) | Programming principles, algorithms, data structures | Pyodide (CPython in WebAssembly) |
| [SQL](/docs/playgrounds/sql) | Databases, joins, grouping, subqueries | SQLite in WebAssembly |
| [Haskell](/docs/playgrounds/haskell) | CSI243 expressions, lists and higher-order functions | A course-subset interpreter written for this site |

## How the playgrounds stay safe and responsive

- **Everything runs on your device.** Your code is never sent to a server. Python and SQL download their runtime once from a public CDN and your browser caches it.
- **JavaScript, Python and SQL run inside Web Workers.** A worker cannot touch this page, your cookies or your storage. If a program never finishes, the playground stops the worker after a time limit instead of freezing the tab.
- **HTML runs inside a sandboxed frame** with no access to the surrounding site.
- **Each run starts clean.** Variables from a previous run do not leak into the next one, so a program that works twice is genuinely correct.

## Editor tips

- **Tab** inserts two spaces. Press **Esc** and then **Tab** to move focus out of the editor with the keyboard.
- **Reset** returns to the selected example. The **Example** menu loads another one.
- Output in amber is a warning or error stream (`console.error`, Python's `stderr`). Red panels are failures with a message to read.

## Datasets

The SQL, Python and JavaScript playgrounds can load a **dataset** before your code runs: a ready-made database, a list of students, a shopping cart. Choose one from the **Dataset** menu, or open an example whose name starts with the dataset, such as *University: join three tables*. Examples and datasets are plain JSON files, so adding one means editing data, not code.

## Using a playground in your own notes

Inside any page of this site, drop in a runnable example with a single tag:

```mdx
<CodeTryIt language="python" code={`print("hello")`} />
```

`language` is one of `html`, `javascript`, `python` or `sql`. Use `<CodePlayground language="sql" />` for a full editor with the example menu.

To start on a particular example, or with a dataset already loaded, give the ids from `content/playground-data`:

```mdx
<CodePlayground language="sql" example="university-join-three-tables" />
<CodeTryIt language="sql" seed="university" code={`SELECT name FROM student WHERE year = 3;`} />
```
