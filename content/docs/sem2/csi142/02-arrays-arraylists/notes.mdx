## Arrays and ArrayLists

An array stores a fixed number of values of one declared type. If `a` has length `n`, valid indices are `0` through `n - 1`. The expression `a.length` is a field, not a method call.

Try it: predict the first two lines and the last index, run the program, then add a sixth value and predict `length` and `last` again.

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        int[] a = {10, 20, 30, 40, 50};
        System.out.println("length = " + a.length);
        System.out.println("last index = " + (a.length - 1));
        System.out.println("last = " + a[a.length - 1]);
        for (int i = 0; i < a.length; i++) {
            System.out.println("a[" + i + "] = " + a[i]);
        }
    }
}
```

```text
length = 5
last index = 4
last = 50
a[0] = 10
a[1] = 20
a[2] = 30
a[3] = 40
a[4] = 50
```

</JavaTryIt>

## Traversal patterns

Use an index loop when the position matters and an enhanced `for` loop when only the values matter. A linear search checks each item until it finds the target or reaches the end. For a maximum, initialise from the first valid element rather than from zero when values may be negative.

```java
int maximum = values[0];
for (int i = 1; i < values.length; i++) {
    if (values[i] > maximum) maximum = values[i];
}
```

Try it: the second loop starts from 0 instead of the first element. Predict both results, run the program, then change `values` to all-positive numbers and predict again.

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        int[] values = {-8, -3, -12, -5};
        int maximum = values[0];
        for (int i = 1; i < values.length; i++) {
            if (values[i] > maximum) maximum = values[i];
        }
        System.out.println("maximum = " + maximum);

        int wrongStart = 0;
        for (int value : values) {
            if (value > wrongStart) wrongStart = value;
        }
        System.out.println("starting from 0 gives " + wrongStart);
    }
}
```

```text
maximum = -3
starting from 0 gives 0
```

</JavaTryIt>

Two-dimensional arrays are arrays of row arrays. Use `matrix.length` for the number of rows and `matrix[row].length` for the length of a particular row; this also handles ragged arrays.

## ArrayList

`ArrayList<Integer> scores = new ArrayList<>();` creates a resizable list. Common operations are `add`, `get`, `set`, `remove`, `size`, and `contains`. Indices remain zero-based. Removing by an integer can be confusing because `remove(2)` removes index 2, while `remove(Integer.valueOf(2))` removes the value 2.

Try it: predict the list after each step, then run the program. Swap the two `remove` calls and predict again.

<JavaTryIt>

```java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<Integer> scores = new ArrayList<>();
        scores.add(5);
        scores.add(2);
        scores.add(8);
        scores.add(9);
        System.out.println(scores + ", size " + scores.size());
        scores.remove(2);
        System.out.println("after remove(2): " + scores);
        scores.remove(Integer.valueOf(2));
        System.out.println("after remove(Integer.valueOf(2)): " + scores);
        System.out.println("contains 9: " + scores.contains(9));
        scores.set(0, 70);
        System.out.println(scores + ", first = " + scores.get(0));
    }
}
```

```text
[5, 2, 8, 9], size 4
after remove(2): [5, 2, 9]
after remove(Integer.valueOf(2)): [5, 9]
contains 9: true
[70, 9], first = 70
```

</JavaTryIt>

## Aliasing and copying

An array variable stores a reference. Assigning `b = a` gives two names for the same array; changing one changes the other. Use `Arrays.copyOf` when an independent copy is required. The same aliasing idea applies to lists and objects.

Try it: predict what `a`, `b` and `c` hold and the two `true` or `false` lines before you run the program. Then change `b[0] = 100;` to `a[0] = 100;` and predict again.

<JavaTryIt>

```java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        int[] b = a;
        int[] c = Arrays.copyOf(a, a.length);
        b[0] = 100;
        c[1] = 200;
        System.out.println("a = " + Arrays.toString(a));
        System.out.println("b = " + Arrays.toString(b));
        System.out.println("c = " + Arrays.toString(c));
        System.out.println("a and b are the same array: " + (a == b));
        System.out.println("a and c are the same array: " + (a == c));
    }
}
```

```text
a = [100, 2, 3]
b = [100, 2, 3]
c = [1, 200, 3]
a and b are the same array: true
a and c are the same array: false
```

</JavaTryIt>

## Common mistakes

- Using `i <= array.length` instead of `i < array.length`.
- Confusing `size()` with `length`.
- Removing list elements while iterating without controlling the index.
- Assuming a shallow copy duplicates nested objects.
