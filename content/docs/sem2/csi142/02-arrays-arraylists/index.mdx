An array stores a fixed number of values of one declared type, and an `ArrayList` stores a resizable list of objects. This topic goes beyond the basics to the traversal patterns used in practice, such as linear search and finding a maximum, the operations of `ArrayList`, and the difference between sharing and copying. Knowing that array and list variables hold references explains many surprising results.

<LearningObjectives items={[
  "Traverse an array with an index loop or an enhanced for loop, as the task requires, and write a linear search.",
  "Find a maximum by starting from the first element so that negative values are handled correctly.",
  "Handle two-dimensional and ragged arrays using matrix.length and matrix[row].length.",
  "Use the ArrayList operations add, get, set, remove, size and contains, and tell removal by index from removal by value.",
  "Explain aliasing, and copy an array with Arrays.copyOf when an independent copy is needed.",
]} />
