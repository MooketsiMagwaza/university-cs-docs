A class defines a type, with fields for state and methods for behaviour, and an object is an instance created from it. This topic covers keeping fields private and exposing controlled operations, how constructors establish a valid initial state, and how to tell identity from logical equality. Designing a class around its invariant makes its objects safe to use and straightforward to test.
