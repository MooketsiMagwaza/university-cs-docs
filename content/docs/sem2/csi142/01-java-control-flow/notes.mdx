## Java Recap and Control Flow

A Java program is evaluated from expressions into values and from statements into state changes. Trace variables after every assignment rather than guessing from the final output.

## Expressions and conditions

Use `==` for primitive value comparison and `.equals()` for the contents of objects such as `String`. A boolean expression combines comparisons with `&&`, `||`, and `!`. Short-circuit evaluation means the right side of `&&` is skipped when the left side is false, and the right side of `||` is skipped when the left side is true.

Try it: predict which `checking` lines appear and what the last two lines say, then run the program. Change the first `false` to `true` and predict again.

<JavaTryIt>

```java
public class Main {
    static boolean check(String label, boolean value) {
        System.out.println("checking " + label);
        return value;
    }

    public static void main(String[] args) {
        boolean first = check("A", false) && check("B", true);
        boolean second = check("C", true) || check("D", false);
        System.out.println(first + " " + second);
        String word = "Java";
        System.out.println(word.equals("Java"));
    }
}
```

```text
checking A
checking C
false true
true
```

</JavaTryIt>

An `if` statement selects between branches. Use braces even for one statement so later edits cannot change the intended scope. A `switch` is useful when one expression is compared with several discrete cases; include `break` or use the modern arrow form to avoid accidental fall-through.

## Loops

Use a `for` loop when the iteration structure is known, a `while` loop when continuation depends on a condition, and a `do-while` loop when the body must execute once. Every loop needs an initial state, a continuation condition, and progress toward termination.

For a loop summing values, maintain an invariant: after processing the first $k$ items, `sum` equals their total. Test zero iterations, one iteration, and a boundary value. These cases expose off-by-one errors.

Try it: after the first `k` items, `sum` should equal their total, so check each printed line against that rule. Then change `values` to `{}` and to `{7}` and predict the output for the zero-item and one-item cases.

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        int[] values = {4, 8, 15};
        int sum = 0;
        System.out.println("items processed: 0, sum = " + sum);
        for (int k = 0; k < values.length; k++) {
            sum += values[k];
            System.out.println("items processed: " + (k + 1) + ", sum = " + sum);
        }
    }
}
```

```text
items processed: 0, sum = 0
items processed: 1, sum = 4
items processed: 2, sum = 12
items processed: 3, sum = 27
```

</JavaTryIt>

## Scope and tracing

A variable declared inside a block is unavailable outside it. For nested conditions, indent code and trace the branch predicate. When debugging, print or inspect the smallest set of state values that distinguishes the expected path from the actual path.

Try it: trace the branches for `temperature = 31` and `raining = false` and predict the output. Change both values, then remove the `//` in front of the last commented line and read the compiler message about `advice`.

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        int temperature = 31;
        boolean raining = false;
        if (temperature > 30) {
            String advice = "hot";
            if (raining) {
                advice = advice + " and wet";
            }
            System.out.println("advice inside: " + advice);
        }
        // System.out.println(advice);
        System.out.println("done");
    }
}
```

```text
advice inside: hot
done
```

</JavaTryIt>

## Common mistakes

- Using assignment `=` where comparison `==` is intended.
- Comparing strings with `==`.
- Writing a loop whose counter never changes.
- Treating the upper bound of a Java array as inclusive.
- Forgetting a `break` in a classic `switch`.

Try it: this `switch` has no `break` after `silver`, so it falls through. Predict the output for `level = 2`, then for `level = 1`, and add `break;` after each message to fix it.

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        int level = 2;
        switch (level) {
            case 1:
                System.out.println("bronze");
            case 2:
                System.out.println("silver");
            case 3:
                System.out.println("gold");
                break;
            default:
                System.out.println("unknown");
        }
    }
}
```

```text
silver
gold
```

</JavaTryIt>
