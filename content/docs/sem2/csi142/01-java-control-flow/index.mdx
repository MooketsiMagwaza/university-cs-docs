title: "Java Recap and Control Flow"
description: "A recap of Java expressions, conditions, loops and scope, with an emphasis on tracing and on the common control-flow mistakes."
---

A Java program turns expressions into values and statements into changes of state, so the most reliable way to understand it is to trace its variables after every assignment. This topic refreshes conditions and short-circuit evaluation, selection, loops with invariants, and variable scope. It prepares the ground for the methods, classes and collections that follow.

<LearningObjectives items={[
  "Use == for primitive values and .equals() for the contents of objects, and write boolean expressions with &&, || and ! that account for short-circuit evaluation.",
  "Choose between if and switch, using braces and break (or the arrow form) to avoid accidental fall-through.",
  "Choose between for, while and do-while, and give every loop an initial state, a continuation condition and progress toward termination.",
  "Maintain a loop invariant, and test zero, one and boundary iterations to expose off-by-one errors.",
  "Explain block scope, and trace nested conditions to find where the actual path differs from the expected one.",
]} />
