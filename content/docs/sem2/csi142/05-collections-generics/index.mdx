title: "Collections and Generics"
description: "Lists, sets, maps and queues, generic type parameters and autoboxing, safe iteration, and choosing a collection by the operations needed."
---

Collections model groups of objects with different ordering and performance properties, and generics let the compiler check which type each collection holds. This topic compares `List`, `Set`, `Map` and `Queue`, shows how to iterate over and modify them safely, and gives a way to choose a collection from the operations a task needs. Choosing by requirement rather than habit makes programs simpler and more reliable.
