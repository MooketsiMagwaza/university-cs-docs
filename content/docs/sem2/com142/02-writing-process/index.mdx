---
title: "The Writing Process"
description: "Planning, drafting, revising, editing and proofreading an assignment, and using feedback to improve it."
---

Strong writing is developed in stages. Planning reduces aimless research, drafting makes the reasoning visible, and revision and editing improve both the argument and the reader's experience. This topic walks through each stage and shows how to ask for feedback that you can use.

<LearningObjectives items={[
  "Plan an assignment by unpacking the prompt, forming a working thesis, and building a reverse outline and a source table.",
  "Draft for meaning first, using placeholders for a missing reference or example instead of stopping to fix it.",
  "Revise an argument by testing whether each section earns its place, reading the first sentence of each paragraph, and checking connections and counterarguments.",
  "Edit and proofread for concise sentences, consistent terminology, grammar, citation style, names and numbers.",
  "Ask a reviewer a focused question, and decide which feedback serves the purpose of the assignment.",
]} />
