## The Writing Process

Strong writing is developed in stages. Planning reduces aimless research; drafting makes the reasoning visible; feedback and revision improve the argument; editing improves the reader’s experience.

## Plan

Unpack the prompt, list the required components, and turn the topic into a question. Build a working thesis and a reverse outline of the points needed to support it. Create a source table with the claim, evidence, and citation details for each useful source.

## Draft

Write a first draft for meaning, not perfection. Use placeholders for a missing reference or unclear example instead of stopping every few sentences. The introduction should establish context, the question, and the route through the answer; write it after the body if that helps you state the actual argument.

## Revise

Revision means re-seeing the work. Test whether each section earns its place, whether the sequence is logical, and whether evidence is explained. Read only the first sentence of each paragraph to test the argument skeleton. Then inspect paragraph connections and counterarguments.

## Edit and proofread

Edit for concise sentences, consistent terminology, grammar, punctuation, headings, tables, and citation style. Proofread slowly in a different format and check names, numbers, quotations, page references, and file requirements.

## Feedback

Ask a reviewer a focused question: “Can you identify my main claim?” or “Where does the evidence need more explanation?” Treat feedback as data about a reader’s experience; decide which changes improve the assignment’s purpose.
