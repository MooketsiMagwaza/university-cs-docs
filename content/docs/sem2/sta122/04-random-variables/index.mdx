title: "Random Variables"
description: "Discrete random variables, probability mass and cumulative distribution functions, expectation, variance, and linear transformations."
---

A random variable assigns a number to each outcome, which turns questions about events into questions about values. This topic covers discrete random variables with their probability mass function and cumulative distribution function, the expected value and variance, and what happens to them under a linear transformation. It also shows how to define exactly what a variable counts, which is the first step in choosing a distribution.

<LearningObjectives items={[
  "Define a random variable, and distinguish a random variable from an outcome.",
  "Write and check a probability mass function: non-negative values that sum to 1 over the whole support.",
  "Construct and interpret a cumulative distribution function, and relate its jumps to point probabilities.",
  "Calculate the expected value and the variance of a discrete random variable, using the shortcut form of the variance.",
  "Apply the rules for the expected value and variance of a linear transformation, and explain why adding a constant does not change the spread.",
  "State what one trial is and what the variable counts before selecting a distribution.",
]} />
