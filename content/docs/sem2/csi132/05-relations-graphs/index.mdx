---
title: "Relations and Graphs"
description: "Relation properties, equivalence relations and classes, graph terminology, adjacency matrices and lists, and breadth-first and depth-first search."
---

A relation on a set $A$ is a subset of $A\times A$, and its properties describe how pairs behave. This topic uses relations to build equivalence relations, which split a set into disjoint classes, and then moves to graph models: directed and undirected graphs, walks, paths, cycles and connectivity. It ends with the representations and search algorithms that turn graph questions into computations.

<LearningObjectives items={[
  "Check a relation for the reflexive, symmetric, antisymmetric and transitive properties from a table or a directed diagram.",

  "Use graph terms correctly: degree, indegree, outdegree, walk, trail, path, cycle and connectivity.",
  "Represent a graph by an adjacency matrix or an adjacency list, and say when each is the better choice.",
  "Describe breadth-first and depth-first search, and say what each can be used to find.",
]} />
