## Applications of Integration

The definite integral accumulates a signed rate or area. Before integrating, identify the interval, the top and bottom functions, and where the functions change order.

## Area between curves

With vertical slices, $A=\int_a^b[\text{top}(x)-\text{bottom}(x)]dx$. Find intersections by solving $f(x)=g(x)$, then test a point to determine which graph is above. If the curves cross inside the interval, split the integral.

With horizontal slices, use $A=\int_c^d[\text{right}(y)-\text{left}(y)]dy$. Choose the direction that gives the simpler description and avoids an incorrect subtraction.

## Volumes

The disk method uses $V=\pi\int_a^b[R(x)]^2dx$. Washers use the difference of squared outer and inner radii:

$$V=\pi\int_a^b(R(x)^2-r(x)^2)dx.$$

For shells around a vertical axis, $V=2\pi\int_a^b(\text{radius})(\text{height})dx$. Sketching the shell or washer prevents using the wrong radius.

## Average value and accumulation

The average value of $f$ on $[a,b]$ is $\frac1{b-a}\int_a^b f(x)dx$. If velocity is $v(t)$, displacement is $\int v(t)dt$, while total distance requires integrating speed $|v(t)|$ and splitting where velocity changes sign.

## Units and checks

An area integral has square units and a volume integral has cubic units. Estimate the graph’s scale and sign before accepting a calculator result.
