# Practice Questions: Hash Tables

<ExamQuestion title="Question 1: Collision Resolution Strategies [10 Marks]">
  <SubQuestion part="a" prompt={<>Explain the difference between Primary Clustering and Secondary Clustering in Open Addressing. [4]</>} solution={<>Primary clustering occurs in Linear Probing when contiguous blocks of occupied slots form, increasing the probe sequence length for new insertions. Secondary clustering occurs in Quadratic Probing where elements hashing to the same initial index follow the exact same probe sequence, though it avoids contiguous blocks.</>} />
  <SubQuestion part="b" prompt={<>How does Double Hashing eliminate both primary and secondary clustering? [6]</>} solution={<>Double hashing uses a second hash function to determine the step size for probing. Because the step size depends on the key itself, even if two keys hash to the same initial index, they will follow completely different probe sequences, eliminating secondary clustering. It also prevents contiguous blocks, eliminating primary clustering.</>} />
</ExamQuestion>

<ExamQuestion title="Question 2: Load Factor & Rehashing [8 Marks]">
  <SubQuestion part="a" prompt={<>Define the Load Factor of a hash table. Why is it critical for maintaining O(1) time complexity? [4]</>} solution={<>Load factor is the ratio of occupied entries to total buckets (size / capacity). It is critical because as the load factor approaches 1, collisions increase drastically, degrading lookup/insertion times from O(1) to O(N) in the worst case.</>} />
  <SubQuestion part="b" prompt={<>Describe the process of Rehashing. What is its time complexity? [4]</>} solution={<>When the load factor exceeds a threshold (e.g., 0.75), the table allocates a new backing array (usually double the capacity) and re-inserts all existing elements using the new modulo base. The time complexity is O(N) where N is the number of elements currently in the table.</>} />
</ExamQuestion>
