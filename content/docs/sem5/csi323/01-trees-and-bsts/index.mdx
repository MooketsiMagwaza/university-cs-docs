A tree stores data in a hierarchy, and a binary search tree keeps it ordered so that a search discards half of what remains at each step. This topic covers the vocabulary of trees, how a binary search tree inserts, deletes and searches, the four ways to traverse a tree, and the rotations that keep a tree balanced.
