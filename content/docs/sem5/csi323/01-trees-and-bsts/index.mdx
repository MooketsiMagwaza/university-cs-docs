A tree stores data in a hierarchy, and a binary search tree keeps it ordered so that a search discards half of what remains at each step. This topic covers the vocabulary of trees, how a binary search tree inserts, deletes and searches, the four ways to traverse a tree, and the rotations that keep a tree balanced.

<Callout type="note" title="Notes still to come">This topic has a visual study map, a review and practice questions. Written lesson notes are still being prepared.</Callout>

<LearningObjectives items={[
  'Use tree terminology correctly: root, parent, child, leaf, height and depth',
  'Insert, search and delete in a binary search tree, and state the cost in terms of its height',
  'Traverse a tree in in-order, pre-order, post-order and level-order',
  'Explain how AVL rotations and red-black properties keep a tree balanced',
]} />
