A heap is a binary tree stored in an array that always puts the smallest (or largest) element at the root, which makes it the natural way to build a priority queue. This topic covers the heap properties and the array layout, insertion and extraction, the linear-time method for building a heap, and the places heaps are used: Dijkstra's algorithm, the top-k problem and heap sort.
