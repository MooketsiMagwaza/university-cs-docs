# Practice Questions: Graphs

<ExamQuestion title="Question 1: Dijkstra vs Bellman-Ford [10 Marks]">
  <SubQuestion part="a" prompt={<>Why does Dijkstra's algorithm fail on graphs with negative edge weights? [4]</>} solution={<>Dijkstra's relies on a greedy assumption: once a node is popped from the priority queue, its shortest path is finalized. Negative edges can later provide a shorter path to an already 'finalized' node, breaking the algorithm.</>} />
  <SubQuestion part="b" prompt={<>How does Bellman-Ford detect a negative weight cycle? [6]</>} solution={<>It relaxes all edges V-1 times. If on the V-th iteration, any edge can still be relaxed (distance updates), it proves a negative weight cycle exists, as a valid shortest path can have at most V-1 edges.</>} />
</ExamQuestion>

<ExamQuestion title="Question 2: Topological Sort [8 Marks]">
  <SubQuestion part="a" prompt={<>Explain Kahn's Algorithm for Topological Sorting. What data structure is primarily used? [5]</>} solution={<>Calculate in-degrees for all nodes. Push all nodes with in-degree 0 into a Queue. Pop a node, add to result, and decrement in-degrees of its neighbors. If a neighbor's in-degree becomes 0, push to Queue.</>} />
  <SubQuestion part="b" prompt={<>How do you use Kahn's Algorithm to detect if a graph contains a cycle? [3]</>} solution={<>If the final topological order array contains fewer nodes than the total vertices in the graph (V), it means some nodes were trapped in a cycle and never reached an in-degree of 0.</>} />
</ExamQuestion>
