## Sets, Functions, Relations, and Graphs

A set is a collection of distinct objects. The statement $x\in A$ means that $x$ is an element of $A$. The empty set is $\emptyset$ and the universal set for a problem is usually written $U$.

## Set operations

$$
A\cup B=\{x:x\in A\text{ or }x\in B\},\quad
A\cap B=\{x:x\in A\text{ and }x\in B\}
$$

The complement $A^c$ contains the elements of $U$ not in $A$, while $A\setminus B$ contains elements in $A$ but not $B$. A power set $\mathcal P(A)$ contains every subset of $A$; if $|A|=n$, then $|\mathcal P(A)|=2^n$.

Set equality is normally proved by **double inclusion**: show $A\subseteq B$ and $B\subseteq A$. To prove an inclusion, take an arbitrary element of the left side and show it belongs to the right side.

## Cartesian products and relations

The Cartesian product
$$
A\times B=\{(a,b):a\in A, b\in B\}
$$
contains ordered pairs. A relation from $A$ to $B$ is any subset of $A\times B$. A relation on $A$ may be reflexive, symmetric, antisymmetric, or transitive.

## Functions

A function $f:A\to B$ assigns **exactly one** output in $B$ to each input in $A$. Several inputs may share an output, and elements of $B$ may be unused.

- **Injective:** $f(a_1)=f(a_2)$ implies $a_1=a_2$.
- **Surjective:** every $b\in B$ equals $f(a)$ for some $a\in A$.
- **Bijective:** both injective and surjective.

Only a bijection has a genuine inverse function $f^{-1}:B\to A$. Composition is $(g\circ f)(x)=g(f(x))$ and is defined only when the codomain of $f$ fits the domain of $g$.

## Graphs

A graph consists of vertices and edges. Degree counts incident edges; a path is a sequence of connected vertices; a cycle returns to its starting vertex. Directed graphs represent one-way relationships. Adjacency matrices and lists translate the visual structure into data structures.

## Common mistakes

- Confusing $x\in A$ with $\{x\}\subseteq A$.
- Treating a relation as a function when one input has two outputs.
- Claiming “onto” without naming the codomain.
- Forgetting that composition order matters: $g\circ f$ is generally not $f\circ g$.
