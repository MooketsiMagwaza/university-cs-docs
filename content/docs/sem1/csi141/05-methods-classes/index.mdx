title: "Methods, Libraries, and Classes"
description: "Writing methods with clear contracts, how Java passes arguments, using library documentation, and defining classes with fields, constructors and encapsulation."
---

Methods isolate a responsibility behind a name, and a class defines a type with its own state and behaviour. This topic covers method signatures and contracts, how Java passes arguments by value, using the standard library through its documentation, and writing a class with private fields, constructors and public methods. These are the foundations of object-oriented programming.
