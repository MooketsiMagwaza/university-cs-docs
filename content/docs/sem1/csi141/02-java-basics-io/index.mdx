Java is statically typed: every variable has a declared type, and the compiler checks that each operation is compatible with it. This topic covers the primitive types, strings, arithmetic with integer division and casts, reading input with `Scanner`, and printing formatted output. Many early mistakes, such as comparing strings with `==` or forgetting integer division, come from misunderstanding these basics.
