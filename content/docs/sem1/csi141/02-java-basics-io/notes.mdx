## Java Basics, Types, and I/O

Java is statically typed: every variable has a declared type, and the compiler checks that operations are compatible with that type.

## Values and variables

Common primitive types include `int`, `long`, `double`, `boolean`, and `char`. A variable declaration reserves a name and type; assignment stores a value:

```java
int count = 3;
double average = 12.5;
boolean ready = false;
```

Try it: change the three values, and the name, then predict the three lines before you run the program again.

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        int count = 3;
        double average = 12.5;
        boolean ready = false;
        String name = "Thandi";
        System.out.println(name + " has " + count + " items");
        System.out.println("Average: " + average);
        System.out.println("Ready: " + ready);
    }
}
```

```text
Thandi has 3 items
Average: 12.5
Ready: false
```

</JavaTryIt>

`String` is a reference type. Use `.equals` to compare string contents, not `==`, which compares references.

## Expressions and conversions

Arithmetic follows precedence: multiplication, division, and remainder before addition and subtraction. Integer division discards the fractional part:

```java
System.out.println(5 / 2);       // 2
System.out.println(5 / 2.0);     // 2.5
```

Widening conversions such as `int` to `double` are usually safe. Narrowing conversions need an explicit cast and may lose information:

```java
double price = 19.95;
int whole = (int) price; // 19
```

Try it: predict all four lines, run the program, then change `5 / 2.0` to `5 / 2` and `19.95` to `19.99` and predict again. Does the cast round the number?

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(5 / 2);
        System.out.println(5 / 2.0);
        double price = 19.95;
        int whole = (int) price;
        System.out.println(whole);
        System.out.println(7 % 3);
    }
}
```

```text
2
2.5
19
1
```

</JavaTryIt>

## Strings

Useful operations include `length()`, `charAt(i)`, `substring(a,b)`, and `toUpperCase()`. The upper bound of `substring` is exclusive, and valid character indices run from `0` to `length()-1`.

Try it: predict each line, run the program, then change `substring(0, 4)` to `substring(3, 7)` and predict again. Last, change `charAt(0)` to `charAt(11)` and read the message.

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        String word = "programming";
        System.out.println(word.length());
        System.out.println(word.charAt(0));
        System.out.println(word.substring(0, 4));
        System.out.println(word.toUpperCase());
        System.out.println(word.equals("Programming"));
    }
}
```

```text
11
p
prog
PROGRAMMING
false
```

</JavaTryIt>

## Console input

```java
Scanner in = new Scanner(System.in);
int age = in.nextInt();
String name = in.next();
in.nextLine();
String sentence = in.nextLine();
```

`nextInt()` leaves the line-ending character in the input buffer. Call `nextLine()` once to consume it before reading a complete line. For robust programs, validate that the next token has the expected type before reading it.

Try it: the browser runner has no keyboard, so the two variables stand in for what `in.nextInt()` and `in.next()` would return. Type a different age and name into the code and predict the two lines.

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        // These stand in for in.nextInt() and in.next().
        int age = 19;
        String name = "Ada";
        System.out.println("Hello, " + name + "!");
        System.out.println("Next year you will be " + (age + 1) + ".");
    }
}
```

```text
Hello, Ada!
Next year you will be 20.
```

</JavaTryIt>

## Output

`System.out.println` adds a newline; `System.out.print` does not. `printf` formats values:

```java
System.out.printf("Average: %.2f%n", average);
```

Try it: predict the four lines and run the program. Then change `12.5` to `12.3456` and predict how `%.2f` prints it, and change `%.2f` to `%.1f` to see how the number of decimal places follows the format.

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        double average = 12.5;
        System.out.print("One ");
        System.out.print("line");
        System.out.println();
        System.out.println("Two lines");
        System.out.printf("Average: %.2f%n", average);
        System.out.printf("%d items cost %.1f%n", 3, 7.26);
    }
}
```

```text
One line
Two lines
Average: 12.50
3 items cost 7.3
```

</JavaTryIt>

## Common mistakes

- Using `==` for string content.
- Comparing a `double` for exact equality after arithmetic.
- Forgetting integer division.
- Reading a line immediately after `nextInt()` without consuming the newline.
- Accessing `charAt(length())`, which is outside the valid range.
