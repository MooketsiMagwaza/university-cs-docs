Programming is the disciplined process of turning a problem into instructions a computer can execute. The language is only one part of that process: understanding the problem, choosing a representation and testing the result matter just as much. This topic introduces the path from a problem to a running Java program, the three kinds of error, and the habit of tracing and testing before trusting a result.

<LearningObjectives items={[
  "Turn a problem into a plan by identifying the inputs, outputs, constraints and assumptions and solving a small example by hand.",
  "State the four properties of an algorithm: finite, definite, effective and correct.",
  "Describe the Java workflow, in which javac compiles source code to bytecode and the Java Virtual Machine runs it, and write and run a minimal program.",
  "Distinguish compilation errors, runtime errors and logical errors.",
  "Trace variables in a table, and design tests for normal, boundary, zero or empty, and invalid cases.",
  "Use the debugging questions to find the first incorrect value instead of fixing the symptom at the end.",
]} />
