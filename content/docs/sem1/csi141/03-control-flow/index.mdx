title: "Control Flow and Debugging"
description: "Boolean conditions, selection with if and switch, loops with invariants, input validation, and systematic debugging."
---

Control flow decides which statements run and how often, so a reliable program makes each decision and stopping condition visible. This topic covers conditions built from comparison and logical operators, selection with `if` and `switch`, and repetition with `while`, `for` and `do-while` loops. It also shows how to debug a loop systematically with a trace table and by finding the first wrong value.

<LearningObjectives items={[
  "Write conditions with comparison and logical operators and parentheses, and order if, else if and else branches so that the right one runs.",
  "Choose between while, for and do-while for a given repetition.",
  "Design a loop with an initial state, a condition, an update that moves toward termination and an invariant.",
  "Use switch with break and default, and validate input before the value is used.",
  "Separate syntax, runtime and logic errors, and debug a loop with a trace table.",
  "Avoid common faults such as = in place of ==, a loop with no update, and a broad condition placed before a specific one.",
]} />
