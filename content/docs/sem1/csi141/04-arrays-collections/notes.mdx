## Arrays and ArrayLists

An array stores a fixed number of values of one type. Its valid indices are `0` through `length - 1`.

```java
int[] scores = new int[4];
scores[0] = 72;
for (int i = 0; i < scores.length; i++) {
    System.out.println(scores[i]);
}
```

The enhanced loop is convenient when the index is not needed:

```java
for (int score : scores) {
    total += score;
}
```

Try it: predict the total, run the program, then change `new int[4]` to `new int[3]` and read the message the runner gives for the fourth score.

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        int[] scores = new int[4];
        scores[0] = 72;
        scores[1] = 65;
        scores[2] = 90;
        scores[3] = 58;
        for (int i = 0; i < scores.length; i++) {
            System.out.println("scores[" + i + "] = " + scores[i]);
        }
        int total = 0;
        for (int score : scores) {
            total += score;
        }
        System.out.println("Total: " + total);
    }
}
```

```text
scores[0] = 72
scores[1] = 65
scores[2] = 90
scores[3] = 58
Total: 285
```

</JavaTryIt>

## Two-dimensional arrays

An `int[][]` is an array of rows, and rows may have different lengths. Use `matrix.length` for the number of rows and `matrix[row].length` for a particular row.

Try it: the rows of this array have different lengths. Add a value to the last row and a fourth row of your own, and predict each printed line before you run it.

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        int[][] matrix = {
            {1, 2, 3},
            {4, 5},
            {6}
        };
        System.out.println("Rows: " + matrix.length);
        for (int row = 0; row < matrix.length; row++) {
            System.out.print("Row " + row + " (length " + matrix[row].length + "):");
            for (int col = 0; col < matrix[row].length; col++) {
                System.out.print(" " + matrix[row][col]);
            }
            System.out.println();
        }
    }
}
```

```text
Rows: 3
Row 0 (length 3): 1 2 3
Row 1 (length 2): 4 5
Row 2 (length 1): 6
```

</JavaTryIt>

## ArrayList

`ArrayList<T>` grows dynamically and stores reference types, so use wrapper types such as `Integer` instead of `int` as the type parameter.

```java
ArrayList<String> names = new ArrayList<>();
names.add("Ada");
String first = names.get(0);
names.set(0, "Grace");
names.remove(0);
int n = names.size();
```

`remove(0)` removes an element by index; `remove(Integer.valueOf(0))` removes the value `0` from an integer list. This overload distinction matters.

Try it: predict both lists before you run the program. Then swap the two `remove` calls on `numbers` and predict again.

<JavaTryIt>

```java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> names = new ArrayList<>();
        names.add("Ada");
        names.add("Grace");
        names.set(0, "Alan");
        names.remove(1);
        System.out.println(names + ", size " + names.size());

        ArrayList<Integer> numbers = new ArrayList<>();
        numbers.add(5);
        numbers.add(0);
        numbers.add(7);
        numbers.remove(Integer.valueOf(0));
        System.out.println(numbers);
        numbers.remove(0);
        System.out.println(numbers);
    }
}
```

```text
[Alan], size 1
[5, 7]
[7]
```

</JavaTryIt>

## Choosing a collection

Use an array when the size is fixed and indexed access is central. Use `ArrayList` when the number of elements changes. Use a set when uniqueness matters and a map when values are retrieved by keys; these are introduced as the collection ideas grow.

Try it: the array stays at three cells while the list grows. Change the loop limit from 5 to 8 and predict both sizes. Then delete the `if` check and read the message.

<JavaTryIt>

```java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        int[] fixed = new int[3];
        ArrayList<Integer> growing = new ArrayList<>();
        for (int i = 0; i < 5; i++) {
            if (i < fixed.length) {
                fixed[i] = i * 10;
            }
            growing.add(i * 10);
        }
        System.out.println("array length: " + fixed.length);
        System.out.println("list size: " + growing.size());
        System.out.println(growing);
    }
}
```

```text
array length: 3
list size: 5
[0, 10, 20, 30, 40]
```

</JavaTryIt>

## Bounds and aliasing

An index error means the program asked for an element outside the valid range. Check empty collections before accessing index 0. Two variables can refer to the same array, so a mutation through one name is visible through the other.

Try it: predict the three lines. Then change `c[1] = -5;` to `a[1] = -5;` and predict the last line again: does the copy `c` see the change?

<JavaTryIt>

```java
public class Main {
    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        int[] b = a;
        b[0] = 99;
        System.out.println("a[0] = " + a[0]);
        System.out.println("b[0] = " + b[0]);

        int[] c = new int[a.length];
        for (int i = 0; i < a.length; i++) {
            c[i] = a[i];
        }
        c[1] = -5;
        System.out.println("a[1] = " + a[1] + ", c[1] = " + c[1]);
    }
}
```

```text
a[0] = 99
b[0] = 99
a[1] = 2, c[1] = -5
```

</JavaTryIt>

## Common mistakes

- Looping while `i <= array.length` instead of `i < array.length`.
- Using `.length` on an `ArrayList`; use `.size()`.
- Removing items while moving forward through a list and skipping the next item.
- Assuming a two-dimensional array is always rectangular.
