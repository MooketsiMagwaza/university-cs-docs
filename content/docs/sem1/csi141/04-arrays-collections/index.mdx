title: "Arrays and ArrayLists"
description: "Fixed-size and two-dimensional arrays, ArrayList operations, choosing a collection, and avoiding index errors and aliasing."
---

An array stores a fixed number of values of one type, while an `ArrayList` grows as elements are added. This topic covers one- and two-dimensional arrays, the operations of `ArrayList`, how to choose a collection, and how to avoid index errors and the unintended sharing of an array between variables. Together they let a program handle many values under one name with a loop.

<LearningObjectives items={[

  "Choose between an array and an ArrayList, and say when a set or a map would fit better.",
  "Prevent index errors by checking bounds and empty collections, and explain how aliasing lets a change through one variable show through another.",
]} />
