## Information Literacy

Information literacy is the ability to recognise an information need, find appropriate sources, evaluate them, use them ethically, and communicate the result. Search skill is only one part of the process.

## Turn a topic into a search

Begin with a question, then list key concepts and synonyms. Combine terms with Boolean operators:

| Operator | Effect | Example |
| --- | --- | --- |
| `AND` | Requires both concepts | `cybersecurity AND students` |
| `OR` | Allows alternatives | `mobile OR smartphone` |
| `NOT` | Excludes a term where supported | `jaguar NOT car` |
| Quotation marks | Searches a phrase | `"software engineering"` |

Use a broad search to learn vocabulary, then narrow with a date, subject, author, or peer-review filter. Search the library catalogue for books and research databases for journal literature; a general web search is useful for discovery but is not automatically evidence.

## Source types and evaluation

Primary sources present original data, documents, interviews, or experiments. Secondary sources analyse or interpret primary material. Tertiary sources summarise established information, such as encyclopaedias and glossaries. Match the source to the claim.

Check authority, accuracy, currency, relevance, and purpose. Ask who created the source, what evidence is supplied, whether the method can be inspected, when it was updated, and whether the language is informing, selling, entertaining, or persuading. Professional design is not proof of reliability.

## Keeping a research record

For every useful source, record full bibliographic details, page or section, key claim, and your own evaluation. Save a stable link or file copy where permitted. This prevents citation archaeology at the end of an assignment and makes your argument reproducible.

Respect copyright, database licences, privacy, and data terms of use. Cite ideas, words, images, tables, and code that came from another source. Paraphrasing changes the wording, not the need for attribution.
