## Functions and Graphs

A function $f:A\to B$ assigns exactly one output in $B$ to each input in $A$. The domain is the allowed input set; the range is the set of outputs actually produced.

## Domain and range

For a formula, exclude values that make a denominator zero or place a negative number under an even root. Logarithms require positive arguments. The range can be found algebraically, graphically, or by solving $y=f(x)$ for possible $y$ values.

## One-to-one and onto

The horizontal-line test checks one-to-one behaviour on a graph. A function is onto only relative to its stated codomain. A bijection is both one-to-one and onto and therefore has an inverse function.

## Composition and inverses

$(f\circ g)(x)=f(g(x))$ and the order matters. To find an inverse, write $y=f(x)$, solve for $x$, and rename the result $f^{-1}(y)$. Verify both compositions on the correct domains.

## Transformations

For $y=f(x)+k$, the graph shifts vertically by $k$; $y=f(x-h)$ shifts right by $h$. A negative outside reflects in the $x$-axis, while a negative inside reflects in the $y$-axis. Work from the base graph and state the transformed domain.

## Worked example

For $f(x)=1/(x-2)$, the domain excludes $x=2$ and the range excludes $y=0$. The graph is the reciprocal graph shifted right by 2, with vertical asymptote $x=2$ and horizontal asymptote $y=0$.

## Common mistakes

- Confusing domain with range.
- Claiming a function is onto without specifying its codomain.
- Forgetting restrictions after composition or inversion.
- Reversing the direction of a horizontal shift.
