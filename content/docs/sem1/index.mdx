## Core Courses

- **CSI131: Discrete Structures I**  
  The mathematical foundation of computer science. This course introduces propositional logic, set theory, functions, and proof techniques, developing the rigorous analytical reasoning required for advanced algorithms and computational theory.
  
- **CSI141: Programming Principles**  
  The gateway to software development. Transitioning from computational thinking to writing functional code, this course covers Java fundamentals, control structures, arrays, and introductory object-oriented concepts to build robust problem-solving skills.
  
- **CSI161: Introduction to Computing**  
  A holistic exploration of modern computing systems. This course looks "under the hood" of the digital world, covering the information processing cycle, computer architecture, hardware/software ecosystems, data representation, and network fundamentals.
  
- **MAT111: Introductory Mathematics I**  
  A comprehensive pre-calculus foundation. Consolidating secondary school mathematics, this course rigorously explores algebraic concepts, function properties, trigonometry, and complex numbers, preparing students for advanced scientific and engineering mathematics.

- **COM141: Communication and Academic Literacy Skills (Science)**
  The academic communication toolkit for science students: university learning, information literacy, reading, writing, listening, speaking, source evaluation, and ethical referencing.
