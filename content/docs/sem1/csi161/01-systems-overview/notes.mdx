## Computing Systems and the Information Cycle

A computer system combines hardware, software, data, people, and procedures to transform input into useful output. The four basic stages are input, processing, output, and storage; communication connects the stages and lets systems cooperate.

## Hardware and software

Hardware is the physical equipment: processor, memory, storage, input devices, output devices, and buses. Software is the instructions and data that tell hardware what to do. Neither is useful in isolation: hardware executes software, and software depends on hardware capabilities.

## The information cycle

When a student submits an online form, the keyboard and network provide input, the processor validates and transforms it, a display or response provides output, and a database stores the result. The same cycle appears in banking, scientific measurement, and mobile applications.

## System thinking

Changing one component affects the rest. More memory may reduce disk traffic; faster storage may reduce waiting time; a stronger password policy changes both software validation and user interaction. Analyse the whole system rather than one device in isolation.

## Data and information

Data are recorded symbols or measurements. Information is data interpreted in context. A number such as `42` has no meaning until the system says whether it is a temperature, age, count, or identifier.

## Checkpoint

For any everyday technology, identify the user, input, processing steps, output, storage location, communication links, and failure points. This decomposition is the foundation for later architecture and networking topics.
