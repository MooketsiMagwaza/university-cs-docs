## Software and Operating Systems

Software can be grouped by how close it is to hardware. Machine language is binary instruction data, assembly language is a symbolic representation, and a high-level language expresses algorithms in a form designed for humans.

## Translators

An assembler converts assembly language to machine code. A compiler translates a program before execution, usually reporting many errors together. An interpreter executes translated parts during runtime. Java uses compilation to bytecode and execution by a virtual machine.

## Operating-system responsibilities

An operating system manages processes, memory, files, devices, users, and security. It schedules work, isolates programs, provides system calls, and exposes interfaces such as shells and graphical desktops.

## Application and utility software

Applications solve user tasks such as writing, browsing, analysis, or communication. Utilities maintain or inspect the system: backup tools, antivirus, compression, and diagnostic programs are examples. Device drivers let the operating system communicate with specific hardware.

## Files and paths

Files store named data, while directories organise paths. A relative path depends on the current working directory; an absolute path identifies a location from the root. Permissions and ownership determine who may read, write, or execute a file.

## Checkpoint

Classify a program by role, then describe the operating-system services it needs. For a file error, check the path, permissions, file existence, and expected format in that order.
