---
title: "Software and Operating Systems"
description: "Machine, assembly and high-level languages, translators, the services of an operating system, application and utility software, and files and paths."
---

Software can be grouped by how close it is to the hardware, from machine language through assembly language to high-level languages, and by the job it does. This topic covers the translators that turn programs into machine code, what an operating system manages, the difference between applications, utilities and drivers, and how files and paths are organised. It explains how the hardware described earlier is controlled and used.
