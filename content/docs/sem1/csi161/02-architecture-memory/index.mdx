---
title: "Architecture, Organisation, and Memory"
description: "Computer architecture versus organisation, the components of the CPU, the instruction cycle, the memory hierarchy and the buses."
---

Computer architecture describes the behaviour and instruction set that a programmer sees, while computer organisation describes the hardware arrangements that implement it. This topic looks inside the processor and its memory: the CPU components, the instruction cycle, the memory hierarchy and the buses that carry data. It explains why the performance of a program depends on more than the clock speed.
