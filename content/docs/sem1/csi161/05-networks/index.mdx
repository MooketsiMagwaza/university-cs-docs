description: "Network devices and roles, packets and layered protocols, performance and reliability, and the basics of network security."

A network is a collection of connected devices that exchange data using agreed protocols. This topic covers the devices and roles in a network, how messages are divided into packets and governed by layered protocols, how performance and reliability are described, and the basic ideas of security. It ends by following a web request from a device to a server and back.

<LearningObjectives items={[
  "Describe the components of a network, and distinguish clients from servers and switches from routers and wireless access points.",
  "Explain how a message is divided into packets with headers and payloads, and what protocols and layering provide.",
  "Distinguish bandwidth, latency and throughput, and name the factors that affect performance.",
  "Explain how redundancy and error detection improve reliability at the cost of overhead.",
  "Distinguish authentication, authorisation, encryption and integrity checks.",
  "Trace a web request from a device to a server, identifying the client, the router, the addressing and the response path.",
]} />
