## Networks and Telecommunications

A network is a collection of connected devices that exchange data using agreed protocols. Communication involves a sender, receiver, medium, addressing scheme, and rules for interpreting messages.

## Components

Clients request services; servers provide them. Switches connect devices in a local network, routers forward packets between networks, and wireless access points bridge radio devices to a wired network.

## Packets and protocols

Large messages are divided into packets. Headers carry addressing and control information; payloads carry data. Protocols define formatting, ordering, error detection, and response behaviour. Layering lets an application use transport and network services without implementing every physical detail.

## Performance and reliability

Bandwidth is capacity, latency is delay, and throughput is the achieved rate. Congestion, interference, distance, and retransmission affect performance. Redundancy and error detection improve reliability but add overhead.

## Security

Authentication answers who a user is; authorisation answers what they may do. Encryption protects confidentiality, while integrity checks detect modification. Strong security is a system property, not just a password choice.

## Checkpoint

Trace a web request from a device to a server. Identify the client, local connection, router, addressing information, transport behaviour, and response path.
