---
title: "Data Representation"
description: "Bits and bytes, conversion between binary, hexadecimal and decimal, range and overflow, and how text, images and sound are encoded."
---

Digital hardware represents information with bits, and a pattern of bits has meaning only when it is interpreted using a type or an encoding. This topic covers the binary and hexadecimal number systems and conversion between them and decimal, the range of values that $n$ bits can hold, overflow, and how text, images and sound are represented. It shows why every stored value has limits.

<LearningObjectives items={[
  "Explain that a bit pattern has meaning only through a type or an encoding, and that a byte holds eight bits.",
  "Convert a value between decimal, binary and hexadecimal, grouping binary digits in fours to reach hexadecimal.",
  "State the range of values that a given number of unsigned bits can represent, and explain how signed representations reserve patterns for negative values.",
  "Explain overflow, and what can happen when a calculation exceeds the available bits.",
  "Describe how character encodings, pixels with colour channels, and sound samples represent text, images and sound, and the storage cost of more bits per sample or pixel.",
]} />
