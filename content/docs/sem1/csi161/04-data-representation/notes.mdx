## Data Representation

Digital hardware represents information with bits, each having two possible states. A byte contains eight bits. The same pattern has meaning only when interpreted using a type or encoding.

## Bases

Binary uses powers of 2; hexadecimal uses powers of 16 and maps four bits to one digit. For example,
$$
(101101)_2=1(32)+0(16)+1(8)+1(4)+0(2)+1(1)=45_{10}.
$$
Group binary digits in fours to convert quickly to hexadecimal: $1011\ 0101_2=B5_{16}$.

## Range and overflow

With $n$ unsigned bits there are $2^n$ patterns representing $0$ through $2^n-1$. Signed representations reserve patterns for negative values. Overflow occurs when a result cannot be represented in the available number of bits.

## Text and media

Character encodings map symbols to numbers. Images use pixels and colour channels; sound uses samples taken over time. More bits per sample or pixel can improve fidelity but increases storage and transmission requirements.
