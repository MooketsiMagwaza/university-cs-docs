1. The array we will sort

Arrays use zero-based positions. Sorting changes which values occupy those positions. The target is ascending order; record tags would move with their values.

We will distinguish comparisons, swaps, shifts, temporary writes and copy-back writes. They are different units.

2. Definition and plain language

Bubble sort is a comparison sort that repeatedly scans adjacent pairs. In ascending order it exchanges a pair only when the left value is larger than the right value.

Read the cards from left to right. Every time a bigger card sits before a smaller one, exchange them. A large card can travel many cells in one pass, while a small card may move left only one cell in that pass.

After one complete pass, the largest active value has reached the last active position. The next pass ignores that fixed suffix.

3. Vocabulary and the central invariant

TermMeaning in this chapter
AdjacentTwo neighbouring indexes j and j + 1.
SwapExchange two values using a temporary variable.
PassOne sweep through the still-active adjacent pairs.
Sorted suffixThe final positions already proved correct.
swapped flagA Boolean reset before each pass; a whole pass with no change permits early termination.

Invariant: At the start of pass p (zero based), the last p positions hold the p largest values in final order.

One non-swap does not prove the whole array is sorted. Only a full no-swap pass supports the early stop.

10. Descending order: change the decision

Change arr[j] > arr[j + 1] to arr[j] < arr[j + 1]. Each pass then locks the smallest active value on the right.

Keep the bounds and movement rules consistent. Reversing a final array is a different procedure and does not reproduce the descending trace of this implementation.

12. Properties and why the complexity occurs

PropertyResultReason
BestO(n)Already sorted input: one pass makes n - 1 comparisons and no swaps.
Average / worstO(n²)A reverse-order array needs many shrinking sweeps.
Auxiliary spaceO(1) iterative; O(n) recursive worst caseA temporary swap value versus a chain of calls.
Stable / in placeYes / yesStrict > avoids crossing equals; values are exchanged inside the input.
AdaptiveYes in this optimized versionThe swapped flag enables early stop.

On the main input there are 10 key comparisons and 6 swaps. A swap writes two input cells, giving 12 array writes. A no-swap first pass on a sorted five-value array uses only 4 comparisons.

13. When to choose it

Useful for small teaching examples and for recognizing adjacent-pair logic. Already sorted input benefits from early stop; large unsorted arrays are better suited to an O(n log n) algorithm.

14. Common mistakes, symptoms and repairs

AttemptWhat goes wrongRepair
Loop to j < arr.lengtharr[j + 1] reaches an invalid index.Use j < arr.length - 1 - pass.
Declare swapped only onceAn earlier swap prevents later early termination.Reset it to false before every pass.
Swap on >=Equal records may cross and lose stability.Swap only strictly inverted pairs.
Stop after one non-swapOnly that pair is ordered.Stop after an entire pass with no swaps.

B. Explain stability with tagged equal keys. [4]

Strict inversion comparisons do not move a value past an equal one. Using >= (or <= descending) would remove that guarantee.

C. Give the time and space, then justify both. [5]
